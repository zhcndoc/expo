| 属性               | 类型   | 必填        | 描述                                                                                                            |
| ------------------ | ------ | ----------- | ---------------------------------------------------------------------------------------------------------------------- |
| `query`            | string | <YesIcon /> | HogQL 查询。当第一行的第一列为 `true` 或非零数字时，该步骤将清除。                   |
| `timeout_seconds`  | number | <NoIcon />  | 最大等待时间，以秒为单位。默认为 `600`。                                                                   |
| `interval_seconds` | number | <NoIcon />  | 检查之间的间隔时间，以秒为单位。默认为 `30`。                                                                     |
| `api_key`          | string | <NoIcon />  | PostHog 个人 API 密钥。默认为 `POSTHOG_CLI_API_KEY` 环境变量。需要 `query:read` 作用域。 |
| `project_id`       | string | <NoIcon />  | PostHog 项目 ID。默认为 `POSTHOG_CLI_PROJECT_ID` 环境变量。                                     |
