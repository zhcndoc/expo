| 属性          | 类型   | 必填       | 描述                                                                            |
| ------------- | ------ | ---------- | ------------------------------------------------------------------------------ |
| `name`        | string | <NoIcon /> | 要下载的构建产物名称。如果未提供 `artifact_id`，则此项为必填项。 |
| `artifact_id` | string | <NoIcon /> | 要下载的构建产物 ID。如果未提供 `name`，则此项为必填项。          |

##### 输出

| 属性            | 类型   | 描述                                                                                                                                                  |
| --------------- | ------ | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `artifact_path` | string | 已下载构建产物的路径。此输出可用作工作流中其他步骤的输入。例如，用于发送或处理构建产物。 |
