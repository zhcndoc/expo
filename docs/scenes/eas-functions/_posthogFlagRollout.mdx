| Property             | Type    | Required    | Description                                                                                                                                                                                                                                                             |
| -------------------- | ------- | ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `flag`               | string  | <YesIcon /> | 要更新的功能标志键。                                                                                                                                                                                                                                  |
| `active`             | boolean | <NoIcon />  | 功能标志是否已启用。                                                                                                                                                                                                                                            |
| `rollout_percentage` | number  | <NoIcon />  | 功能标志面向的用户百分比，取值为 `0` 到 `100` 之间的整数。此函数会将其应用于功能标志的兜底发布条件，并保留其他条件。如果功能标志没有兜底条件，此函数会将其应用于第一个条件。 |
| `payload`            | json    | <NoIcon />  | 要附加到功能标志的负载。                                                                                                                                                                                                                                          |
| `variant`            | string  | <NoIcon />  | 在多变量功能标志上用于存储 `payload` 的变体键。默认为功能标志的 `true` 负载。                                                                                                                                                                 |
| `api_key`            | string  | <NoIcon />  | PostHog 个人 API 密钥。默认为 `POSTHOG_CLI_API_KEY` 环境变量。需要 `feature_flag:read` 和 `feature_flag:write` 作用域。                                                                                                                 |
| `project_id`         | string  | <NoIcon />  | PostHog 项目 ID。默认为 `POSTHOG_CLI_PROJECT_ID` 环境变量。                                                                                                                                                                                      |
| `ignore_error`       | boolean | <NoIcon />  | 为 `true` 时，网络错误、缺少功能标志或意外响应会被记录，但不会导致步骤失败。默认为 `false`。权限错误或无效输入（例如超出范围的 `rollout_percentage`）始终会导致步骤失败。                           |
