| 属性         | 类型     | 必填       | 默认值                         | 描述                                                                   |
| ------------ | -------- | ---------- | ------------------------------ | ---------------------------------------------------------------------- |
| `build_id`   | string   | <YesIcon /> | –                              | 要下载的构建的 ID。必须是有效的 UUID。                                  |
| `extensions` | string[] | <NoIcon />  | `["apk", "aab", "ipa", "app"]` | 要在下载的工件或存档中查找的文件扩展名列表。                            |

##### 输出

| 属性           | 类型   | 描述                                                                                                                                                         |
| -------------- | ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `artifact_path` | string | 匹配的应用程序存档的绝对路径。此输出可用作其他步骤的输入。例如，可用于上传或进一步处理工件。 |
