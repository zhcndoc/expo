| 属性           | 类型    | 必填       | 描述                                                                                                                                                                                        |
| -------------- | ------- | ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `event`        | string  | <YesIcon /> | 要发送的事件名称。                                                                                                                                                                         |
| `distinct_id`  | string  | <NoIcon />  | 要将事件归因到的人员。省略时，事件将匿名发送，且不会创建人员档案。                                                                                                                          |
| `properties`   | json    | <NoIcon />  | 要附加到事件的属性。                                                                                                                                                                       |
| `api_key`      | string  | <NoIcon />  | PostHog 项目 API 密钥。默认为由 `eas integrations:posthog:connect` 设置的 `EXPO_PUBLIC_POSTHOG_API_KEY` 环境变量；如果未设置，则回退到 `POSTHOG_API_KEY`。 |
| `host`         | string  | <NoIcon />  | PostHog 主机。默认为 `EXPO_PUBLIC_POSTHOG_HOST` 环境变量，或 `https://us.posthog.com`。                                                                                                  |
| `ignore_error` | boolean | <NoIcon />  | 当值为 `true` 时，发送事件失败会记录日志，但不会导致步骤失败。默认为 `false`。                                                                                                             |
