| 属性           | 类型    | 必填       | 描述                                                                                                              |
| -------------- | ------- | ---------- | ------------------------------------------------------------------------------------------------------------------------ |
| `directory`    | string  | <NoIcon /> | 包含 bundle 和源映射的目录，相对于工作目录。默认为 `dist`。           |
| `api_key`      | string  | <NoIcon /> | PostHog 个人 API 密钥。默认为 `POSTHOG_CLI_API_KEY` 环境变量。需要源映射上传权限。 |
| `project_id`   | string  | <NoIcon /> | PostHog 项目 ID。默认为 `POSTHOG_CLI_PROJECT_ID` 环境变量。                                       |
| `ignore_error` | boolean | <NoIcon /> | 当为 `true` 时，上传失败会被记录，但不会导致步骤失败。默认为 `false`。                                  |
