## 使用 EAS CLI 在本地创建开发版本

任何 EAS Build 都可以通过添加 `--local` 标志在你自己的计算机上运行：EAS 提供凭据、签名和构建配置文件，而编译则使用你计算机上的原生工具链完成。

这要求你的本地开发环境已设置必要的原生构建工具。详细了解[在本地运行 EAS Build](/build-reference/local-builds/)。

### 主机平台支持

|             | Android           | iOS 模拟器 | iPhone 设备   |
| ----------- | ----------------- | ------------- | --------------- |
| **macOS**   | <YesIcon/>        | <YesIcon/>    | <YesIcon/> (\*) |
| **Windows** | <YesIcon/> (\*\*) | <NoIcon />    | <NoIcon />      |
| **Linux**   | <YesIcon/>        | <NoIcon />    | <NoIcon />      |

> (\*) 所有在 iPhone 设备上运行的构建都需要付费的 [Apple Developer](https://developer.apple.com) 账户进行构建签名。<br />
> (\*\*) 不提供一流支持，但可以通过 [WSL](https://expo.fyi/wsl.md) 实现。

<Prerequisites>
  <Requirement title="Expo 账户">
    如果你还没有 [Expo](https://expo.dev/signup) 账户，请注册一个。
  </Requirement>
  <Requirement title="EAS CLI">
    已安装并登录的 [EAS CLI](/build/setup/#install-the-latest-eas-cli)。
    <Terminal
      cmd={{
        npm: ['$ npm install --global eas-cli && eas login'],

    本地编译需要设置好你的开发环境：[Android
    Studio](/workflow/android-studio-emulator/) 用于 Android 构建，
    [Xcode](/workflow/ios-simulator/) 用于 iOS 构建。
  </Requirement>
</Prerequisites>

<Step label="1">

### 安装 expo-dev-client

在项目的根目录中运行以下命令：

<Terminal
  cmd={{
    npm: ['$ npx expo install expo-dev-client'],
    yarn: ['$ yarn expo install expo-dev-client'],
    pnpm: ['$ pnpm expo install expo-dev-client'],
    bun: ['$ bun expo install expo-dev-client'],
  }}
/>

<Collapsible summary="你是否在现有的 React Native 项目中使用此库？">

不使用[持续原生生成](/workflow/continuous-native-generation/)或使用 `npx react-native` 创建的应用，在安装此库后需要进行进一步配置。请参阅[在现有 React Native 项目中安装 `expo-dev-client`](/bare/install-dev-builds-in-bare/)中的步骤 1 和 2。

</Collapsible>

<Step label="2">

### 在你的计算机上构建原生应用

如果你的项目还没有 **eas.json**，EAS CLI 会提示你使用默认的 `development` 配置文件创建一个。

<Tabs>

<Tab label="Android">

<Terminal cmd={['$ eas build --platform android --profile development --local']} />

</Tab>

<Tab label="iOS">

<Terminal cmd={['$ eas build --platform ios --profile development --local']} />

对于模拟器构建，请先在 **eas.json** 的 `development` 配置文件中将 [`simulator`](/eas/json/#simulator) 选项设置为 `true`。

</Tab>

</Tabs>

</Step>

<Step label="3">

### 安装应用

本地构建的输出是一个归档文件（Android 为 **.apk**，iOS 为 **.app**/**.ipa**）。将其拖放到 Android 模拟器或 iOS 模拟器上即可安装，或者使用 [Expo Orbit](https://expo.dev/orbit) 从你的计算机将其安装到任意设备上。

</Step>

<Step label="4">

### 启动 JavaScript 打包器

<Terminal
  cmd={{
    npm: ['$ npx expo start'],
    yarn: ['$ yarn expo start'],
    pnpm: ['$ pnpm expo start'],
    bun: ['$ bun expo start'],
  }}
/>

由于你的项目已安装 `expo-dev-client`，此命令会将目标设为你的开发版本，而不是 Expo Go。

</Step>
