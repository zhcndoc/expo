首次运行 `npx expo prebuild --clean`，完成开发构建设置。之后，每当原生依赖或应用配置发生变化，需要重新构建前，使用相同的命令。使用此项目已有的包管理器，并报告运行了哪些命令。

<AgentPromptOption id="build-with-eas" label="使用 EAS 构建">

```text wrap
为我的 Expo 项目设置开发构建，并在 EAS 上构建。

运行 `npx expo install expo-dev-client`。检查是否已安装 eas-cli，以及我是否已登录。如果项目中没有 eas.json，则创建一个包含 development 配置的 eas.json。对于 iOS Simulator 构建，先在该配置中将 `ios.simulator` 设为 true。然后暂停并询问我：“所有内容均已安装。现在要开始构建吗？”等待我的答复。我回答是之后，针对我指定的平台运行 `eas build --platform <platform> --profile development`。

当 CLI 提示时，将已完成的构建安装到 Android Emulator 或 iOS Simulator（我指定的平台）上，然后使用 `npx expo start` 启动开发服务器。使用此项目已有的包管理器，并报告运行了哪些命令。

有关开发构建的介绍，请参阅 https://docs.expo.dev/develop/development-builds/introduction/?buildenv=build-with-eas。
```

</AgentPromptOption>

<AgentPromptOption id="eas-cli-local" label="使用 EAS CLI 本地构建">

为我的 Expo 项目设置开发构建，并在我自己的机器上运行 EAS 构建。

将生成的 .apk 或 .app 归档安装到我的模拟器上，然后使用 `npx expo start` 启动开发服务器。使用此项目已有的包管理器，并报告运行了哪些命令。

有关开发构建的介绍，请参阅 https://docs.expo.dev/develop/development-builds/introduction/?buildenv=eas-cli-local。
