## 配置你的项目

<Step label="1">

### 安装 expo-dev-client

在项目根目录中运行以下命令：

<Terminal
  cmd={{
    npm: ['$ npx expo install expo-dev-client'],
    yarn: ['$ yarn expo install expo-dev-client'],
    pnpm: ['$ pnpm expo install expo-dev-client'],
    bun: ['$ bun expo install expo-dev-client'],
  }}
/>

</Step>

<Step label="2">

### 通过 USB 插入你的设备并启用开发者模式

1. 使用 USB 数据线将你的 iOS 设备连接到 Mac。解锁设备，如果出现提示，请点按 **信任**。

2. 打开 Xcode。在菜单栏中，选择 **Window** > **Devices and Simulators**。你会在 Xcode 中看到一条启用开发者模式的警告。

3. 在你的 iOS 设备上，打开 **设置** > **隐私与安全性**，向下滚动到 **开发者模式** 选项并进入。

4. 点按开关以启用 **开发者模式**。执行后，设置会显示一条警告，提示你开发者模式会降低设备的安全性。要继续启用 **开发者模式**，请点按警告中的 **重新启动** 按钮。

5. 设备重启并解锁后，设备会显示一条确认你要启用开发者模式的提示。点按 **打开**，并在提示时输入设备密码。

</Step>

<Step label="3">

### 在你的设备上运行项目

1. 在根目录的 **app.json** 文件中添加唯一的 `ios.bundleIdentifier` 值，以便 Xcode 在应用签名步骤中生成配置文件。

2. 在项目根目录中运行以下命令，并从列表中选择你已连接的设备：

<Terminal
  cmd={{
    npm: ['$ npx expo run:ios --device'],
    yarn: ['$ yarn expo run:ios --device'],
    pnpm: ['$ pnpm expo run:ios --device'],
    bun: ['$ bun expo run:ios --device'],
  }}
/>

> 此命令会在构建应用后运行开发服务器。你可以在下一页跳过运行 `npx expo start`。

</Step>
