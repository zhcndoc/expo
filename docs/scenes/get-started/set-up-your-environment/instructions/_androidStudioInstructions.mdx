## 配置 Android Studio

<Tabs>

<Tab label="macOS">

<Step label="1">

下载并安装 [Android Studio](https://developer.android.com/studio)。

</Step>

<Step label="2">

打开 **Android Studio** 应用。首次启动时会显示 **Android Studio Setup Wizard**。在 **Welcome** 界面点击 **Next**。然后，在 **Install Type** 下选择 **Standard** 并点击 **Next**。

<ContentSpotlight
  alt="Android Studio Setup Wizard 要求选择安装类型。"
  src="/static/images/android-studio/install-type.webp"
  className="max-w-[600px]"
/>

确认设置后点击 **Next**。接着接受许可协议并再次点击 **Next**。向导会下载并安装 Android SDK 及其工具。安装完成后点击 **Finish**。

</Step>

<Step label="3">

默认情况下，Android Studio 会安装最新版本的 Android SDK。不过，编译 React Native 应用需要 Android 16（`Baklava`）SDK。

打开 Android Studio，进入 **Settings** &gt; **Languages & Frameworks** &gt; **Android SDK**。在 **SDK Platforms** 选项卡中，在 **Android 16 (`Baklava`)** 下选择 **Android SDK Platform 36** 和 **Sources for Android 36**。

<ContentSpotlight
  alt="Android SDK Platforms"
  src="/static/images/android-studio/sdk-platforms.webp"
  className="max-w-[640px]"
/>

</Step>

<Step label="4">

然后，点击 **SDK Tools** 选项卡，确保至少安装了一个版本的 **Android SDK Build-Tools** 和 **Android Emulator**。

<ContentSpotlight
  alt="Android SDK build tools."
  src="/static/images/android-studio/build-tools.webp"
  className="max-w-[640px]"
/>

</Step>

<Step label="5">

复制或记住框中显示的 **Android SDK Location** 路径。

<ContentSpotlight
  alt="Android SDK location"
  src="/static/images/android-studio/sdk-location.webp"
  className="max-w-[640px]"
/>
</Step>

<Step label="6">

将以下内容添加到你的 **/.zprofile** 或 **~/.zshrc**（如果你使用 bash，则添加到 **~/.bash_profile** 或 **~/.bashrc**）配置文件中：

<Terminal
  cmd={[
    '$ export ANDROID_HOME=$HOME/Library/Android/sdk',
    '$ export PATH=$PATH:$ANDROID_HOME/emulator',
    '$ export PATH=$PATH:$ANDROID_HOME/platform-tools',
  ]}
  cmdCopy="export ANDROID_HOME=$HOME/Library/Android/sdk && export PATH=$PATH:$ANDROID_HOME/emulator && export PATH=$PATH:$ANDROID_HOME/platform-tools"
/>

</Step>

<Step label="7">

在当前 shell 中重新加载 path 环境变量：

<Terminal
  cmd={['# for zsh', '$ source $HOME/.zshrc', '', '# for bash', '$ source $HOME/.bashrc']}
/>

</Step>

<Step label="8">

最后，确保你可以在终端中运行 `adb`。

<Collapsible summary="故障排查：Android Studio 无法识别 JDK">

如果 Android Studio 无法识别你通过 homebrew 安装的 JDK，你可以创建一个 Gradle 配置文件来显式设置 Java 路径：

1.  在你的主目录中创建一个 Gradle properties 文件：

    <Terminal cmd={['$ touch ~/.gradle/gradle.properties']} />

2.  将以下内容添加到 **gradle.properties** 文件中，并将路径替换为你实际的 Java 安装路径：

    ```bash gradle.properties
    java.home=/Library/Java/JavaVirtualMachines/zulu-17.jdk/Contents/Home
    ```

3.  如果你的项目目录中已经存在 `.gradle` 文件夹，请删除它，然后在 Android Studio 中重新打开你的项目：

    <Terminal cmd={['$ rm -rf .gradle']} />

这应该可以解决 Android Studio 无法检测到你的 JDK 安装的问题。

</Collapsible>

</Step>

</Tab>

<Tab label="Windows">

<Step label="1">

下载 [Android Studio](https://developer.android.com/studio)。

</Step>

<Step label="2">

打开 **Android Studio Setup**。在 **Select components to install** 下，选择 Android Studio 和 Android Virtual Device。然后点击 **Next**。

</Step>

<Step label="3">

在 Android Studio Setup Wizard 中，在 **Install Type** 下选择 **Standard** 并点击 **Next**。

<ContentSpotlight
  alt="Android Studio Setup Wizard 要求选择安装类型。"
  src="/static/images/android-studio/windows-install-type.webp"
  className="max-w-[600px]"
/>

</Step>

<Step label="4">

Android Studio Setup Wizard 会要求你确认诸如 Android SDK 版本、platform-tools 等设置。确认后点击 **Next**。

</Step>

<Step label="5">

在下一个窗口中，接受所有可用组件的许可协议。

<ContentSpotlight
  alt="Android Studio Setup Wizard 要求接受各种许可协议以安装工具。"
  src="/static/images/android-studio/windows-licenses.webp"
  className="max-w-[600px]"
/>

</Step>

<Step label="6">

默认情况下，Android Studio 会安装最新版本的 Android SDK。不过，编译 React Native 应用需要 Android 16（`Baklava`）SDK。

打开 Android Studio，进入 **Settings** &gt; **Languages & Frameworks** &gt; **Android SDK**。在 **SDK Platforms** 选项卡中，在 **Android 16 (`Baklava`)** 下选择 **Android SDK Platform 36** 和 **Sources for Android 36**。

<ContentSpotlight
  alt="Android SDK Platforms"
  src="/static/images/android-studio/windows-sdk-platforms.webp"
  className="max-w-[640px]"
/>

</Step>

<Step label="7">

然后，点击 **SDK Tools** 选项卡，确保至少安装了一个版本的 **Android SDK Build-Tools** 和 **Android Emulator**。

<ContentSpotlight
  alt="Android SDK build tools"
  src="/static/images/android-studio/windows-build-tools.webp"
  className="max-w-[640px]"
/>

</Step>

<Step label="8">

工具安装完成后，配置 `ANDROID_HOME` 环境变量。进入 **Windows Control Panel** > **User Accounts** > **User Accounts**（再次）> **Change my environment variables**，然后点击 **New** 创建一个新的 `ANDROID_HOME` 用户变量。该变量的值应指向你的 Android SDK 路径：

<ContentSpotlight
  alt="Setting up ANDROID_HOME user variable."
  src="/static/images/android-studio/windows-android-home-variable.webp"
  className="max-w-[480px]"
/>

<Collapsible summary="如何查找已安装的 SDK 位置？">

默认情况下，Android SDK 安装在以下位置：

```bash
%LOCALAPPDATA%\Android\Sdk
```

要在 Android Studio 中手动查找 SDK 的位置，请进入 **Settings** > **Languages & Frameworks** > **Android SDK**。查看 **Android SDK Location** 旁边的位置。

<ContentSpotlight
  alt="Android SDK location in Android Studio Settings."
  src="/static/images/android-studio/windows-android-sdk-location.webp"
  className="max-w-[400px]"
/>

</Collapsible>

</Step>

<Step label="9">

要验证新的环境变量已加载，请打开 **PowerShell**，并复制粘贴以下命令：

<Terminal cmd={['$ Get-ChildItem -Path Env: ']} />

该命令会输出所有用户环境变量。查看列表中是否已添加 `ANDROID_HOME`。

</Step>

<Step label="10">

要将 platform-tools 添加到 Path 中，请进入 **Windows Control Panel** > **User Accounts** > **User Accounts**（再次）> **Change my environment variables** > **Path** > **Edit** > **New**，然后按如下所示将 platform-tools 的路径添加到列表中：

<ContentSpotlight
  alt="Setting up platform-tools user variable."
  src="/static/images/android-studio/windows-platform-tools-path.webp"
  className="max-w-[480px]"
/>

<Collapsible summary="如何查找已安装的 platform-tools 位置">

默认情况下，platform-tools 安装在以下位置：

```bash
%LOCALAPPDATA%\Android\Sdk\platform-tools
```

</Collapsible>

</Step>

<Step label="11">

最后，确保你可以在 PowerShell 中运行 `adb`。例如，运行 `adb --version` 来查看系统正在使用哪个版本的 `adb`。

</Step>

</Tab>

</Tabs>
