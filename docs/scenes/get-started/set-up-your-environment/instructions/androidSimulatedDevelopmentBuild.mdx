## 创建开发构建

<Step label="1">

### 安装 EAS CLI

要构建你的应用，你需要安装 EAS CLI。你可以在终端中运行以下命令来完成安装：

<Terminal
  cmd={{
    npm: ['$ npm install --global eas-cli'],
    yarn: ['$ yarn global add eas-cli'],
    pnpm: ['$ pnpm add --global eas-cli'],
    bun: ['$ bun add --global eas-cli'],
  }}
/>

</Step>

<Step label="2">

### 创建 Expo 账户并登录

要构建你的应用，你需要创建一个 Expo 账户并登录 EAS CLI。

1. [注册](https://expo.dev/signup) 一个 Expo 账户。
2. 在终端中运行以下命令登录 EAS CLI：
   <Terminal cmd={['$ eas login']} />

</Step>

<Step label="3">
### 配置你的项目

运行以下命令，在你的项目中创建 EAS 配置：

<Terminal cmd={['$ eas build:configure']} />

</Step>

<Step label="4">
### 创建构建

运行以下命令来创建开发构建：

<Terminal cmd={['$ eas build --platform android --profile development']} />
</Step>

<Step label="5">
### 在你的模拟器上安装开发构建

构建完成后，CLI 会提示你自动下载并将其安装到 Android 模拟器上。出现提示时，按 <kbd>Y</kbd> 直接将其安装到模拟器上。

如果你错过了这个提示，可以从终端中提供的链接下载构建，然后将其拖放到 Android 模拟器中进行安装。

</Step>
