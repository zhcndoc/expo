## 安装 JDK

<Tabs>

<Tab label='macOS'>

#### 先决条件

使用 [Homebrew](https://brew.sh/) 等包管理器来安装以下依赖项。

#### 安装依赖项

<Step label="1">

> **info** 安装 Watchman 仅对 SDK 55 及更早版本的项目是必需的。

使用 Homebrew 等工具安装 [Watchman](https://facebook.github.io/watchman/docs/install#macos)：

<Terminal cmd={['$ brew install watchman']} />

</Step>

<Step label="2">

使用 Homebrew 安装名为 Azul Zulu 的 OpenJDK 发行版。该发行版同时为 Apple Silicon 和 Intel Mac 提供 JDK。

在终端中运行以下命令：

<Terminal cmd={['$ brew install --cask zulu@17']} />

安装 JDK 后，在 **~/.bash_profile** 中添加 `JAVA_HOME` 环境变量（如果你使用 Zsh，则添加到 **~/.zshrc** 中）：

```bash
export JAVA_HOME=/Library/Java/JavaVirtualMachines/zulu-17.jdk/Contents/Home
```

</Step>

</Tab>

<Tab label='Windows'>

#### 先决条件

使用 [Chocolatey](https://chocolatey.org/) 等包管理器来安装以下依赖项。

#### 安装依赖项

安装 [Java SE Development Kit (JDK)](https://openjdk.org/)：

<Terminal cmd={['$ choco install -y microsoft-openjdk17']} />

</Tab>

<Tab label="Linux">

#### 安装依赖项

<Step label="1">

> **info** 安装 Watchman 仅对 SDK 55 及更早版本的项目是必需的。

按照 [Watchman 文档中的说明](https://facebook.github.io/watchman/docs/install#linux) 从源代码编译并安装它。

</Step>

<Step label="2">

安装 [Java SE Development Kit (JDK)](https://openjdk.org/)：

你可以从 [AdoptOpenJDK](https://adoptopenjdk.net/) 或你的系统软件包管理器下载并安装 [OpenJDK@17](http://openjdk.java.net/)。

</Step>

</Tab>

</Tabs>
