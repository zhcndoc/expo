## 安装 Expo Go

当你在 [开始开发](/get-started/start-developing) 页面上使用 `npx expo start` 启动开发服务器时，按 <kbd>A</kbd> 打开 Android 模拟器。Expo CLI 会自动安装 Expo Go。
