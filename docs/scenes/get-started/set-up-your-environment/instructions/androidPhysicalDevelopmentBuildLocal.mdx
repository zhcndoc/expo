## 在 Android 设备上运行你的应用

<Step label="1">

### 安装 expo-dev-client

在项目的根目录中运行以下命令：

<Terminal
  cmd={{
    npm: ['$ npx expo install expo-dev-client'],
    yarn: ['$ yarn expo install expo-dev-client'],
    pnpm: ['$ pnpm expo install expo-dev-client'],
    bun: ['$ bun expo install expo-dev-client'],
  }}
/>

</Step>

<Step label="2">
### 启用 USB 调试

默认情况下，大多数 Android 设备只能安装并运行从 Google Play 下载的应用。你需要在设备上启用 USB 调试，才能在开发期间安装你的应用。

要在设备上启用 USB 调试，首先需要通过进入 **设置** > **关于手机** > **软件信息**，然后连续点击底部的 `Build number` 行七次，来启用“开发者选项”菜单。之后，你可以返回 **设置** > **开发者选项**，启用“USB debugging”。

</Step>

<Step label="3">

### 通过 USB 插入你的设备

通过 USB 将你的 Android 设备连接到电脑。

通过在终端中运行 `adb devices`，检查你的设备是否已正确连接到 ADB（Android 调试桥）。你应该会看到设备列表，其中你的设备旁边显示 `device`。例如：

<Terminal cmd={['$ adb devices', '', 'List of devices attached', '8AHX0T32K	device']} />

</Step>

<Step label="4">
### 运行你的应用

在终端中运行以下命令：

<Terminal
  cmd={{
    npm: ['$ npx expo run:android'],
    yarn: ['$ yarn expo run:android'],
    pnpm: ['$ pnpm expo run:android'],
    bun: ['$ bun expo run:android'],
  }}
/>

> 此命令会在构建你的应用后运行一个开发服务器。你可以在下一页跳过运行 `npx expo start`。

</Step>
