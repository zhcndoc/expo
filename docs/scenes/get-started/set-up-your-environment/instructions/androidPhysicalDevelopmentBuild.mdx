import { Step } from '~/ui/components/Step';

import { BuildEnvironmentSwitch } from '../BuildEnvironmentSwitch';

## 使用开发构建设置 Android 设备

<BuildEnvironmentSwitch />

<Step label="1">

### 安装 EAS CLI

要构建你的应用，你需要安装 EAS CLI。你可以通过在终端中运行以下命令来完成：

<Terminal
  cmd={{
    npm: ['$ npm install --global eas-cli'],
    yarn: ['$ yarn global add eas-cli'],
    pnpm: ['$ pnpm add --global eas-cli'],
    bun: ['$ bun add --global eas-cli'],
  }}
/>

</Step>

<Step label="2">

### 创建 Expo 账号并登录

要构建你的应用，你需要创建一个 Expo 账号并登录到 EAS CLI。

1. 为 Expo 账号[注册](https://expo.dev/signup)。
2. 在终端中运行以下命令以登录 EAS CLI：
   <Terminal cmd={['$ eas login']} />

</Step>

<Step label="3">
### 配置你的项目

运行以下命令在你的项目中创建 EAS 配置：

<Terminal cmd={['$ eas build:configure']} />

</Step>

<Step label="4">
### 创建构建

运行以下命令以创建开发构建：

<Terminal cmd={['$ eas build --platform android --profile development']} />
</Step>

<Step label="5">
### 在你的设备上安装开发构建

构建完成后，扫描终端中的二维码或在你的设备上打开链接。点击 **Install** 将构建下载到你的设备，然后点击 **Open** 进行安装。

</Step>
