## 设置模拟器

<Step label="1">
在 Android Studio 主界面上，点击 **More Actions**，然后在下拉菜单中点击 **Virtual Device Manager**。

<ContentSpotlight
  alt="Android Studio 配置。"
  src="/static/images/android-studio/virtual-device.webp"
  className="max-w-[640px]"
/>

</Step>

<Step label="2">

点击 **Create virtual device**。

<ContentSpotlight
  alt="Android Studio 创建虚拟设备。"
  src="/static/images/android-studio/create-device.webp"
  className="max-w-[640px]"
/>

</Step>

<Step label="3">

在 **Add device** 下，选择你想要模拟的硬件类型。我们建议针对多种设备进行测试，不过如果你不确定从哪里开始，Pixel 系列中的最新设备会是一个不错的选择。

<ContentSpotlight
  alt="Android Studio 创建虚拟设备硬件选择。"
  src="/static/images/android-studio/select-hardware.webp"
  className="max-w-[640px]"
/>

</Step>

<Step label="4">

选择要在模拟器上加载的操作系统版本（通常是某个系统映像），并下载该映像（如果需要）。

<ContentSpotlight
  alt="Android Studio 创建虚拟设备操作系统选择。"
  src="/static/images/android-studio/select-os.webp"
  className="max-w-[640px]"
/>

</Step>

<Step label="5">

按需更改其他设置，然后按 **Finish** 创建模拟器。现在，你可以随时在 **Device Manager** 窗口中按下播放按钮来运行此模拟器。

</Step>
