## 使用 Expo Go 设置 iOS 设备

<Step label="1">
### 注册 Apple Developer Program

要在 iOS 设备上安装 Expo Go，你需要订阅 Apple Developer Program。前往[此处注册 Apple Developer Program](https://developer.apple.com/programs/)。

</Step>

<Step label="2">
### 为 iOS 构建 Expo Go

运行以下命令来构建 Expo Go：

<Terminal cmd={['$ npx eas-cli@latest go']} />

</Step>

<Step label="3">
### 安装 TestFlight

下载并安装 [TestFlight 应用](https://apps.apple.com/us/app/testflight/id899247664)。你也可以使用 iOS 设备扫描下方的二维码：

<QRCodeReact value="https://apps.apple.com/us/app/testflight/id899247664" size={228} />

</Step>

<Step label="4">
### 将自己添加为测试人员

1. 前往 [App Store Connect](https://appstoreconnect.apple.com)。
2. 选择 Expo Go 应用。
3. 导航至“TestFlight”标签页。
4. 将你的 Apple ID 邮箱添加为内部测试人员。

完成后，你应该会收到加入 TestFlight 测试版的电子邮件邀请。接受邀请后，你就可以在 iOS 设备上安装 Expo Go。

</Step>

<Step label="5">
### 登录 Expo CLI 和 Expo Go

在实体 iOS 设备上，只有当 Expo CLI 和 Expo Go 登录到同一个 Expo 账户时，Expo Go 才会从开发服务器打开项目。如果你还没有账户，请创建一个免费的 [Expo 账户](https://expo.dev/signup)。

在电脑上登录 Expo CLI：

<Terminal cmd={['$ npx expo login']} />

然后在设备上打开 Expo Go，点按右上角的账户图标，并使用同一个账户登录。如果 Expo Go 显示账户错误，请参阅 [Expo Go 登录要求](/troubleshooting/expo-go-sign-in-required/)。

</Step>
