## 使用开发构建设置 iOS 设备

<BuildEnvironmentSwitch />

<Step label="1">
### 加入 Apple Developer Program

要在 iOS 设备上安装开发构建，你需要拥有有效的 Apple Developer Program 订阅。请在[这里](https://developer.apple.com/programs/)注册 Apple Developer Program。

</Step>

<Step label="2">
### 安装 EAS CLI

要构建你的应用，你需要安装 EAS CLI。你可以在终端中运行以下命令来完成安装：

<Terminal
  cmd={{
    npm: ['$ npm install --global eas-cli'],
    yarn: ['$ yarn global add eas-cli'],
    pnpm: ['$ pnpm add --global eas-cli'],
    bun: ['$ bun add --global eas-cli'],
  }}
/>

</Step>

<Step label="3">

### 创建 Expo 账户并登录

接下来，你需要创建一个 Expo 账户并登录到 EAS CLI。

1. [注册](https://expo.dev/signup)一个 Expo 账户。
2. 在终端中运行以下命令以登录 EAS CLI：
   <Terminal cmd={['$ eas login']} />

</Step>

<Step label="4">
### 配置你的项目

运行以下命令，在你的项目中创建 EAS 配置：

<Terminal cmd={['$ eas build:configure']} />

</Step>

<Step label="5">
### 创建一个 ad hoc provisioning profile

要在 iOS 设备上安装开发构建，你需要创建一个 ad hoc provisioning profile。请在终端中运行以下命令来创建一个：

<Terminal cmd={['$ eas device:create']} />

</Step>

<Step label="6">
### 创建开发构建

运行以下命令来创建开发构建：

<Terminal cmd={['$ eas build --platform ios --profile development']} />

</Step>

<Step label="7">
### 将开发构建安装到你的设备上

构建完成后，扫描终端中的二维码，并在相机应用中出现时点击 **Open with iTunes**。或者，你也可以在设备上打开终端中显示的链接。

确认安装后，该应用将出现在你设备的应用库中。

</Step>

<Step label="8">
### 打开开发者模式

1. 打开 **Settings** > **Privacy & Security**，向下滚动到 **Developer Mode** 列表项并进入。
2. 点击开关以启用 **Developer Mode**。启用后，Settings 会显示一条警告，提示你 Developer Mode 会降低设备的安全性。要继续启用 **Developer Mode**，请点击警告中的 **Restart** 按钮。
3. 设备重启并解锁后，设备会显示一条确认你要启用 Developer Mode 的提示。点击 **Turn On**，并在提示时输入设备密码。

> 或者，如果你在 Mac 上安装了 Xcode，也可以使用它来[启用 iOS 开发者模式](/guides/ios-developer-mode/#connect-an-ios-device-with-a-mac)。

</Step>
