<Step label="1">

### 安装 Xcode

打开 Mac App Store，搜索 [Xcode](https://apps.apple.com/us/app/xcode/id497799835)，然后点击 **安装**（如果你已经安装了，则点击 **更新**）。

</Step>

<Step label="2">

### 安装 Xcode 命令行工具

打开 Xcode，从 Xcode 菜单中选择 **设置...**（或者按 <kbd>cmd ⌘</kbd> + <kbd>,</kbd>）。进入 **Locations**，然后在 **Command Line Tools** 下拉菜单中选择最新版本以安装这些工具。

<ContentSpotlight
  alt="Xcode 偏好设置"
  src="/static/images/ios-simulator/xcode-command-line.webp"
  className="max-w-[580px]"
/>

</Step>

<Step label="3">

### 在 Xcode 中安装 iOS 模拟器

要安装 iOS 模拟器，打开 **Xcode > Settings... > Components**，然后在 **Platform Support > iOS ...** 下点击 **Get**。

</Step>

<Step label="4">

### 安装 Watchman

> **info** 安装 Watchman 仅对 SDK 55 及更早版本的项目是必需的。

[Watchman](https://facebook.github.io/watchman/docs/install#macos) 是一个用于监视文件系统变化的工具。安装它会带来更好的性能。你可以使用以下命令安装：

<Terminal
  cmd={['$ brew update', '$ brew install watchman']}
  cmdCopy="brew update && brew install watchman"
/>

</Step>
