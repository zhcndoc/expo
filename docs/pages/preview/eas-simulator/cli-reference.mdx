`simulator:*` 命令处于实验阶段且默认隐藏。运行这些命令前，请安装或更新 [EAS CLI](/eas/cli/)：

<Terminal cmd={['$ eas simulator:start --help']} />

`--help` 标志会显示 `simulator:start` 的可用选项。

## 命令

| 命令                                               | 用途                                  |
| -------------------------------------------------- | ------------------------------------- |
| [`simulator:availability`](#simulatoravailability) | 检查当前项目的账户是否可以使用 EAS Simulator |
| [`simulator:start`](#simulatorstart)               | 创建会话并等待其控制器配置              |
| [`simulator`](#simulatorstart)                     | `simulator:start` 的别名                |
| [`simulator:exec`](#simulatorexec)                 | 在加载 **.env.eas-simulator** 的情况下运行另一个命令 |
| [`simulator:events`](#simulatorevents)             | 显示已记录的活动，或跟踪运行中会话的活动    |
| [`simulator:get`](#simulatorget)                   | 获取状态、连接详细信息、仪表板 URL、时间戳和构建产物 |
| [`simulator:list`](#simulatorlist)                 | 列出并筛选当前项目的会话                  |
| [`simulator:stop`](#simulatorstop)                 | 停止会话                                  |

## `simulator:availability`

<Terminal cmd={['$ eas simulator:availability --json']} />

`--json` 标志是可选的。它会为代理和自动化工具输出稳定、机器可读的结果；省略该标志则输出适合人类阅读的内容。JSON 对象包含 `available` 和 `accountName`。此命令不会创建会话，也不会消耗模拟器使用额度。

## `simulator:start`

控制器是通过远程设备提供的工具，用于安装、检查和操作应用。启动会话时选择控制器类型：

<Tabs>

<Tab label="agent-device">

使用 [agent-device](/agents/agent-device/) 执行基于无障碍功能的设备操作和应用安装。

<Terminal cmd={['$ eas simulator:start --platform ios --type agent-device --non-interactive']} />

</Tab>

<Tab label="Argent">

使用 [Argent](/agents/argent/) 通过会话运行其远程设备工具。

<Terminal cmd={['$ eas simulator:start --platform ios --type argent --non-interactive']} />

</Tab>

</Tabs>

重要标志：

| 标志                | 描述                                                                                                                                |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `-p, --platform`    | `android` 或 `ios`。在非交互模式下为必需项；在交互式终端中会提示输入                                              |
| `--type`            | 为会话提供的控制器。使用 `agent-device` 或 `argent` 进行程序化控制，或使用 `serve-sim` 进行仅限浏览器的预览 |
| `--package-version` | 控制器软件包版本。默认为服务的最新版本                                                                       |
| `--out-config-type` | `dotenv` 用于写入 **.env.eas-simulator**，或 `env` 用于打印 shell 导出变量                                                                  |
| `--[no-]force`      | 当环境中已存在会话 ID 时，是否创建新会话。默认为 `true`                                    |
| `--non-interactive` | 控制器就绪后返回，而不是保持连接                                                                           |
| `--json`            | 打印机器可读的输出，并隐式启用非交互模式                                                                               |

即使使用 `--json`，默认的 `dotenv` 输出也会写入配置。明确不想写入文件时，请使用 `--out-config-type env`。

常见 JSON 输出字段的格式如下。`remoteConfig` 中的字段取决于所选控制器：

```json
{
  "id": "<会话 ID>",
  "type": "<控制器类型>",
  "deviceRunSessionUrl": "https://expo.dev/accounts/<账户>/projects/<项目>/simulator-sessions/<会话 ID>",
  "remoteConfig": {
    "<控制器特定键>": "<值>"
  }
}
```

请将 `remoteConfig` 视为机密信息，因为其中包含控制器凭据。

### 交互式和非交互式行为

不使用 `--non-interactive` 时，启动命令会保持连接并轮询会话。按一次 Ctrl+C 可停止该命令。EAS CLI 确认会话结束后，会重置 **.env.eas-simulator**。

使用 `--non-interactive` 或 `--json` 时，控制器就绪后命令会返回。你必须单独停止会话。

## `simulator:exec`

`simulator:exec` 与控制器无关。它会从 **.env.eas-simulator** 加载活动会话的连接变量，然后启动后续的命令及参数。

请使用会话启动时所选控制器对应的命令模式：

<Tabs>

<Tab label="agent-device">

<Terminal cmd={['$ eas simulator:exec npx agent-device@latest <command> [args...]']} />

</Tab>

<Tab label="Argent">

<Terminal cmd={['$ eas simulator:exec argent run <tool> [args...]']} />

</Tab>

</Tabs>

`simulator:exec` 不实现设备操作。它只提供活动会话的连接环境，并运行后续的命令。可用的操作和参数语法来自 [agent-device](/agents/agent-device/) 或 [Argent](/agents/argent/)。

## `simulator:events`

显示 **.env.eas-simulator** 所引用会话的活动快照：

<Terminal cmd={['$ eas simulator:events']} />

传入会话 ID 以检查其他会话：

<Terminal cmd={['$ eas simulator:events --id <session-id>']} />

默认的文本输出会将相关操作整合为易读的时间线。其中包括时间戳、控制器、摘要，以及可用时的持续时间。此命令显示来自 agent-device 或 Argent 的会话和控制器活动，而不是应用运行时日志。

在会话运行期间持续查看新活动：

<Terminal cmd={['$ eas simulator:events --follow']} />

`-f` 短标志等同于 `--follow`。会话结束时，命令会停止持续查看。提前停止持续查看，请按 <kbd>Ctrl</kbd> + <kbd>C</kbd>。

对于代理和自动化任务，以 JSON 格式请求原始事件记录：

<Terminal cmd={['$ eas simulator:events --json']} />

JSON 对象包含 `deviceRunSessionId` 和 `events` 数组。常见的事件字段包括 `eventId`、`ts`、`producer`、`type` 和 `summary`，以及可用时的操作 ID、结果、持续时间和控制器特定数据。`--json` 不能与 `--follow` 结合使用。

## `simulator:get`

获取 **.env.eas-simulator** 所引用的会话：

<Terminal cmd={['$ eas simulator:get --json --non-interactive']} />

显式获取另一个会话：

<Terminal cmd={['$ eas simulator:get --id <session-id> --json --non-interactive']} />

响应包括：

- ID、类型、状态和平台
- 创建、启动、完成和更新时间戳
- expo.dev 模拟器会话 URL
- 控制器连接配置
- 会话构件（如果存在）

## `simulator:list`

<Terminal
  cmd={['$ eas simulator:list --platform ios --status in-progress --json --non-interactive']}
/>

筛选条件可以重复使用：

| 筛选条件       | 值                                     |
| ------------ | ------------------------------------------ |
| `--platform` | `ios`、`android`                           |
| `--type`     | `agent-device`、`argent`、`serve-sim`      |
| `--status`   | `new`、`in-progress`、`stopped`、`errored` |

使用 `--limit` 控制页面大小，并将上一响应中的 `endCursor` 与 `--after` 一起使用进行分页。

## `simulator:stop`

停止 **.env.eas-simulator** 所引用的会话：

<Terminal cmd={['$ eas simulator:stop']} />

停止指定的会话：

<Terminal cmd={['$ eas simulator:stop --id <session-id>']} />

停止变更具有幂等性。

## **.env.eas-simulator**

托管文件始终包含会话 ID：

```sh .env.eas-simulator
EAS_SIMULATOR_SESSION_ID="<session-id>"
```

控制器连接变量取决于所选类型：

| 控制器       | 连接变量                                                         |
| ------------ | ---------------------------------------------------------------- |
| agent-device | `AGENT_DEVICE_DAEMON_BASE_URL`、`AGENT_DEVICE_DAEMON_AUTH_TOKEN` |
| Argent       | `ARGENT_TOOLS_URL`，以及在需要时使用的 `ARGENT_AUTH_TOKEN`         |

将该文件添加到 **.gitignore**：

```sh .gitignore
.env.eas-simulator
```

会话运行期间不要修改其中的值。
