以下指南说明如何在现有 React Native 项目中安装和配置 `expo-dev-client`。

<Collapsible summary="你需要创建一个新项目吗？">

如果你是从一个新项目开始，请使用 `with-dev-client` 模板创建它：

<Terminal
  cmd={{
    npm: ['$ npx create-expo-app -e with-dev-client'],
    yarn: ['$ yarn create expo-app -e with-dev-client'],
    pnpm: ['$ pnpm create expo-app -e with-dev-client'],
    bun: ['$ bun create expo -e with-dev-client'],
  }}
/>

</Collapsible>

<Collapsible summary="你的项目中使用 Continuous Native Generation (CNG) 吗？">

要在使用 [CNG](/workflow/continuous-native-generation/) 的项目中使用 `expo-dev-client`，请参阅[创建开发构建](/develop/development-builds/introduction/#how-would-you-like-to-build-your-development-build)。

</Collapsible>

<Prerequisites>
  <Requirement title="安装并配置 expo 包">
    如果你使用 `npx @react-native-community/cli@latest init` 创建了项目，并且没有安装任何其他 Expo 库，那么在继续之前，你需要先[安装 Expo 模块](/bare/installing-expo-modules)。
  </Requirement>
</Prerequisites>

<Step label="1">

## 安装 expo-dev-client

将 `expo-dev-client` 库添加到你的 **package.json** 中：

<Terminal
  cmd={{
    npm: ['$ npx expo install expo-dev-client'],
    yarn: ['$ yarn expo install expo-dev-client'],
    pnpm: ['$ pnpm expo install expo-dev-client'],
    bun: ['$ bun expo install expo-dev-client'],
  }}
/>

如果你的项目磁盘上有一个 **ios** 目录，请运行以下命令以完全安装 `expo-dev-client` 的原生代码：

<Terminal
  cmd={{
    npm: ['$ npx pod-install'],
    yarn: ['$ yarn dlx pod-install'],
    pnpm: ['$ pnpm dlx pod-install'],
    bun: ['$ bunx pod-install'],
  }}
/>

如果你的项目没有 **ios** 目录，则可以跳过这一步。

</Step>

<Step label="2">

## 配置深度链接

Expo CLI 使用深度链接来启动你的项目；如果你计划在项目中添加自定义深度链接 scheme 后，使用 [expo-dev-client 启动预览更新](/eas-update/getting-started/)，这也会很有用。

如果你还没有为应用配置用于支持深度链接的 `scheme`，那么可以使用 `uri-scheme` 库来帮你完成。

<Terminal
  cmd={{
    npm: [
      "# 列出你项目中的 scheme",
      '$ npx uri-scheme list',
      '',
      '# 向你的项目添加一个 scheme',
      '$ npx uri-scheme add your-scheme',
    ],
    yarn: [
      "# 列出你项目中的 scheme",
      '$ yarn dlx uri-scheme list',
      '',
      '# 向你的项目添加一个 scheme',
      '$ yarn dlx uri-scheme add your-scheme',
    ],
    pnpm: [
      "# 列出你项目中的 scheme",
      '$ pnpm dlx uri-scheme list',
      '',
      '# 向你的项目添加一个 scheme',
      '$ pnpm dlx uri-scheme add your-scheme',
    ],
    bun: [
      "# 列出你项目中的 scheme",
      '$ bunx uri-scheme list',
      '',
      '# 向你的项目添加一个 scheme',
      '$ bunx uri-scheme add your-scheme',
    ],
  }}
/>

有关更多信息，请参阅 [`uri-scheme` 库](https://www.npmjs.com/package/uri-scheme)。

</Step>

<Step label="3">

## 构建并安装应用

使用你选择的工具创建应用的调试构建。例如，你可以[使用 Expo CLI 在本地完成](/guides/local-app-development/)，也可以[使用 EAS Build 在云端完成](/develop/development-builds/introduction/?buildenv=build-with-eas#how-would-you-like-to-build-your-development-build)。

</Step>
