> **重要** [`@expo/ui` 提供了一个可直接替代的实现](./ui/drop-in-replacements/segmentedcontrol)，用于替代 `@react-native-segmented-control/segmented-control`，在 Android 上由 Jetpack Compose 提供支持，在 iOS 上由 SwiftUI 提供支持。

它有点像一个花哨的单选按钮，或者用 Apple 的话说：“一种由多个分段组成的水平控件，每个分段都作为一个独立按钮发挥作用”（[来源](https://developer.apple.com/documentation/uikit/uisegmentedcontrol)）。这个组件在 iOS 上会渲染为 [`UISegmentedControl`](https://developer.apple.com/documentation/uikit/uisegmentedcontrol)，而在 Android 和 web 上则会忠实地重现该控件（因为这些平台的标准库中没有等效实现）。
