`expo-observe` 是一个用于收集应用性能指标，并将其发送到 [EAS Observe](/eas/observe/introduction/)（Expo 提供的性能监控服务）或你首选的、符合 OpenTelemetry（OTEL）标准的后端的库。它可以测量在生产环境中运行的应用的实际启动性能，例如[首次渲染时间（TTR）](/eas/observe/reference/metrics/#time-to-first-render-ttr)和[可交互时间（TTI）](/eas/observe/reference/metrics/#time-to-interactive-tti)。

> **warning** `expo-observe` 在 Expo Go 中不可用。要使用它，请创建一个[开发构建](/develop/development-builds/introduction/)。

## 配置

在发布构建中，只需安装 `expo-observe` 库，即可配置该库开始发送启动指标（不过，你需要按照以下用法说明调用 `AppMetrics.markInteractive` 来追踪 TTI）。该库不会在调试构建中发送事件，但你可以通过调用 `AppMetrics.configure({})` 更改此设置及其他配置选项，例如采样率和环境名称。所有可用选项，请参阅 [EAS Observe 配置指南](/eas/observe/configuration/)。

## 用法

在 SDK 55 中，使用 `AppMetricsRoot` 包装根布局，即可自动测量首次渲染时间。然后，在应用准备好接受用户交互时调用 `AppMetrics.markInteractive`，以记录可交互时间：

```tsx src/app/_layout.tsx
import { AppMetrics, AppMetricsRoot } from 'expo-observe';
import { Stack } from 'expo-router';
import { useEffect } from 'react';

function RootLayout() {
  useEffect(() => {
    // Replace this effect with your own readiness signal: only call
    // markInteractive() after initialization work behind the splash screen
    // (such as loading initial data) completes.
    AppMetrics.markInteractive();
  }, []);

  return <Stack />;
}

export default AppMetricsRoot.wrap(RootLayout);
```

有关分步说明，包括完整的启动屏幕示例以及如何处理具有多个入口屏幕的应用，请参阅 [EAS Observe 入门指南](/eas/observe/get-started/)。

> **info** [用户自定义事件](/eas/observe/events/)和[导航集成](/eas/observe/integrations/expo-router/)需要使用 SDK 56 或更高版本。
