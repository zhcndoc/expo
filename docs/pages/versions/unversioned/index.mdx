Expo SDK 是一组用于访问设备和系统功能的软件包，例如相机、联系人、位置、传感器、触觉反馈等。每个软件包专用于某项功能，并且可以独立使用。只要安装了 `expo` 软件包，所有软件包都可以在任何 React Native 应用中运行。

您可以使用 [`npx expo install`](/more/expo-cli/#install) 命令安装任意 Expo SDK 软件包。例如，您可以使用以下命令安装三个不同的软件包：

<Terminal
  cmd={{
    npm: ['$ npx expo install expo-camera expo-contacts expo-sensors'],
    yarn: ['$ yarn expo install expo-camera expo-contacts expo-sensors'],
    pnpm: ['$ pnpm expo install expo-camera expo-contacts expo-sensors'],
    bun: ['$ bun expo install expo-camera expo-contacts expo-sensors'],
  }}
/>

安装一个或多个软件包后，您可以将它们导入 JavaScript 代码中：

```ts
import { CameraView } from 'expo-camera';
import { Contact } from 'expo-contacts';
import { Gyroscope } from 'expo-sensors';
```

这样，您就可以编写 [`Contact.getAll()`](./sdk/contacts#getalloptions) 来读取设备中的联系人，读取陀螺仪传感器以检测设备移动，或启动手机相机并拍摄照片。

## 所有 Expo SDK 包都可在任何 React Native 应用中使用

Expo 应用本身就是 React Native 应用，因此只要安装并配置了 `expo` 包，所有 Expo SDK 包都可以在任何 React Native 应用中使用。创建支持 Expo SDK 包的 React Native 应用最简单的方法是使用 `create-expo-app`。不过，你也可以使用 `npx install-expo-modules` 命令为现有的 React Native 应用添加 Expo SDK 支持。

<Terminal
  cmd={{
    npm: [
      '# 创建一个名为 my-app 的项目',
      '$ npx create-expo-app my-app --template bare-minimum',
    ],
    yarn: [
      '# 创建一个名为 my-app 的项目',
      '$ yarn create expo-app my-app --template bare-minimum',
    ],
    pnpm: [
      '# 创建一个名为 my-app 的项目',
      '$ pnpm create expo-app my-app --template bare-minimum',
    ],
    bun: ['# 创建一个名为 my-app 的项目', '$ bun create expo my-app --template bare-minimum'],
  }}
/>

## 使用预发布版本

新的 Expo SDK 版本每年发布三次。在这些发布之间，我们会发布 `expo` 包以及所有 Expo SDK 包的预发布版本。预发布版本不被视为稳定版本，只有在你能够接受遇到 bug 或其他问题风险时才应使用。

### 金丝雀版本

金丝雀发布代表了它们发布时 `main` 分支状态的一个快照。金丝雀包版本的名称中包含 `-canary`，并带有日期和提交哈希，例如 `56.0.0-canary-20260506-03817f5`。要安装最新的金丝雀版本：

<Terminal
  cmd={{
    npm: [
      '# 安装 expo 及其相关包的金丝雀版本',
      '$ npm install expo@canary && npx expo install --fix',
    ],
    yarn: [
      '# 安装 expo 及其相关包的金丝雀版本',
      '$ yarn add expo@canary && yarn expo install --fix',
    ],
    pnpm: [
      '# 安装 expo 及其相关包的金丝雀版本',
      '$ pnpm add expo@canary && pnpm expo install --fix',
    ],
    bun: [
      '# 安装 expo 及其相关包的金丝雀版本',
      '$ bun add expo@canary && bun expo install --fix',
    ],
  }}
/>

你通常可以在 Expo SDK 的稳定版本中使用单个包的预发布版本。金丝雀质量的发布有时可能会出现不兼容或其他问题。如果你选择使用金丝雀包，并且已经验证它适用于你的使用场景，你可能希望[关闭依赖验证警告](/more/expo-cli/#configuring-dependency-validation)。

### Beta 版本

在每个 Expo SDK 版本发布之前，我们会发布 `expo` 包以及所有 Expo SDK 包的 beta 版本。Beta 版本被认为比金丝雀版本稳定得多，我们鼓励开发者在他们的应用中尝试并分享反馈。Beta 版本在 npm 上使用 `beta` 标签，并遵循相关 [更新日志](https://expo.dev/changelog) 帖子中的说明。

### 其他信息

<Collapsible summary="用于跟踪 React Native 发布的 Expo SDK 政策">

- 每个 Expo SDK 版本都面向单一的 React Native 版本。通常这就是发布时的最新稳定版。
- React Native 目前每年发布六个版本，并且目标是让每个版本都不包含破坏性变更。
- Expo SDK 的发布旨在遵循这一节奏。
- 即将发布的 Expo SDK 预发布版本会很快支持最新的 React Native 版本，通常在其发布的当天就会支持。Expo SDK 团队的一名成员会参与每次 React Native 发布团队的工作，负责持续更新 Expo 仓库中的 React Native 版本、验证兼容性，并将回归问题反馈给 React Native 团队。

</Collapsible>

<Collapsible summary="如果我需要最新 React Native 版本中的某个改动，但它还没有出现在 Expo SDK 发布版中，该怎么办？">
Expo 在 React Native 发布团队中的工程师会确保任何紧急修复都包含在最新 Expo SDK 所使用的 React Native 版本中。如果你的特定修复不会被 cherry-pick 到现有版本中，可能是因为它不被视为关键修复，或者因为它涉及破坏性变更，那么你有两个选择：

1. 使用 [`patch-package`](https://github.com/ds300/patch-package) 来引入该修复。
2. 使用 [Expo SDK 的预发布版本](#using-pre-release-versions)。

</Collapsible>

<Collapsible summary="我可以在最新的 Expo SDK 中使用较旧版本的 React Native 吗？">

Expo SDK 中的包旨在支持该 SDK 所对应的 React Native 版本。通常，它们不支持较旧版本的 React Native，但也可能支持。当 React Native 发布新版本时，Expo SDK 包的最新版本通常会更新以支持它。不过，这可能需要几周甚至更久，具体取决于该版本中变更的范围。

</Collapsible>

## 支持的 Android 和 iOS 版本

每个 Expo SDK 版本都支持特定的 Android 和 iOS 操作系统最低版本。对于 Android，会定义 `compileSdkVersion`，用于告知 [Gradle](https://developer.android.com/studio/build) 编译应用时使用哪个 Android SDK 版本。这也意味着你可以使用该 SDK 版本及更早版本中包含的 Android API 功能。对于 iOS，[Xcode](https://developer.apple.com/news/upcoming-requirements/) 会指示编译应用时使用的最低 Xcode SDK 版本。

在决定是否升级 Expo SDK 版本时，也请考虑 Expo 的 SDK 版本和应用商店提交要求，如上表所述。Google Play 商店和 Apple App Store 会定期提高新应用提交所需的最低操作系统版本和 API 级别。Expo 无法控制应用商店的要求，你应查看 [Google](https://developer.android.com/studio/build) 和 [Apple](https://developer.apple.com/news/upcoming-requirements/) 以了解当前的商店提交要求。
