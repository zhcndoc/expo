> **重要** [`@expo/ui` provides a drop-in replacement](./ui/drop-in-replacements/segmentedcontrol) for `@react-native-segmented-control/segmented-control`, powered by Jetpack Compose on Android and SwiftUI on iOS.

它就像一个花哨的单选按钮，或者用苹果的话说：“一种由多个段组成的水平控件，每个段都可作为一个独立按钮使用”（[来源](https://developer.apple.com/documentation/uikit/uisegmentedcontrol)）。这个组件在 iOS 上会渲染为 [`UISegmentedControl`](https://developer.apple.com/documentation/uikit/uisegmentedcontrol)，在 Android 和 web 上则会渲染为对该控件的忠实复刻（因为这些平台的标准库中没有对应的控件）。
