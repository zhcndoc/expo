`@expo/ui` 中的通用组件是在各平台原生 UI 工具包之上的单一 API 层。在 Android 上，它们会委托给 [`@expo/ui/jetpack-compose`](../jetpack-compose)。在 iOS 上，它们会委托给 [`@expo/ui/swift-ui`](../swift-ui)。在 web 上，它们是使用 `react-dom` 或 `react-native-web` 的 JS 实现，并且会根据具体组件选择最适合该控件的实现。

## 用法

通用组件仍然必须包裹在一个 [`Host`](host) 中，但你可以从包的根入口导入所有内容，包括 `Host`。通用的 `Host` 会在 Android 和 iOS 上分发到平台原生的 host，因此无需直接使用 [`@expo/ui/swift-ui`](../swift-ui) 或 [`@expo/ui/jetpack-compose`](../jetpack-compose)。

```tsx UniversalExample.tsx
import { Host, Column, Button, Text } from '@expo/ui';

export default function Example() {
  return (
    <Host style={{ flex: 1 }}>
      <Column spacing={12} alignment="center">
        <Text>Hello, world!</Text>
        <Button label="按我" onPress={() => alert('Pressed')} />
      </Column>
    </Host>
  );
}
```

## 可用组件

| 类别                        | 组件                                                                                                                         |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| 容器                       | [`Host`](host)，每个通用子树所需的根。                                                                   |
| 布局                       | [`Column`](column)、[`Row`](row)、[`Spacer`](spacer)、[`ScrollView`](scrollview)                                                 |
| 显示                       | [`Text`](text)、[`Icon`](icon)                                                                                                   |
| 控件                       | [`Button`](button)、[`Switch`](switch)、[`Checkbox`](checkbox)、[`Slider`](slider)、[`TextInput`](textinput)、[`Picker`](picker) |
| 披露和展示                 | [`BottomSheet`](bottomsheet)、[`Collapsible`](collapsible)                                                                       |
| 集合和表单                 | [`List`](list)（包含 `ListItem`）、[`FieldGroup`](fieldgroup)                                                                     |

## 何时使用这个而不是 `jetpack-compose`/`swift-ui`

- 当你希望一个组件树无需修改即可在 Android、iOS 和 web 上运行时，请选择 **universal** 组件。由于这些组件在底层委托给 Jetpack Compose/SwiftUI，因此在 Android 和 iOS 上会保留平台原生的外观和体验。
- 当你需要 universal API 未提供的平台特定控件、修饰符或行为时，请直接选择 **[`@expo/ui/jetpack-compose`](../jetpack-compose)** 或 **[`@expo/ui/swift-ui`](../swift-ui)**。
