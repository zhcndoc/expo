一种布局间隔组件，用于在 [`Row`](row) 或 [`Column`](column) 内的兄弟元素之间产生空白。使用 [`size`](#size) 创建固定间距，或使用 [`flexible`](#flexible) 填充剩余的主轴空间。

### 固定大小的间隔

<ComponentExample
  title="FixedSpacerExample.tsx"
  android={{

```tsx
import { useColorScheme } from 'react-native';
import { Host, Column, Text, Spacer } from '@expo/ui';

export default function FixedSpacerExample() {
  const colorScheme = useColorScheme();
  const ink = { color: colorScheme === 'dark' ? '#FFFFFF' : '#000000' };

  return (
    <Host matchContents>
      <Column>
        <Text textStyle={ink}>Top</Text>
        <Spacer size={32} />
        <Text textStyle={ink}>Bottom</Text>
      </Column>
    </Host>
  );
}
```

</ComponentExample>

### 可伸缩间隔

可伸缩间隔会填充其父元素主轴方向上的剩余空间，将周围内容推到两端。

<ComponentExample
  title="FlexibleSpacerExample.tsx"
  android={{
    src: '/static/images/expo-ui/examples/universal-spacer-flexible-android-light.webp',
    darkSrc: '/static/images/expo-ui/examples/universal-spacer-flexible-android-dark.webp',
    alt: 'Leading and trailing labels pushed to opposite edges',
  }}
  ios={{
    src: '/static/images/expo-ui/examples/universal-spacer-flexible-ios-light.webp',
    darkSrc: '/static/images/expo-ui/examples/universal-spacer-flexible-ios-dark.webp',
    alt: 'Leading and trailing labels pushed to opposite edges',
  }}>

```tsx
import { useColorScheme } from 'react-native';
import { Host, Row, Text, Spacer } from '@expo/ui';

export default function FlexibleSpacerExample() {
  const colorScheme = useColorScheme();
  const ink = { color: colorScheme === 'dark' ? '#FFFFFF' : '#000000' };

  return (
    <Host matchContents={{ vertical: true }} style={{ width: '100%' }}>
      <Row>
        <Text textStyle={ink}>Leading</Text>
        <Spacer flexible />
        <Text textStyle={ink}>Trailing</Text>
      </Row>
    </Host>
  );
}
```

</ComponentExample>
