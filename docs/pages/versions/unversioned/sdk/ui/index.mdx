`@expo/ui` 是一组原生输入组件，可让你使用 Jetpack Compose 和 SwiftUI 构建完全原生的界面。它旨在提供典型应用所需的常用功能和组件。

## 功能

- **原生基础组件**：Expo UI 不是另一个 UI 库，而是将 Jetpack Compose 和 SwiftUI 基础组件引入 React Native。
- **一对一映射**：组件与其对应的原生组件一一对应。若要浏览 Jetpack Compose 和 SwiftUI 组件目录，请参见下文的[可用组件](#available-components)。
- **完整应用支持**：Expo UI 在组件层级进行集成。你可以使用它编写整个应用，也可以一次采用一个屏幕。你还可以混用 [React Native 组件](https://reactnative.dev/docs/components-and-apis)、[DOM 组件](/guides/dom-components/)和使用 [`react-native-skia`](https://shopify.github.io/react-native-skia/) 绘制的 2D 组件。

## 可用平台

组件适用于以下平台：

- **[Jetpack Compose](jetpack-compose)**：使用 Jetpack Compose 组件构建原生 Android 界面
- **[SwiftUI](swift-ui)**：使用 SwiftUI 组件构建原生 iOS 界面
- **[通用](universal)**：使用单一代码源构建可在 Android、iOS 和 Web 上运行的跨平台组件

如果你想让同一个组件树无需修改就能在 Android、iOS 和 Web 上运行，请从 **[通用](universal)** 开始。如果你需要通用 API 未涵盖的平台专属控件、修饰符或行为，请直接使用 **[Jetpack Compose](jetpack-compose)** 或 **[SwiftUI](swift-ui)**。

## 常见问题

<FAQ>

<Collapsible summary="我可以在 Expo UI 组件中使用 flexbox 或其他样式吗？">

Flexbox 样式适用于 `Host` 组件本身。进入原生上下文后，便无法使用 [`Yoga`](https://www.yogalayout.dev/)。在 Android 上使用 `Row` 和 `Column` 定义布局，在 iOS 上使用 `HStack` 和 `VStack`。

</Collapsible>

<Collapsible summary={<>什么是 <CODE>Host</CODE> 组件？</>}>

`Host` 是 React Native 与原生 UI 工具包之间的桥梁。每个 Expo UI 组件都必须由它包裹。你可以把它想象成 DOM 中的 [`<svg>`](https://developer.mozilla.org/en-US/docs/Web/SVG/Reference/Element/svg)，或者 [`react-native-skia`](https://shopify.github.io/react-native-skia/) 中的 [`<Canvas>`](https://shopify.github.io/react-native-skia/docs/canvas/overview/)。在 iOS 上，它使用 [`UIHostingController`](https://developer.apple.com/documentation/swiftui/uihostingcontroller) 在 UIKit 中渲染 SwiftUI 视图。有关跨平台用法，请参见通用版 [`Host`](universal/host)。

</Collapsible>

<Collapsible summary={<>Expo UI 与 <CODE>react-native-paper</CODE> 或 <CODE>react-native-elements</CODE> 之类的库有何不同？</>}>

Expo UI 不是“又一个”UI 库，也不是带有特定设计理念的设计套件。相反，它是一个基础组件库。它直接向 JavaScript 暴露原生 Jetpack Compose 和 SwiftUI 组件，而不是用 JavaScript 重新实现或模拟 UI。

</Collapsible>

<Collapsible summary={<>我可以在 Android 或 Web 上使用 <CODE>@expo/ui/swift-ui</CODE> 吗？</>}>

不可以。`@expo/ui/swift-ui` 渲染 SwiftUI 视图，而 SwiftUI 仅适用于 Apple 平台。Android 请使用 [`@expo/ui/jetpack-compose`](jetpack-compose)。如果你想要一个适用于 Android、iOS 和 Web 的组件树，请使用[通用组件](universal)。

</Collapsible>

<Collapsible summary="我可以在 SwiftUI 组件中使用 React Native 组件吗？">

可以，你可以将 React Native 组件作为 JSX 子元素放入 Expo UI 组件中。Expo UI 会自动为你创建 [`UIViewRepresentable`](https://developer.apple.com/documentation/swiftui/uiviewrepresentable) 包装器。
不过请注意，SwiftUI 布局系统的工作方式与 UIKit 不同，且存在一些限制。根据 Apple 的文档：

> **警告** SwiftUI 完全控制 UIKit 视图的 [`center`](https://developer.apple.com/documentation/UIKit/UIView/center)、[`bounds`](https://developer.apple.com/documentation/UIKit/UIView/bounds)、[`frame`](https://developer.apple.com/documentation/UIKit/UIView/frame) 和 [`transform`](https://developer.apple.com/documentation/UIKit/UIView/transform) 属性。请勿在自己的代码中直接设置由 [`UIViewRepresentable`](https://developer.apple.com/documentation/swiftui/uiviewrepresentable) 实例管理的视图上的这些布局相关属性，因为这会与 SwiftUI 冲突，并导致未定义行为。

另请注意，渲染 React Native 组件后，你就离开了 SwiftUI 上下文。若要再次添加 Expo UI 组件，请重新引入 `Host` 包装器。

请保持 SwiftUI 布局独立。虽然可以进行互操作，但明确划分边界时效果最佳。

</Collapsible>

<Collapsible summary="我是 Jetpack Compose 或 SwiftUI 开发者。为什么要学习 Expo UI？">

React 所倡导的“学一次，到处编写”如今也适用于 Jetpack Compose 和 SwiftUI。你可以运用现有知识，在 React Native 生态系统中构建应用。同一个应用还可以通过 [DOM 组件](/guides/dom-components/)扩展到 Web，并使用 [`react-native-skia`](https://shopify.github.io/react-native-skia/) 添加 2D 渲染，或使用 [`react-native-webgpu`](https://github.com/wcandillon/react-native-webgpu) 添加 3D 渲染。应用的不同部分可以采用不同方式，因为集成是在组件层级进行的。

</Collapsible>

</FAQ>
