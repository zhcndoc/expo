## 用法

### 基础懒加载行

[`LazyRow`](#lazyrow) 的每个子项都是一个项目。使用 `horizontalArrangement` 属性设置项目之间的间距，使用 `contentPadding` 属性为列表内容添加内边距。

<ComponentExample
  title="BasicLazyRow.tsx"
  src="/static/images/expo-ui/examples/lazyrow-static-android-light.webp"
  darkSrc="/static/images/expo-ui/examples/lazyrow-static-android-dark.webp"
  alt="一行水平排列的三个带边框项目，彼此之间有小间距">

```tsx
import {
  Host,
  LazyRow,
  Text,
  useMaterialColors,
} from '@expo/ui/jetpack-compose';
import {
  border,
  padding,
} from '@expo/ui/jetpack-compose/modifiers';

export default function BasicLazyRow() {
  const colors = useMaterialColors();

  return (
    <Host style={{ height: 100 }}>
      <LazyRow
        horizontalArrangement={{ spacedBy: 8 }}
        verticalAlignment="center">
        <Text
          style={{ fontSize: 28 }}
          color={colors.onBackground}
          modifiers={[
            border(1, colors.outline),
            padding(12, 6, 12, 6),
          ]}>
          Photos
        </Text>
        <Text
          style={{ fontSize: 28 }}
          color={colors.onBackground}
          modifiers={[
            border(1, colors.outline),
            padding(12, 6, 12, 6),
          ]}>
          Music
        </Text>
        <Text
          style={{ fontSize: 28 }}
          color={colors.onBackground}
          modifiers={[
            border(1, colors.outline),
            padding(12, 6, 12, 6),
          ]}>
          Videos
        </Text>
      </LazyRow>
    </Host>
  );
}
```

### 大型列表

使用 [`LazyRow.Items`](#lazyitems) 从数组渲染项目。将项目作为 `data` 传入，使用 `keyExtractor` 为每个项目提供唯一键，并传入一个返回项目视图的 `children` 函数。`LazyRow.Items` 只渲染可见区域附近的项目，并在滚动时复用这些项目。

<ComponentExample
  title="LargeLazyRow.tsx"
  src="/static/images/expo-ui/examples/lazyrow-large-android-light.webp"
  darkSrc="/static/images/expo-ui/examples/lazyrow-large-android-dark.webp"
  alt="一行带边框的项目，滚动后会移出屏幕右侧">

```tsx
import {
  Host,
  LazyRow,
  Text,
  useMaterialColors,
} from '@expo/ui/jetpack-compose';
import {
  border,
  padding,
} from '@expo/ui/jetpack-compose/modifiers';

const items = Array.from(
  { length: 10000 },
  (_, i) => `Item ${i + 1}`
);

function Chip({ label }: { label: string }) {
  const colors = useMaterialColors();

  return (
    <Text
      style={{ fontSize: 28 }}
      color={colors.onBackground}
      modifiers={[
        border(1, colors.outline),
        padding(12, 6, 12, 6),
      ]}>
      {label}
    </Text>
  );
}

function renderItem({ item }: { item: string }) {
  return <Chip label={item} />;
}

export default function LargeLazyRow() {
  return (
    <Host style={{ height: 100 }}>
      <LazyRow
        horizontalArrangement={{ spacedBy: 8 }}
        verticalAlignment="center">
        <LazyRow.Items
          data={items}
          keyExtractor={item => item}
          estimatedItemSize={120}>
          {renderItem}
        </LazyRow.Items>
      </LazyRow>
    </Host>
  );
}
```

</ComponentExample>

渲染项目时请遵循以下规则：

- 为 `LazyRow` 设置固定高度。尚未准备好的项目会显示填满行高的空占位符。
- 在组件外定义 `children` 函数，或使用 `useCallback` 包装它。否则，每次组件渲染时，可见区域附近的项目都会重新渲染。
- 复用的视图会保留之前显示项目的本地状态（`useState`）。项目变化时重置状态，或将状态保存在视图外部。
- 将 `estimatedItemSize` 设置为接近项目宽度的值，单位为密度无关像素（dp）。
- 使用 `overscanCount` 在可见项目前后预先准备更多项目。
- 要更新项目，请传入新的 `data` 数组。不要原地修改数组。
- 设置 `recycling={false}` 可预先渲染每个项目。
