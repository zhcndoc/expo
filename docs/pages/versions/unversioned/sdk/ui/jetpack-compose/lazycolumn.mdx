## 用法

### 基础懒加载列

[`LazyColumn`](#lazycolumn) 的每个子项都是一行。使用 `verticalArrangement` 属性设置行间距，使用 `contentPadding` 属性为列表内容添加内边距。

<ComponentExample
  title="BasicLazyColumn.tsx"
  src="/static/images/expo-ui/examples/lazycolumn-static-android-light.webp"
  darkSrc="/static/images/expo-ui/examples/lazycolumn-static-android-dark.webp"
  alt="包含三个设置行的列表，每行都有标题和描述">

```tsx
import {
  Host,
  LazyColumn,
  ListItem,
  Text,
} from '@expo/ui/jetpack-compose';

export default function BasicLazyColumn() {
  return (
    <Host style={{ height: 400 }}>
      <LazyColumn verticalArrangement={{ spacedBy: 8 }}>
        <ListItem>
          <ListItem.HeadlineContent>
            <Text>Wi-Fi</Text>
          </ListItem.HeadlineContent>
          <ListItem.SupportingContent>
            <Text>Connected to Home</Text>
          </ListItem.SupportingContent>
        </ListItem>
        <ListItem>
          <ListItem.HeadlineContent>
            <Text>Bluetooth</Text>
          </ListItem.HeadlineContent>
          <ListItem.SupportingContent>
            <Text>On</Text>
          </ListItem.SupportingContent>
        </ListItem>
        <ListItem>
          <ListItem.HeadlineContent>
            <Text>Notifications</Text>
          </ListItem.HeadlineContent>
          <ListItem.SupportingContent>
            <Text>Allowed for all apps</Text>
          </ListItem.SupportingContent>
        </ListItem>
      </LazyColumn>
    </Host>
  );
}
```

</ComponentExample>

### 大型列表

使用 [`LazyColumn.Items`](#lazyitems) 从数组渲染行。将项目作为 `data` 传入，使用 `keyExtractor` 为每个项目提供唯一键，并传入一个返回项目行的 `children` 函数。`LazyColumn.Items` 只渲染可见区域附近的行，并在滚动时复用它们。

<ComponentExample
  title="LargeLazyColumn.tsx"
  src="/static/images/expo-ui/examples/lazycolumn-large-android-light.webp"
  darkSrc="/static/images/expo-ui/examples/lazycolumn-large-android-dark.webp"
  alt="显示一万个联系人中前七个的可滚动列表">

```tsx
import {
  Host,
  LazyColumn,
  ListItem,
  Text,
} from '@expo/ui/jetpack-compose';

type Contact = { id: string; name: string };

const contacts: Contact[] = Array.from(
  { length: 10000 },
  (_, i) => ({
    id: String(i),
    name: `Contact ${i + 1}`,
  })
);

function renderContact({ item }: { item: Contact }) {
  return (
    <ListItem>
      <ListItem.HeadlineContent>
        <Text>{item.name}</Text>
      </ListItem.HeadlineContent>
    </ListItem>
  );
}

export default function LargeLazyColumn() {
  return (
    <Host style={{ height: 400 }}>
      <LazyColumn>
        <LazyColumn.Items
          data={contacts}
          keyExtractor={contact => contact.id}>
          {renderContact}
        </LazyColumn.Items>
      </LazyColumn>
    </Host>
  );
}
```

</ComponentExample>

渲染行时请遵循以下规则：

- 将 `children` 函数定义在组件外部，或使用 `useCallback` 包装它。否则，每次组件渲染时，可见区域附近的行都会再次渲染。
- 复用的行会保留它之前显示的项目的本地状态（`useState`）。当项目变化时重置状态，或将状态保留在行视图之外。
- 尚未准备好的行会显示填充行高的空占位符。将 `estimatedItemSize` 设置为接近行高的值，单位为与密度无关的像素（dp）。
- 使用 `overscanCount` 在可见行的上方和下方预先准备更多行。
- 要更新行，请传入新的 `data` 数组。不要原地修改数组。
- 设置 `recycling={false}` 可预先渲染所有行。
