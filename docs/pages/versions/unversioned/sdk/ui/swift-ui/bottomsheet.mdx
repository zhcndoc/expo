## 使用

### 基本底部弹窗

将打开弹窗的控件作为 `anchor` 属性传入。子元素是弹窗的内容。

<ComponentExample
  title="BasicBottomSheetExample.tsx"
  src="/static/images/expo-ui/examples/bottomsheet-basic-ios-light.webp"
  darkSrc="/static/images/expo-ui/examples/bottomsheet-basic-ios-dark.webp"
  alt="一个占满屏幕的底部弹窗，中央显示文本 Hello, world!">

```tsx
import { useState } from 'react';
import {
  Host,
  BottomSheet,
  Button,
  Text,
  VStack,
} from '@expo/ui/swift-ui';

export default function BasicBottomSheetExample() {
  const [isPresented, setIsPresented] = useState(false);

  return (
    <Host style={{ flex: 1 }}>
      <VStack>
        <BottomSheet
          isPresented={isPresented}
          onIsPresentedChange={setIsPresented}
          anchor={
            <Button
              label="Open sheet"
              onPress={() => setIsPresented(true)}
            />
          }>
          <Text>Hello, world!</Text>
        </BottomSheet>
      </VStack>
    </Host>
  );
}
```

</ComponentExample>

### 自定义背景

默认情况下，弹窗使用系统的半透明材质背景（iOS 26 上为 Liquid Glass）。使用 `Group` 上的 [`presentationBackground`](modifiers/#presentationbackgroundstyle) 修饰符自行绘制弹窗背景，这也会使弹窗不再使用该半透明材质。它接受任何 `ShapeStyle`：纯色、材质或渐变。

> **info** 在 iOS 26 上，材质（例如 `{ type: 'material', material: 'ultraThin' }`）会渲染为纯色，而不是半透明模糊效果。请选择一种在不透明状态下也清晰易辨的背景。

> **info** 优先使用 `presentationBackground`，而不是在 sheet 内容上使用 `background` 修饰符。`background` 位于内容自身背景的 _后面_，因此 `Form` 或 `List` 会将其遮住，并且当 sheet 在不同 detent 之间移动时，颜色显示会不一致。`presentationBackground` 会给 sheet 表面本身着色，因此在每个 detent 下都保持一致。当内容是 `Form` 或 `List` 时，也请添加 [`scrollContentBackground('hidden')`](modifiers/#scrollcontentbackgroundvisible)，这样 sheet 颜色就能透过分组背景显示出来。

### 带有停靠位置的底部弹窗

在 `Group` 上使用 [`presentationDetents`](modifiers/#presentationdetentsdetents-options) 修饰器来控制可用高度。你可以使用：

- `'medium'`：系统中等高度（大约半屏）
- `'large'`：系统大高度（全屏）
- `{ fraction: number }`：屏幕高度的比例（0-1）
- `{ height: number }`：以点为单位的固定高度

<ComponentExample
  title="BottomSheetWithDetentsExample.tsx"

  darkSrc="/static/images/expo-ui/examples/bottomsheet-detents-ios-dark.webp"

```tsx
import { useState } from 'react';
import {
  Host,
  BottomSheet,
  Button,
  Group,
  Text,
  VStack,
} from '@expo/ui/swift-ui';
import { presentationDetents } from '@expo/ui/swift-ui/modifiers';

export default function BottomSheetWithDetentsExample() {
  const [isPresented, setIsPresented] = useState(false);

  return (
    <Host style={{ flex: 1 }}>
      <VStack>
        <BottomSheet
          isPresented={isPresented}
          onIsPresentedChange={setIsPresented}
          anchor={
            <Button
              label="Open sheet"
              onPress={() => setIsPresented(true)}
            />

          <Group
            modifiers={[
              presentationDetents([
                'medium',
                'large',
                { fraction: 0.3 },
                { height: 200 },
              ]),
            ]}>
            <Text>此弹窗可以停靠到多个高度。</Text>
          </Group>
        </BottomSheet>
      </VStack>
    </Host>
  );
}
```

</ComponentExample>

### 跟踪停靠位置选择的底部弹窗

将 `selection` 和 `onSelectionChange` 选项传递给 [`presentationDetents`](modifiers/#presentationdetentsdetents-options)，即可通过编程方式控制弹窗停靠到哪个停靠位置。

<ComponentExample
  title="BottomSheetWithDetentSelectionExample.tsx"
  src="/static/images/expo-ui/examples/bottomsheet-detent-selection-ios-light.webp"
  darkSrc="/static/images/expo-ui/examples/bottomsheet-detent-selection-ios-dark.webp"
  alt="一个列出停靠位置选项的底部弹窗，当前停靠位置显示为 medium">

```tsx
import { useState } from 'react';
import {
  Host,
  BottomSheet,
  Button,
  List,
  Section,
  Text,
  VStack,
  Group,
} from '@expo/ui/swift-ui';
import {
  presentationDetents,
  presentationDragIndicator,
  foregroundStyle,
} from '@expo/ui/swift-ui/modifiers';
import type { PresentationDetent } from '@expo/ui/swift-ui/modifiers';

export default function BottomSheetWithDetentSelectionExample() {
  const [isPresented, setIsPresented] = useState(false);
  const detents: PresentationDetent[] = [
    { height: 300 },
    { fraction: 0.3 },
    'medium',
    'large',
  ];
  const [selectedDetent, setSelectedDetent] =
    useState<PresentationDetent>('medium');

  const formatDetent = (detent: PresentationDetent): string => {
    if (typeof detent === 'string') return detent;
    if ('fraction' in detent) return `比例 ${detent.fraction}`;
    return `高度 ${detent.height}`;
  };

  return (
    <Host style={{ flex: 1 }}>
      <VStack>
        <BottomSheet
          isPresented={isPresented}
          onIsPresentedChange={setIsPresented}
          anchor={
            <Button
              label="Show sheet"
              onPress={() => setIsPresented(true)}
            />
          }>
          <Group
            modifiers={[
              presentationDetents(detents, {
                selection: selectedDetent,
                onSelectionChange: setSelectedDetent,
              }),
              presentationDragIndicator('visible'),
            ]}>
            <List>
              <Section title="Change detent">
                <Button
                  label="Height 300"
                  onPress={() => setSelectedDetent({ height: 300 })}
                />
                <Button
                  label="Fraction 0.3"
                  onPress={() =>
                    setSelectedDetent({ fraction: 0.3 })
                  }
                />
                <Button
                  label="Medium"
                  onPress={() => setSelectedDetent('medium')}
                />
                <Button
                  label="Large"
                  onPress={() => setSelectedDetent('large')}
                />
              </Section>
              <Section title="Current">
                <Text
                  modifiers={[foregroundStyle('secondaryLabel')]}>
                  {formatDetent(selectedDetent)}
                </Text>
              </Section>
            </List>
          </Group>
        </BottomSheet>
      </VStack>
    </Host>
  );
}
```

</ComponentExample>

### 带有 React Native 内容的底部弹窗

使用 `RNHostView` 将 React Native 组件嵌入到底部弹窗中。设置 `matchContents` 可让宿主视图自动调整大小以适配其内容。

### 可滚动的 React Native 内容

将可滚动的 React Native 列表，例如 `FlatList`、`ScrollView`，或高性能列表（如 [FlashList](https://shopify.github.io/flash-list/) 或 [Legend List](https://github.com/LegendApp/legend-list)）嵌套在带有 `RNHostView` 的弹窗中。使用 [`presentationDetents`](modifiers/#presentationdetentsdetents-options) 设置弹窗尺寸，列表会在该高度内滚动。

              presentationDragIndicator('visible'),

            <RNHostView>
              <View style={{ padding: 16 }}>

                  data={DATA}
                  keyExtractor={item => item}
                  renderItem={({ item }) => (
                    <RNText
                      style={{
