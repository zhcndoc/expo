## 用法

> **注意：** 使用 `linear` 样式（确定性进度的默认样式）时，`ProgressView` 是一个可变宽度组件，会扩展以填充可用的水平空间。在 `Host` 上使用 `matchContents` 时，应在 `ProgressView` 上应用 [`frame`](modifiers/#frameparams) 修饰符，为其指定明确的宽度。或者，使用 `style` 为 `Host` 指定明确的尺寸（例如，`style={{ width: 300 }}` 或 `style={{ flex: 1 }}`）。`circular` 样式和不确定性加载指示器大小固定，可以与 `matchContents` 一起使用。

### 不确定性进度

未提供 `value` 时，进度视图会显示不确定性指示器（spinner）。

<ComponentExample
  title="IndeterminateExample.tsx"
  src="/static/images/expo-ui/examples/progressview-indeterminate-ios-light.webp"
  darkSrc="/static/images/expo-ui/examples/progressview-indeterminate-ios-dark.webp"
  alt="An indeterminate spinner sized to its content at the leading edge">

```tsx
import { Host, ProgressView } from '@expo/ui/swift-ui';

export default function IndeterminateExample() {
  return (
    <Host matchContents>
      <ProgressView />
    </Host>
  );
}
```

</ComponentExample>

### 确定性进度

提供一个介于 `0` 和 `1` 之间的 `value`，以显示确定性进度。

<ComponentExample
  title="DeterminateExample.tsx"
  src="/static/images/expo-ui/examples/progressview-determinate-ios-light.webp"
  darkSrc="/static/images/expo-ui/examples/progressview-determinate-ios-dark.webp"
  alt="A linear progress bar filled to the halfway point">

```tsx
import { Host, ProgressView } from '@expo/ui/swift-ui';

export default function DeterminateExample() {
  return (
    <Host style={{ flex: 1 }}>
      <ProgressView value={0.5} />
    </Host>
  );
}
```

</ComponentExample>

### 进度视图样式

使用 [`progressViewStyle`](modifiers/#progressviewstylestyle) 修饰符更改进度视图的外观。可用样式包括：`automatic`、`linear` 和 `circular`。

<ComponentExample
  title="ProgressViewStylesExample.tsx"
  src="/static/images/expo-ui/examples/progressview-styles-ios-light.webp"
  darkSrc="/static/images/expo-ui/examples/progressview-styles-ios-dark.webp"
  alt="A half-filled linear progress bar labelled Linear, above a circular spinner labelled Circular">

```tsx
import {
  Host,
  ProgressView,
  Text,
  VStack,
} from '@expo/ui/swift-ui';
import { progressViewStyle } from '@expo/ui/swift-ui/modifiers';

export default function ProgressViewStylesExample() {
  return (
    <Host style={{ flex: 1 }}>
      <VStack spacing={16}>
        <Text>Linear</Text>
        <ProgressView
          value={0.5}
          modifiers={[progressViewStyle('linear')]}
        />
        <Text>Circular</Text>
        <ProgressView
          value={0.5}
          modifiers={[progressViewStyle('circular')]}
        />
      </VStack>
    </Host>
  );
}
```

</ComponentExample>

### 带标签

你可以将自定义组件作为 `children` 传入，为进度视图提供标签。

<ComponentExample
  title="LabelExample.tsx"
  src="/static/images/expo-ui/examples/progressview-label-ios-light.webp"
  darkSrc="/static/images/expo-ui/examples/progressview-label-ios-dark.webp"
  alt="A progress bar filled to one quarter, with the label Loading above it">

```tsx
import { Host, ProgressView, Text } from '@expo/ui/swift-ui';

export default function LabelExample() {
  return (
    <Host style={{ flex: 1 }}>
      <ProgressView value={0.25}>
        <Text>加载中...</Text>
      </ProgressView>
    </Host>
  );
}
```

</ComponentExample>

使用 `tint` 修饰符更改进度视图的颜色。

<ComponentExample

</ComponentExample>

### 基于计时器的进度

使用 `timerInterval` 属性创建一个会在指定时间范围内自动播放动画的进度视图。这适用于显示倒计时或定时操作。

> **注意：** 基于计时器的进度仅适用于 iOS 16+ 和 tvOS 16+。

<ComponentExample
  title="TimerExample.tsx"
  src="/static/images/expo-ui/examples/progressview-timer-ios-light.webp"
  darkSrc="/static/images/expo-ui/examples/progressview-timer-ios-dark.webp"
  alt="Two timer progress bars part way through a ten second range, one labeled Counting up">

```tsx
import {
  Host,
  ProgressView,
  Text,
  VStack,
} from '@expo/ui/swift-ui';

export default function TimerExample() {
  const startDate = new Date();
  const endDate = new Date(Date.now() + 10000); // 距现在 10 秒

  return (
    <Host style={{ flex: 1 }}>
      <VStack spacing={16}>
        <ProgressView
          timerInterval={{ lower: startDate, upper: endDate }}
        />
        <ProgressView
          timerInterval={{ lower: startDate, upper: endDate }}
          countsDown={false}>
          <Text>Counting up</Text>
        </ProgressView>
      </VStack>
    </Host>
  );
}
```

</ComponentExample>
