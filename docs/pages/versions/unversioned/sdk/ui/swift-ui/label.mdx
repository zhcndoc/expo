## 用法

### 带 SF Symbol 的基础标签

<ComponentExample
  title="BasicLabelExample.tsx"
  src="/static/images/expo-ui/examples/label-basic-ios-light.webp"
  darkSrc="/static/images/expo-ui/examples/label-basic-ios-dark.webp"
  alt="标题 Favorites 旁边的星形 SF Symbol">

```tsx
import { Host, Label } from '@expo/ui/swift-ui';

export default function BasicLabelExample() {
  return (
    <Host style={{ flex: 1 }}>
      <Label title="Favorites" systemImage="star.fill" />
    </Host>
  );
}
```

</ComponentExample>

### 使用自定义图标

使用 `icon` 属性提供一个自定义 React 节点作为图标，而不是 SF Symbol。

<ComponentExample
  title="LabelCustomIconExample.tsx"
  src="/static/images/expo-ui/examples/label-custom-icon-ios-light.webp"
  darkSrc="/static/images/expo-ui/examples/label-custom-icon-ios-dark.webp"
  alt="标题 Custom Icon 旁边的紫色闪光 SF Symbol">

```tsx
import { Host, Label, Image } from '@expo/ui/swift-ui';

export default function LabelCustomIconExample() {
  return (
    <Host matchContents>
      <Label
        title="Custom Icon"
        icon={
          <Image systemName="sparkles" size={20} color="purple" />
        }
      />
    </Host>
  );
}
```

</ComponentExample>

### 仅显示图标

使用 [`labelStyle`](modifiers/#labelstylestyle) 修饰符并设置为 `iconOnly` 以仅显示图标。即使图标不可见，也始终要提供 `title` 以满足可访问性要求。

<ComponentExample
  title="LabelIconOnlyExample.tsx"
  src="/static/images/expo-ui/examples/label-icon-only-ios-light.webp"
  darkSrc="/static/images/expo-ui/examples/label-icon-only-ios-dark.webp"
  alt="单独显示的齿轮 SF Symbol，不显示标题文本">

```tsx
import { Host, Label } from '@expo/ui/swift-ui';
import { labelStyle } from '@expo/ui/swift-ui/modifiers';

export default function LabelIconOnlyExample() {
  return (
    <Host style={{ flex: 1 }}>
      <Label
        title="Settings"
        systemImage="gear"
        modifiers={[labelStyle('iconOnly')]}
      />
    </Host>
  );
}
```

</ComponentExample>
