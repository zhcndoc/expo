### 仅含图标的按钮

使用 `labelStyle` 修饰器在保留辅助功能标签的同时仅显示图标。

<ComponentExample
  title="IconOnlyButtonExample.tsx"
  src="/static/images/expo-ui/examples/button-icon-only-ios-light.webp"
  darkSrc="/static/images/expo-ui/examples/button-icon-only-ios-dark.webp"
  alt="一个没有可见标签的齿轮图标按钮">

```tsx
import { Host, Button } from '@expo/ui/swift-ui';
import { labelStyle } from '@expo/ui/swift-ui/modifiers';

export default function IconOnlyButtonExample() {
  return (
    <Host style={{ flex: 1 }}>
      <Button
        label="设置"
        systemImage="gear"
        modifiers={[labelStyle('iconOnly')]}
        onPress={() => alert('设置')}
      />
    </Host>
  );
}
```

</ComponentExample>

### 按钮样式

使用 `buttonStyle` 修饰器更改按钮外观。可用样式有：`bordered`、`borderedProminent`、`borderless`、`plain`、`glass` 和 `glassProminent`。

> **注意：** `glass` 和 `glassProminent` 样式仅在使用 Xcode 26 构建时、iOS 26+ 上可用。

<ComponentExample
  title="ButtonStylesExample.tsx"
  src="/static/images/expo-ui/examples/button-styles-ios-light.webp"
  darkSrc="/static/images/expo-ui/examples/button-styles-ios-dark.webp"
  alt="四个按钮，分别展示 bordered、bordered prominent、borderless 和 plain 样式">

```tsx
import { Host, Button, VStack } from '@expo/ui/swift-ui';
import { buttonStyle } from '@expo/ui/swift-ui/modifiers';

export default function ButtonStylesExample() {
  return (
    <Host style={{ flex: 1 }}>
      <VStack spacing={8}>
        <Button
          label="Bordered"
          modifiers={[buttonStyle('bordered')]}
        />
        <Button
          label="Bordered Prominent"
          modifiers={[buttonStyle('borderedProminent')]}
        />
        <Button
          label="Borderless"
          modifiers={[buttonStyle('borderless')]}
        />
        <Button label="Plain" modifiers={[buttonStyle('plain')]} />
      </VStack>
    </Host>
  );
}
```

</ComponentExample>

### 按钮边框形状

使用 `buttonBorderShape` 修饰器更改样式化按钮的形状。可用形状有：`automatic`、`capsule`、`roundedRectangle` 和 `circle`（iOS 17+）。

<ComponentExample
  title="ButtonBorderShapeExample.tsx"
  src="/static/images/expo-ui/examples/button-border-shape-ios-light.webp"
  darkSrc="/static/images/expo-ui/examples/button-border-shape-ios-dark.webp"
  alt="一个圆形的 glass 按钮，内含心形图标">

```tsx
import { Host, Button } from '@expo/ui/swift-ui';
import {
  buttonStyle,
  controlSize,
  buttonBorderShape,
  labelStyle,
} from '@expo/ui/swift-ui/modifiers';

export default function ButtonBorderShapeExample() {
  return (
    <Host style={{ flex: 1 }}>
      <Button
        label="Favorite"
        systemImage="heart.fill"
        modifiers={[
          buttonStyle('glass'),
          controlSize('extraLarge'),
          labelStyle('iconOnly'),
          buttonBorderShape('circle'),
        ]}
        onPress={() => alert('Favorited')}
      />
    </Host>
  );
}
```

</ComponentExample>

### 控件尺寸

使用 `controlSize` 修饰器调整按钮大小。可用尺寸有：`mini`、`small`、`regular`、`large` 和 `extraLarge`。

> **注意：** `extraLarge` 尺寸仅在 iOS 17+ 上可用。

<ComponentExample
  title="ControlSizeExample.tsx"
  src="/static/images/expo-ui/examples/button-control-sizes-ios-light.webp"
  darkSrc="/static/images/expo-ui/examples/button-control-sizes-ios-dark.webp"
  alt="四个 bordered 按钮，尺寸分别为 mini、small、regular 和 large">

```tsx
import { Host, Button, VStack } from '@expo/ui/swift-ui';
import {
  buttonStyle,
  controlSize,
} from '@expo/ui/swift-ui/modifiers';

export default function ControlSizeExample() {
  return (
    <Host style={{ flex: 1 }}>
      <VStack spacing={8}>
        <Button
          label="Mini"
          modifiers={[controlSize('mini'), buttonStyle('bordered')]}
        />
        <Button
          label="Small"
          modifiers={[
            controlSize('small'),
            buttonStyle('bordered'),
          ]}
        />
        <Button
          label="Regular"
          modifiers={[
            controlSize('regular'),
            buttonStyle('bordered'),
          ]}
        />
        <Button
          label="Large"
          modifiers={[
            controlSize('large'),
            buttonStyle('bordered'),
          ]}
        />
      </VStack>
    </Host>
  );
}
```

</ComponentExample>

### 按钮角色

使用 `role` 属性指示按钮的语义角色。可用角色有：`default`、`cancel` 和 `destructive`。

<ComponentExample
  title="ButtonRolesExample.tsx"
  src="/static/images/expo-ui/examples/button-roles-ios-light.webp"
  darkSrc="/static/images/expo-ui/examples/button-roles-ios-dark.webp"
  alt="三个按钮，分别展示 default、cancel 和红色 destructive 角色">

```tsx
import { Host, Button, VStack } from '@expo/ui/swift-ui';

export default function ButtonRolesExample() {
  return (
    <Host style={{ flex: 1 }}>
      <VStack spacing={8}>
        <Button label="默认" role="default" />
        <Button label="取消" role="cancel" />
        <Button label="删除" role="destructive" />
      </VStack>
    </Host>
  );
}
```

</ComponentExample>

### 自定义标签内容

你可以将自定义组件作为 `children` 传入，以实现更复杂的按钮标签内容。

<ComponentExample
  title="CustomContentExample.tsx"
  src="/static/images/expo-ui/examples/button-custom-content-ios-light.webp"
  darkSrc="/static/images/expo-ui/examples/button-custom-content-ios-dark.webp"
  alt="一个按钮，文件夹图标位于标签 Folder 上方">

```tsx
import {
  Host,
  Button,
  VStack,
  Image,
  Text,
} from '@expo/ui/swift-ui';

export default function CustomContentExample() {
  return (
    <Host style={{ flex: 1 }}>
      <Button onPress={() => console.log('Pressed!')}>
        <VStack spacing={4}>
          <Image systemName="folder" />
          <Text>文件夹</Text>
        </VStack>
      </Button>
    </Host>
  );
}
```

</ComponentExample>
