## 用法

### 基本懒加载垂直堆栈

应在 `ScrollView` 中使用 [`LazyVStack`](#lazyvstack)。`LazyVStack` 的每个子项都是一行。使用 `spacing` 和 `alignment` 属性设置行之间的间距和对齐方式。

<ComponentExample
  title="BasicLazyVStackExample.tsx"
  src="/static/images/expo-ui/examples/lazyvstack-static-ios-light.webp"
  darkSrc="/static/images/expo-ui/examples/lazyvstack-static-ios-dark.webp"
  alt="垂直堆叠的三行项目，彼此之间有小间距">

```tsx
import {
  Host,
  ScrollView,
  LazyVStack,
  Text,
} from '@expo/ui/swift-ui';

export default function BasicLazyVStackExample() {
  return (
    <Host style={{ flex: 1 }}>
      <ScrollView>
        <LazyVStack spacing={12}>
          <Text>Wi-Fi</Text>
          <Text>Bluetooth</Text>
          <Text>Notifications</Text>
        </LazyVStack>
      </ScrollView>
    </Host>
  );
}
```

</ComponentExample>

### 大型列表

使用 [`LazyVStack.ForEach`](#lazyvstackforeach) 从数组渲染行。将项目作为 `data` 传入，使用 `keyExtractor` 为每个项目提供唯一键，并传入一个返回项目行的 `children` 函数。`LazyVStack.ForEach` 只渲染可见区域附近的行，并在滚动时复用这些行。

<ComponentExample
  title="LargeLazyVStackExample.tsx"
  src="/static/images/expo-ui/examples/lazyvstack-large-ios-light.webp"
  darkSrc="/static/images/expo-ui/examples/lazyvstack-large-ios-dark.webp"
  alt="显示一万名联系人的前几行的垂直列表">

```tsx
import {
  Host,
  ScrollView,
  LazyVStack,
  Text,
} from '@expo/ui/swift-ui';

type Contact = { id: string; name: string };

const contacts: Contact[] = Array.from(
  { length: 10000 },
  (_, i) => ({
    id: String(i),
    name: `Contact ${i + 1}`,
  })
);

function renderContact({ item }: { item: Contact }) {
  return <Text>{item.name}</Text>;
}

export default function LargeLazyVStackExample() {
  return (
    <Host style={{ flex: 1 }}>
      <ScrollView>
        <LazyVStack spacing={12}>
          <LazyVStack.ForEach
            data={contacts}
            keyExtractor={contact => contact.id}
            estimatedItemSize={20}>
            {renderContact}
          </LazyVStack.ForEach>
        </LazyVStack>
      </ScrollView>
    </Host>
  );
}
```

</ComponentExample>

渲染行时请遵循以下规则：

- 在组件外定义 `children` 函数，或使用 `useCallback` 包装它。否则，每次组件渲染时，可见区域附近的行都会重新渲染。
- 复用的行会保留之前显示项目的本地状态（`useState`）。项目变化时重置状态，或将状态保存在行外部。
- 尚未准备好的行会显示空占位符。将 `estimatedItemSize` 设置为接近行高的值，单位为点。
- 使用 `overscanCount` 在可见行的上方和下方预先准备更多行。
- 要更新行，请传入新的 `data` 数组。不要原地修改数组。
- 设置 `recycling={false}` 可预先渲染每一行。
