## 用法

### 基础确认对话框

使用 `ConfirmationDialog.Trigger` 来定义可见元素，并使用 `ConfirmationDialog.Actions` 来提供对话框按钮。

<ComponentExample
  title="BasicConfirmationDialogExample.tsx"
  src="/static/images/expo-ui/examples/confirmationdialog-basic-ios-light.webp"
  darkSrc="/static/images/expo-ui/examples/confirmationdialog-basic-ios-dark.webp"
  alt="一个锚定在触发器下方的对话框，标题为“你确定吗？”，带有一个“确认”按钮">

```tsx
import { useState } from 'react';
import {
  Host,
  ConfirmationDialog,
  Button,
} from '@expo/ui/swift-ui';

export default function BasicConfirmationDialogExample() {
  const [isPresented, setIsPresented] = useState(false);

  return (
    <Host style={{ flex: 1 }}>
      <ConfirmationDialog
        title="你确定吗？"
        isPresented={isPresented}
        onIsPresentedChange={setIsPresented}
        titleVisibility="visible">
        <ConfirmationDialog.Trigger>
          <Button
            label="Show dialog"
            onPress={() => setIsPresented(true)}
          />
        </ConfirmationDialog.Trigger>
        <ConfirmationDialog.Actions>
          <Button
            label="Confirm"
            onPress={() => setIsPresented(false)}
          />
          <Button label="Cancel" role="cancel" />
        </ConfirmationDialog.Actions>
      </ConfirmationDialog>
    </Host>
  );
}
```

</ComponentExample>

### 危险操作确认

在 `ConfirmationDialog.Actions` 内的 `Button` 上使用 `role="destructive"`，将其样式设置为危险操作。

<ComponentExample
  title="DestructiveConfirmationDialogExample.tsx"
  src="/static/images/expo-ui/examples/confirmationdialog-destructive-ios-light.webp"
  darkSrc="/static/images/expo-ui/examples/confirmationdialog-destructive-ios-dark.webp"
  alt="一个标题为“删除项目？”的对话框，带有一条消息和一个红色的“删除”按钮">

```tsx
import { useState } from 'react';
import {
  Host,
  ConfirmationDialog,
  Button,
  Text,
} from '@expo/ui/swift-ui';

export default function DestructiveConfirmationDialogExample() {
  const [isPresented, setIsPresented] = useState(false);

  return (
    <Host style={{ flex: 1 }}>
      <ConfirmationDialog
        title="删除项目？"
        isPresented={isPresented}
        onIsPresentedChange={setIsPresented}
        titleVisibility="visible">
        <ConfirmationDialog.Trigger>
          <Button
            label="Delete"
            role="destructive"
            onPress={() => setIsPresented(true)}
          />
        </ConfirmationDialog.Trigger>
        <ConfirmationDialog.Actions>
          <Button
            label="删除"
            role="destructive"
            onPress={() => {
              console.log('Deleted');
              setIsPresented(false);
            }}
          />
          <Button label="取消" role="cancel" />
        </ConfirmationDialog.Actions>
        <ConfirmationDialog.Message>
          <Text>此操作无法撤销。</Text>
        </ConfirmationDialog.Message>
      </ConfirmationDialog>
    </Host>
  );
}
```

</ComponentExample>

### 带消息和多个操作

使用 `ConfirmationDialog.Message` 在标题下方显示描述性消息，并包含多个操作按钮以提供不同选择。

<ComponentExample
  title="MultiActionConfirmationDialogExample.tsx"
  src="/static/images/expo-ui/examples/confirmationdialog-multi-action-ios-light.webp"
  darkSrc="/static/images/expo-ui/examples/confirmationdialog-multi-action-ios-dark.webp"
  alt="一个标题为“保存更改？”的对话框，带有一条消息、一个“保存”按钮和一个红色的“放弃”按钮">

```tsx
import { useState } from 'react';
import {
  Host,
  ConfirmationDialog,
  Button,
  Text,
} from '@expo/ui/swift-ui';

export default function MultiActionConfirmationDialogExample() {
  const [isPresented, setIsPresented] = useState(false);

  return (
    <Host style={{ flex: 1 }}>
      <ConfirmationDialog
        title="保存更改？"
        isPresented={isPresented}
        onIsPresentedChange={setIsPresented}
        titleVisibility="visible">
        <ConfirmationDialog.Trigger>
          <Button
            label="Close document"
            onPress={() => setIsPresented(true)}
          />
        </ConfirmationDialog.Trigger>
        <ConfirmationDialog.Actions>
          <Button
            label="Save"
            onPress={() => console.log('Saved')}
          />
          <Button
            label="Discard"
            role="destructive"
            onPress={() => console.log('Discarded')}
          />
          <Button label="Cancel" role="cancel" />
        </ConfirmationDialog.Actions>
        <ConfirmationDialog.Message>
          <Text>
            你有未保存的更改。你想如何处理？
          </Text>
        </ConfirmationDialog.Message>
      </ConfirmationDialog>
    </Host>
  );
}
```

</ComponentExample>

### 隐藏标题

设置 `titleVisibility="hidden"` 可在隐藏对话框标题的同时仍显示操作和消息。为了可访问性，你仍应提供一个 `title`。

<ComponentExample
  title="HiddenTitleConfirmationDialogExample.tsx"
  src="/static/images/expo-ui/examples/confirmationdialog-hidden-title-ios-light.webp"
  darkSrc="/static/images/expo-ui/examples/confirmationdialog-hidden-title-ios-dark.webp"
  alt="一个仅显示消息和“确定”按钮、不显示标题的对话框">

```tsx
import { useState } from 'react';
import {
  Host,
  ConfirmationDialog,
  Button,
  Text,
} from '@expo/ui/swift-ui';

export default function HiddenTitleConfirmationDialogExample() {
  const [isPresented, setIsPresented] = useState(false);

  return (
    <Host style={{ flex: 1 }}>
      <ConfirmationDialog
        title="隐藏标题"
        isPresented={isPresented}
        onIsPresentedChange={setIsPresented}
        titleVisibility="hidden">
        <ConfirmationDialog.Trigger>
          <Button
            label="Show dialog"
            onPress={() => setIsPresented(true)}
          />
        </ConfirmationDialog.Trigger>
        <ConfirmationDialog.Actions>
          <Button
            label="OK"
            onPress={() => setIsPresented(false)}
          />
          <Button label="Cancel" role="cancel" />
        </ConfirmationDialog.Actions>
        <ConfirmationDialog.Message>
          <Text>只有消息和操作可见。</Text>
        </ConfirmationDialog.Message>
      </ConfirmationDialog>
    </Host>
  );
}
```

</ComponentExample>
