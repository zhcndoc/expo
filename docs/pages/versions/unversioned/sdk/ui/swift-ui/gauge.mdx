## 用法

### 基础仪表

<ComponentExample
  title="BasicGaugeExample.tsx"
  src="/static/images/expo-ui/examples/gauge-basic-ios-light.webp"
  darkSrc="/static/images/expo-ui/examples/gauge-basic-ios-dark.webp"
  alt="在 iOS 上渲染的基础仪表">

```tsx
import { Host, Gauge } from '@expo/ui/swift-ui';

export default function BasicGaugeExample() {
  // 线性仪表会延展至可用宽度，因此请为宿主视图指定尺寸。
  return (
    <Host style={{ flex: 1 }}>
      <Gauge value={0.5} />
    </Host>
  );
}
```

</ComponentExample>

### 添加标签

你可以将自定义组件作为 `children` 传入，为仪表提供标签。

<ComponentExample
  title="LabelExample.tsx"
  src="/static/images/expo-ui/examples/gauge-label-ios-light.webp"
  darkSrc="/static/images/expo-ui/examples/gauge-label-ios-dark.webp"
  alt="在 iOS 上渲染的带有进度标签的仪表">

```tsx
import { Host, Gauge, Text } from '@expo/ui/swift-ui';

export default function LabelExample() {
  return (
    <Host style={{ flex: 1 }}>
      <Gauge value={0.7}>
        <Text>进度</Text>
      </Gauge>
    </Host>
  );
}
```

</ComponentExample>

### 添加数值标签

使用 `currentValueLabel`、`minimumValueLabel` 和 `maximumValueLabel` 属性显示数值信息。

<ComponentExample
  title="ValueLabelsExample.tsx"
  src="/static/images/expo-ui/examples/gauge-value-labels-ios-light.webp"
  darkSrc="/static/images/expo-ui/examples/gauge-value-labels-ios-dark.webp"
  alt="在 iOS 上渲染的带有当前值、最小值和最大值标签的仪表">

```tsx
import { Host, Gauge, Text } from '@expo/ui/swift-ui';

export default function ValueLabelsExample() {
  return (
    <Host style={{ flex: 1 }}>
      <Gauge
        value={50}
        min={0}
        max={100}
        currentValueLabel={<Text>50%</Text>}
        minimumValueLabel={<Text>0</Text>}
        maximumValueLabel={<Text>100</Text>}>
        <Text>用量</Text>
      </Gauge>
    </Host>
  );
}
```

</ComponentExample>

### 仪表样式

使用 `gaugeStyle` 修饰符更改仪表的外观。可用样式包括：`automatic`、`circular`、`circularCapacity`、`linear` 和 `linearCapacity`。

<ComponentExample
  title="GaugeStylesExample.tsx"
  src="/static/images/expo-ui/examples/gauge-styles-ios-light.webp"
  darkSrc="/static/images/expo-ui/examples/gauge-styles-ios-dark.webp"
  alt="在 iOS 上渲染的圆形、圆形容量、线性和线性容量仪表样式">

```tsx
import { Host, Gauge, Text, VStack } from '@expo/ui/swift-ui';
import { gaugeStyle } from '@expo/ui/swift-ui/modifiers';

export default function GaugeStylesExample() {
  return (
    <Host style={{ flex: 1 }}>
      <VStack spacing={16}>
        <Text>Circular</Text>
        <Gauge value={0.5} modifiers={[gaugeStyle('circular')]}>
          <Text>圆形</Text>
        </Gauge>
        <Text>Circular Capacity</Text>
        <Gauge
          value={0.5}
          modifiers={[gaugeStyle('circularCapacity')]}>
          <Text>Circular Capacity</Text>
        </Gauge>
        <Text>Linear</Text>
        <Gauge value={0.5} modifiers={[gaugeStyle('linear')]}>
          <Text>线性</Text>
        </Gauge>
        <Gauge
          value={0.5}
          modifiers={[gaugeStyle('linearCapacity')]}>
          <Text>Linear Capacity</Text>
        </Gauge>
      </VStack>
    </Host>
  );
}
```

</ComponentExample>

### 着色仪表

使用 `tint` 修饰符更改仪表的颜色。

<ComponentExample
  title="TintedGaugeExample.tsx"
  src="/static/images/expo-ui/examples/gauge-tinted-ios-light.webp"
  darkSrc="/static/images/expo-ui/examples/gauge-tinted-ios-dark.webp"
  alt="在 iOS 上渲染的绿色圆形仪表和红色线性仪表">

```tsx
import { Host, Gauge, VStack } from '@expo/ui/swift-ui';
import { gaugeStyle, tint } from '@expo/ui/swift-ui/modifiers';

export default function TintedGaugeExample() {
  return (
    <Host style={{ flex: 1 }}>
      <VStack spacing={16}>
        <Gauge
          value={0.7}
          modifiers={[gaugeStyle('circular'), tint('green')]}
        />
        <Gauge
          value={0.3}
          modifiers={[gaugeStyle('linear'), tint('red')]}
        />
      </VStack>
    </Host>
  );
}
```

</ComponentExample>
