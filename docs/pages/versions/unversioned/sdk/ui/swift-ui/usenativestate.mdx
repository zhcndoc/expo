`useNativeState` 返回一个 [`ObservableState`](#observablestate)，它在原生端映射到 SwiftUI 的 [`ObservableObject`](https://developer.apple.com/documentation/combine/observableobject)，因此对 `.value` 的读取和写入会被 SwiftUI 直接观察到，而不会经过 React 的渲染周期。这使你可以在 UI 线程上的 worklet 中同步更新原生视图。

> **注意：** 当使用 [React 编译器](https://react.dev/learn/react-compiler) 时，你应避免直接访问和修改 `value` 属性。相反，请使用 [`get`](#observablestate) 和 [`set`](#observablestate) 方法，它们符合 React 编译器标准。

## 用法

> **注意：** 使用 worklet 需要在项目中安装 [`react-native-worklets`](https://docs.swmansion.com/react-native-worklets/)。`useNativeState` 本身无需安装它即可使用，但下方展示的 UI 线程同步更新依赖 worklet 运行时。

以下示例会在用户输入时对电话号码进行格式化。格式化以及对 `maskedPhone.value`（文本）和 `selection.value`（光标位置）的写入都会在 UI 线程上同步进行，因此原始输入与格式化后的值之间不会出现闪烁。

```tsx WorkletPhoneMaskExample.tsx
import { Host, TextField, useNativeState } from '@expo/ui/swift-ui';
import { keyboardType } from '@expo/ui/swift-ui/modifiers';
import { useCallback } from 'react';

export default function WorkletPhoneMaskExample() {
  const maskedPhone = useNativeState('');
  const selection = useNativeState({ start: 0, end: 0 });

  const handleTextChange = useCallback(
    (v: string) => {
      'worklet';
      const digits = v.replace(/\D/g, '').slice(0, 10);
      let formatted: string;
      if (digits.length === 0) {
        formatted = '';
      } else if (digits.length <= 3) {
        formatted = digits;
      } else if (digits.length <= 6) {
        formatted = `(${digits.slice(0, 3)}) ${digits.slice(3)}`;
      } else {
        formatted = `(${digits.slice(0, 3)}) ${digits.slice(3, 6)}-${digits.slice(6)}`;
      }
      if (formatted !== v) {
        maskedPhone.value = formatted;
        // Snaps to end for demo. Real masks need smarter cursor handling.
        selection.value = {
          start: formatted.length,
          end: formatted.length,
        };
      }
    },
    [maskedPhone, selection]
  );

  return (
    <Host matchContents>
      <TextField
        text={maskedPhone}
        selection={selection}
        placeholder="(555) 123-4567"
        modifiers={[keyboardType('phone-pad')]}
        onTextChange={handleTextChange}
      />
    </Host>
  );
}
```

### Worklet 回调

报告变更的修饰符（例如 [`onHingeChange`](modifiers/#onhingechangehandler)）可以接收普通函数（在 JavaScript 线程上运行），也可以接收 `useWorkletCallback` 返回的回调（在 UI 线程上同步运行）。将其与 `useNativeState` 配合使用，即可在每次变更时更新视图，而无需触发 React 渲染。

```tsx WorkletHingeExample.tsx
import {
  Host,
  Text,
  useNativeState,
  useWorkletCallback,
  VStack,
} from '@expo/ui/swift-ui';
import { onHingeChange } from '@expo/ui/swift-ui/modifiers';

export default function WorkletHingeExample() {
  const isFullyOpen = useNativeState(false);
  const onHinge = useWorkletCallback((_, newContext) => {
    'worklet';
    isFullyOpen.value = newContext.hinge?.status === 'fullyOpen';
  });

  return (
    <Host matchContents>
      <VStack modifiers={[onHingeChange(onHinge)]}>
        <Text>Fold the device</Text>
      </VStack>
    </Host>
  );
}
```
