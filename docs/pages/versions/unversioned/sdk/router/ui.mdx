`expo-router/ui` 是 `expo-router` 库的一个子模块，导出用于构建[自定义标签页布局](/router/advanced/custom-tabs/)的无头组件和 hooks。你可以使用它替代 Expo Router 内置的导航器，例如 [JavaScript 标签页](/router/advanced/tabs/)和[原生标签页](/router/advanced/native-tabs/)。

> 有关适用于原生和 Web 应用的基于文件的路由库的更多信息，请参阅 [Expo Router](./index) 参考文档。

## 安装

要在项目中使用 `expo-router/ui`，你需要先在项目中安装 `expo-router`。请按照 Expo Router 的安装指南进行操作：

<BoxLink
  title="安装 Expo Router"
  description="了解如何在项目中安装 Expo Router。"
  href="/router/installation/"
  Icon={RouterLogo}
/>

## 在 app 配置中进行配置

如果你正在使用 [默认](/more/create-expo/#--template) 模板创建新项目，那么 `expo-router` 的 [配置插件](/config-plugins/introduction/) 已经在你的 app 配置中完成设置。

<ConfigPluginExample>

```json app.json
{
  "expo": {
    "plugins": ["expo-router"]
  }
}
```

</ConfigPluginExample>
