`expo-age-range` 提供对用户年龄范围信息的访问。它在 Android 上使用 Google 的 [Play Age Signals API](https://developer.android.com/google/play/age-signals/use-age-signals-api)，在 iOS 上使用 Apple 的 [Declared Age Range framework](https://developer.apple.com/documentation/declaredagerange/)。

此库允许你向应用用户请求年龄范围信息，以帮助你遵守适龄内容法规（例如在 [美国德克萨斯州](https://developer.apple.com/news/?id=btkirlj8)）并在应用中提供适龄体验。

> **important** **Google 和 Apple 提供的底层原生 API 正在积极开发中。虽然此库本身很稳定，但为了适应这些变化，可能需要进行更多破坏性变更。**

### 限制

我们建议在真实设备上测试此功能，因为模拟器运行时可能无法按预期工作。

## 在应用配置中进行配置

### 设置 iOS 项目

要在 iOS 上使用年龄范围 API，你需要使用 Xcode 26.0 或更高版本构建项目，但我们建议使用最新版本的 Xcode，以便访问最新的 API。

需要使用 `com.apple.developer.declared-age-range` 权限。将其添加到你的[应用配置](../config/app/)文件中：

```json app.json
{
  "expo": {
    "ios": {
      "entitlements": {
        "com.apple.developer.declared-age-range": true
      }
    }
  }
}
```

<ConfigReactNative>

对于现有的 React Native 项目，将该权限添加到项目的 **ios/[app]/[app].entitlements** 文件中：

```xml
<key>com.apple.developer.declared-age-range</key>
<true/>
```

## 用法

在 Android 上，Play Age Signals 仅在用户同意共享年龄范围时才会报告年龄范围。请先调用 [`requestAgeSignalsAccessAsync`](#agerangerequestagesignalsaccessasync)，并仅在该调用解析为 `'SHARED'` 时继续。在 iOS 上，同意提示是 `requestAgeRangeAsync` 的一部分，因此该调用会解析为 `null`，下面的示例会继续执行。

<SnackInline label="年龄范围用法" dependencies={['expo-age-range']} platforms={['android', 'ios']}>

```tsx
import * as AgeRange from 'expo-age-range';
import { useState } from 'react';
import { StyleSheet, Text, View, Button } from 'react-native';

export default function App() {
  const [result, setResult] = useState<AgeRange.AgeRangeResponse | { error: string } | null>(null);

  const requestAgeRange = async () => {
    try {
      // On Android, ask the user to share their age signals first. Resolves with null on iOS.
      const status = await AgeRange.requestAgeSignalsAccessAsync();
      if (status !== null && status !== 'SHARED') {
        setResult({ error: `Age signals are not shared: ${status}` });
        return;
      }

      const ageRange = await AgeRange.requestAgeRangeAsync({
        threshold1: 10,
        threshold2: 13,
        threshold3: 18,
      });
      setResult(ageRange);
    } catch (error) {
      setResult({ error: error.message });
    }
  };

  return (
    <View style={styles.container}>
      <Button title="请求年龄范围" onPress={requestAgeRange} />
      {result && (
        <Text style={styles.result}>
          {'error' in result ? `错误: ${result.error}` : `较低年龄界限: ${result.lowerBound}`}
        </Text>
      )}
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    justifyContent: 'center',
    padding: 20,
  },
  result: {
    marginTop: 20,
    fontSize: 16,
  },
});
```

## 错误代码

可在原生模块抛出的任何错误的 `code` 属性中找到。有关 Android 特有的错误代码，请参阅 [Use Play Age Signals API 文档](https://developer.android.com/google/play/age-signals/handle-errors)中的“错误代码参考”。

| 代码                            | 平台                                     | 描述                                                                                                        |
| ------------------------------- | ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| `ERR_AGE_RANGE_USER_DECLINED`   | <PlatformTags platforms={['ios']} />     | 用户拒绝共享其年龄范围。                                                                            |
| `ERR_AGE_RANGE_NOT_AVAILABLE`   | <PlatformTags platforms={['ios']} />     | 年龄范围不可用。最可能的原因是用户未在设备上登录其 Apple 账户。 |
| `ERR_AGE_RANGE_INVALID_REQUEST` | <PlatformTags platforms={['ios']} />     | 提供的参数无效。年龄范围之间至少需要相差 2 年。                                 |
| `ERR_AGE_RANGE_TASK_CANCELLED`  | <PlatformTags platforms={['android']} /> | 用户关闭了 Play Age Signals 年龄共享同意页面。                                                |
