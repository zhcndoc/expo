## 配置

Expo Maps 提供对 Android 和 iOS 上平台原生地图 API 的访问。

- **Apple Maps（仅适用于 <PlatformTag platform="ios" />）**。安装此包后，无需额外配置即可使用。
- **Google Maps（仅适用于 <PlatformTag platform="android" />）**。虽然 Google 为 iOS 提供了 Google Maps SDK，但 Expo Maps 仅在 Android 上支持它。如果你想在 iOS 上使用 Google Maps，可以考虑使用[替代库](https://reactnative.directory/)或[自行编写](/modules/overview/)。

### Google Cloud API 设置

**在 Android 上使用 Google Maps 之前**，你需要注册一个 Google Cloud API 项目，启用 Maps SDK for Android，并将相关配置添加到你的 Expo 项目中。

<Collapsible summary="在 Android 上设置 Google Maps">

> 如果你已经为 Android 上的其他 Google 服务（例如 Google Sign In）注册了项目，那么只需在你的项目中启用 **Maps SDK for Android**，然后跳到第 4 步。

<Step label="1">
**注册一个 Google Cloud API 项目并启用 Maps SDK for Android**

- 在浏览器中打开 [Google API Manager](https://console.cloud.google.com/apis) 并创建一个项目。
- 创建完成后，进入该项目并启用 **Maps SDK for Android**。

</Step>

<Step label="2">
**复制你应用的 SHA-1 证书指纹**

<Tabs>
<Tab label="适用于 Google Play 商店">

- **如果你要将应用部署到 Google Play 商店**，你需要至少先[将应用二进制文件上传到 Google Play 控制台](/submit/android/)一次。这是 Google 生成应用签名凭据所必需的。
- 前往 **[Google Play Console](https://play.google.com/console) > (你的应用) > 发布 > 设置 > 应用完整性 > 应用签名**。
- 复制 **SHA-1 certificate fingerprint** 的值。

</Tab>

<Tab label="适用于开发构建">

- 如果你已经创建了[开发构建](/develop/development-builds/introduction/)，你的项目将使用 debug keystore 进行签名。
- 构建完成后，前往你的[项目仪表盘](https://expo.dev/accounts/[username]/projects/[project-name])，然后在 **Project settings** 下点击 **Credentials**。
- 在 **Application Identifiers** 下，点击你项目的包名，然后在 **Android Keystore** 下复制 **SHA-1 Certificate Fingerprint** 的值。

</Tab>

</Tabs>

</Step>

<Step label="3">
**创建一个 API key**

- 前往 [Google Cloud Credential manager](https://console.cloud.google.com/apis/credentials) 并点击 **Create Credentials**，然后选择 **API Key**。
- 在弹窗中，点击 **Edit API key**。
- 在 **Key restrictions** > **Application restrictions** 下，选择 **Android apps**。
- 在 **Restrict usage to your Android apps** 下，点击 **Add an item**。
- 将 **app.json** 中的 `android.package`（例如：`com.company.myapp`）添加到包名字段中。
- 然后，添加第 2 步中的 **SHA-1 certificate fingerprint** 的值。
- 点击 **Done**，然后点击 **Save**。

</Step>

<Step label="4">
**将 API key 添加到你的项目中**

- 将你的 **API Key** 复制到 **app.json** 中的 `android.config.googleMaps.apiKey` 字段下。
- 创建一个新的开发构建，现在你就可以在 Android 上使用 `expo-maps` 的 Google Maps API 了。

</Step>

</Collapsible>

## 权限

要在地图上显示用户的位置，您需要事先声明并请求位置权限。如果您在项目中使用 config plugin（[Continuous Native Generation (CNG)](/workflow/continuous-native-generation/)），可以使用其内置的 [config plugin](/config-plugins/introduction/) 进行配置。该插件允许您配置各种无法在运行时设置、且需要重新构建新的应用二进制文件后才会生效的属性。如果您的应用**不**使用 CNG，那么您需要手动配置该库。

  }
}

## 用法

```tsx
import { AppleMaps, GoogleMaps } from 'expo-maps';
import { Platform, Text } from 'react-native';

export default function App() {
  if (Platform.OS === 'ios') {
    return <AppleMaps.View style={{ flex: 1 }} />;
  } else if (Platform.OS === 'android') {
    return <GoogleMaps.View style={{ flex: 1 }} />;
  } else {
    return <Text>地图仅在 Android 和 iOS 上可用</Text>;
  }
}
```

### 自定义标记图标

你可以使用 `expo-image` 中的 [`useImage`](/versions/v57.0.0/sdk/image/#useimage) 钩子来加载自定义标记和注释图标。

<Tabs>
<Tab label="Google Maps">

以下示例展示了如何在 Android 上使用 Google Maps 显示自定义标记图标。

```tsx
import { useImage } from 'expo-image';
import { GoogleMaps } from 'expo-maps';

export default function Map() {
  const icon = useImage('https://example.com/marker.svg', { maxWidth: 48, maxHeight: 48 });

  return (
    <GoogleMaps.View
      style={{ flex: 1 }}
      markers={[
        {
          coordinates: { latitude: 37.78825, longitude: -122.4324 },
          icon: icon ?? undefined,
          anchor: { x: 0.5, y: 0.5 },
        },
      ]}
    />
  );
}
```

`GoogleMaps.Marker.icon` 期望接收一个图像引用，例如 `expo-image` 包中 `useImage` 钩子返回的值。它不直接接受图像源。

加载后的图像尺寸决定标记大小，而不是某个 marker 样式属性。对于 SVG 图标，请在 SVG 中设置 `width`、`height` 和 `viewBox`，或者向 `useImage` 钩子传入 `maxWidth` 和 `maxHeight`。你可以使用 `anchor` 来将自定义图标与其坐标对齐。

</Tab>
<Tab label="Apple Maps">

以下示例展示了如何在 iOS 上使用 Apple Maps 显示自定义注释图标。

```tsx
import { useImage } from 'expo-image';
import { AppleMaps } from 'expo-maps';

export default function Map() {
  const icon = useImage('https://example.com/marker.svg');

  return (
    <AppleMaps.View
      style={{ flex: 1 }}
      annotations={[
        {
          coordinates: { latitude: 37.78825, longitude: -122.4324 },
          icon: icon ?? undefined,
        },
      ]}
    />
  );
}
```

`AppleMaps.Annotation.icon` 期望接收一个图像引用，例如 `expo-image` 库中 `useImage` 钩子返回的值。你可以使用 `AppleMaps.Annotation` 来设置自定义图像图标。`AppleMaps.Marker` 支持特定于标记的选项，例如 `systemImage`、`monogram` 和 `tintColor`。

</Tab>
</Tabs>

## 权限

### Android

要在地图上显示用户的位置，`expo-maps` 库需要以下权限：

- `ACCESS_COARSE_LOCATION`：用于获取设备的大致位置
- `ACCESS_FINE_LOCATION`：用于获取设备的精确位置

<AndroidPermissions
  permissions={[
    'ACCESS_COARSE_LOCATION',
    'ACCESS_FINE_LOCATION',
    'FOREGROUND_SERVICE',
    'FOREGROUND_SERVICE_LOCATION',
    'ACCESS_BACKGROUND_LOCATION',
  ]}
/>

### iOS

此库使用以下用途说明键：
