## 用法

### 辅助芯片

辅助芯片可帮助用户执行操作或开始任务，例如预订航班或打开地图。它们通常会在响应用户输入时作为临时 UI 元素出现。

<ComponentExample
  title="AssistChipExample.tsx"
  src="/static/images/expo-ui/examples/chip-assist-android-light.webp"
  darkSrc="/static/images/expo-ui/examples/chip-assist-android-dark.webp"
  alt="一个带有飞机图标和“预订航班”标签的描边辅助芯片">

```tsx
import {
  Host,
  AssistChip,
  Icon,
  Text,
} from '@expo/ui/jetpack-compose';

export default function AssistChipExample() {
  return (
    <Host matchContents>
      <AssistChip
        onClick={() => console.log('Opening flight booking...')}>
        <AssistChip.Label>
          <Text>预订航班</Text>
        </AssistChip.Label>
        <AssistChip.LeadingIcon>
          <Icon source={require('./assets/flight.xml')} size={18} />
        </AssistChip.LeadingIcon>
      </AssistChip>
    </Host>
  );
}
```

</ComponentExample>

### 筛选芯片

筛选芯片允许用户从一组选项中细化内容。它们支持选中状态，通常用于搜索栏或内容筛选。

<ComponentExample
  title="FilterChipExample.tsx"
  src="/static/images/expo-ui/examples/chip-filter-android-light.webp"
  darkSrc="/static/images/expo-ui/examples/chip-filter-android-dark.webp"
  alt="一个标签为“图片”的筛选芯片，显示为选中后的填充状态">

```tsx
import { useState } from 'react';
import { Host, FilterChip, Text } from '@expo/ui/jetpack-compose';

export default function FilterChipExample() {
  const [selected, setSelected] = useState(false);

  return (
    <Host matchContents>
      <FilterChip
        selected={selected}
        onClick={() => setSelected(!selected)}>
        <FilterChip.Label>
          <Text>图片</Text>
        </FilterChip.Label>
      </FilterChip>
    </Host>
  );
}
```

</ComponentExample>

### 输入芯片

输入芯片表示用户输入的离散信息片段，例如文本字段中的标签。它们支持头像、尾随图标，并且可以被移除。

<ComponentExample
  title="InputChipExample.tsx"
  src="/static/images/expo-ui/examples/chip-input-android-light.webp"
  darkSrc="/static/images/expo-ui/examples/chip-input-android-dark.webp"
  alt="三个分别标有“工作”“旅行”和“新闻”的输入芯片，每个都带有关闭图标">

```tsx
import { useState } from 'react';
import {
  Host,
  InputChip,
  Icon,
  Text,
  FlowRow,
} from '@expo/ui/jetpack-compose';

export default function InputChipExample() {
  const [chips, setChips] = useState(['工作', '旅行', '新闻']);

  return (
    <Host matchContents>
      <FlowRow horizontalArrangement={{ spacedBy: 8 }}>
        {chips.map(label => (
          <InputChip
            key={label}
            selected
            onClick={() =>
              setChips(prev => prev.filter(c => c !== label))
            }>
            <InputChip.Label>
              <Text>{label}</Text>
            </InputChip.Label>
            <InputChip.TrailingIcon>
              <Icon
                source={require('./assets/close.xml')}
                size={18}
              />
            </InputChip.TrailingIcon>
          </InputChip>
        ))}
      </FlowRow>
    </Host>
  );
}
```

</ComponentExample>

### 建议芯片

建议芯片通过展示动态生成的建议来帮助缩小用户意图范围，例如聊天中的快速回复选项或搜索细化项。

<ComponentExample
  title="SuggestionChipExample.tsx"
  src="/static/images/expo-ui/examples/chip-suggestion-android-light.webp"
  darkSrc="/static/images/expo-ui/examples/chip-suggestion-android-dark.webp"
  alt="一个标有“附近”的描边建议芯片">

```tsx
import {
  Host,
  SuggestionChip,
  Text,
} from '@expo/ui/jetpack-compose';

export default function SuggestionChipExample() {
  return (
    <Host matchContents>
      <SuggestionChip
        onClick={() => console.log('Searching nearby...')}>
        <SuggestionChip.Label>
          <Text>附近</Text>
        </SuggestionChip.Label>
      </SuggestionChip>
    </Host>
  );
}
```

</ComponentExample>
