## 用法

### 水平分隔线

一条细水平线，用于在列表和布局中直观地分隔内容。

<ComponentExample
  title="HorizontalDividerExample.tsx"
  src="/static/images/expo-ui/examples/divider-horizontal-android-light.webp"
  darkSrc="/static/images/expo-ui/examples/divider-horizontal-android-dark.webp"
  alt="一条全宽分割线将“第一部分”和“第二部分”标签分隔开">

```tsx
import {
  Host,
  HorizontalDivider,
  Column,
  Text,
  useMaterialColors,
} from '@expo/ui/jetpack-compose';

export default function HorizontalDividerExample() {
  const colors = useMaterialColors();

  return (
    <Host style={{ flex: 1 }}>
      <Column>
        <Text style={{ fontSize: 28 }} color={colors.onBackground}>
          First section
        </Text>
        <HorizontalDivider />
        <Text style={{ fontSize: 28 }} color={colors.onBackground}>
          Second section
        </Text>
      </Column>
    </Host>
  );
}
```

</ComponentExample>

### 自定义粗细和颜色

`HorizontalDivider` 和 `VerticalDivider` 都接受 `thickness` 和 `color` 属性。使用 `StyleSheet.hairlineWidth` 可绘制单像素线，或设置自定义的粗细和颜色。

<ComponentExample
  title="CustomDividerExample.tsx"
  src="/static/images/expo-ui/examples/divider-custom-android-light.webp"
  darkSrc="/static/images/expo-ui/examples/divider-custom-android-dark.webp"
  alt="一条淡色细线分割线位于一条粗粉色分割线上方，每条分割线都分隔一个标签">

```tsx
import {
  Host,
  HorizontalDivider,
  Column,
  Text,
  useMaterialColors,
} from '@expo/ui/jetpack-compose';
import { StyleSheet } from 'react-native';

export default function CustomDividerExample() {
  const colors = useMaterialColors();

  return (
    <Host style={{ flex: 1 }}>
      <Column>
        <Text style={{ fontSize: 28 }} color={colors.onBackground}>
          Hairline divider (1 pixel)
        </Text>
        <HorizontalDivider thickness={StyleSheet.hairlineWidth} />
        <Text style={{ fontSize: 28 }} color={colors.onBackground}>
          Thick colored divider
        </Text>
        <HorizontalDivider thickness={4} color="#E91E63" />
        <Text style={{ fontSize: 28 }} color={colors.onBackground}>
          Below
        </Text>
      </Column>
    </Host>
  );
}
```

</ComponentExample>

### 垂直分隔线

一条垂直线，用于在横向排列的行布局中分隔并排项目。

<ComponentExample
  title="VerticalDividerExample.tsx"
  src="/static/images/expo-ui/examples/divider-vertical-android-light.webp"
  darkSrc="/static/images/expo-ui/examples/divider-vertical-android-dark.webp"
  alt="一条短垂直线将“左”和“右”标签分隔开">

```tsx
import {
  Host,
  VerticalDivider,
  Row,
  Text,
  useMaterialColors,
} from '@expo/ui/jetpack-compose';
import { height } from '@expo/ui/jetpack-compose/modifiers';

export default function VerticalDividerExample() {
  const colors = useMaterialColors();

  return (
    <Host matchContents>
      <Row
        verticalAlignment="center"
        horizontalArrangement={{ spacedBy: 16 }}
        modifiers={[height(48)]}>
        <Text style={{ fontSize: 28 }} color={colors.onBackground}>
          Left
        </Text>
        <VerticalDivider />
        <Text style={{ fontSize: 28 }} color={colors.onBackground}>
          Right
        </Text>
      </Row>
    </Host>
  );
}
```

</ComponentExample>
