在 [`Row`](row) 或 [`Column`](column) 内部，在兄弟组件之间生成空白空间的布局间隔器。使用 [`size`](#size) 创建固定间隙，或使用 [`flexible`](#flexible) 填充剩余的主轴空间。

## 用法

### 固定大小间隔

```tsx FixedSpacerExample.tsx
import { Host, Column, Text, Spacer } from '@expo/ui';

export default function FixedSpacerExample() {
  return (
    <Host matchContents>
      <Column>
        <Text>顶部</Text>
        <Spacer size={32} />
        <Text>底部</Text>
      </Column>
    </Host>
  );
}
```

### 弹性间隔

弹性间隔会沿其父元素的主轴填充剩余空间，将周围内容推到两端。

```tsx FlexibleSpacerExample.tsx
import { Host, Row, Text, Spacer } from '@expo/ui';

export default function FlexibleSpacerExample() {
  return (
    <Host style={{ flex: 1 }}>
      <Row>
        <Text>前导</Text>
        <Spacer flexible />
        <Text>尾随</Text>
      </Row>
    </Host>
  );
}
```
