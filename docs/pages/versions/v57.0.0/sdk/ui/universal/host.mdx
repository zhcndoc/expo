一个用于通用 `@expo/ui` 内容的容器。在 Android 和 iOS 上，它会重新导出平台原生的 [`Host` for Jetpack Compose](../jetpack-compose/host)/[`Host` for SwiftUI](../swift-ui/host)，因此 Jetpack Compose/SwiftUI 子组件的渲染效果与在平台特定包中完全一致。在 web 上，它会回退为 React Native [`View`](https://reactnative.dev/docs/view)。请将 `Host` 作为任何通用子树的根节点，这样同一组件树就能在所有三个平台上正常工作。

### 在 React Native 视图中放置组件

`Host` 会在 Android 上使用 Jetpack Compose、在 iOS 上使用 SwiftUI 来渲染其通用子组件。`Host` 内的 React Native 视图（例如 `View` 或 `ScrollView`）会切换回 React Native 渲染。若要在该视图中使用通用组件，请将组件包裹在新的 `Host` 中。即使树中更高层的 `Host` 已经包裹了该视图，也要这样做。

```tsx ReactNativeLayoutExample.tsx
import { useState } from 'react';
import { ScrollView, Text, View, useColorScheme } from 'react-native';
import { Host, Switch } from '@expo/ui';

export default function ReactNativeLayoutExample() {
  const colorScheme = useColorScheme();
  const [enabled, setEnabled] = useState(false);

  return (
    <ScrollView>
      <View
        style={{
          flexDirection: 'row',
          alignItems: 'center',
          justifyContent: 'space-between',
          padding: 16,
        }}>
        <Text style={{ color: colorScheme === 'dark' ? '#FFFFFF' : '#000000' }}>Notifications</Text>
        <Host matchContents>
          <Switch value={enabled} onValueChange={setEnabled} />
        </Host>
      </View>
    </ScrollView>
  );
}
```

要将 React Native 视图放置在通用布局中，请使用 [`RNHostView`](rnhostview)。

### 内容尺寸匹配

使用 `matchContents` 让 `Host` 的尺寸自适应其内容。在 Android 和 iOS 上，这会转发到平台原生的 `Host`（精确的平台语义请参见 [Jetpack Compose](../jetpack-compose/host)/[SwiftUI](../swift-ui/host)）。在 web 上，它会将 `alignSelf: 'flex-start'` 应用到底层 `View`，这样 host 会缩小以适应其子元素，而不是被父元素拉伸。

> **注意：** 在 web 上，按轴形式（`{ horizontal: true }` / `{ vertical: true }`）的行为与布尔形式相同，因为 `alignSelf` 只控制父元素交叉轴上的拉伸。依赖按轴独立尺寸调整的组件，应预期在 web 上无论选择哪个轴，都会表现为相同的按内容收缩行为。

### 布局方向

使用 `layoutDirection` 将子树渲染为从左到右或从右到左。在 Android 和 iOS 上，这会转发到平台原生的 `Host`（精确的平台语义请参见 [Jetpack Compose](../jetpack-compose/host)/[SwiftUI](../swift-ui/host)）。在 web 上，它会在底层 `View` 上设置 `dir` 属性，使后代继承所选方向。

<ComponentExample
  title="LayoutDirectionExample.tsx"
  android={{
    src: '/static/images/expo-ui/examples/universal-host-layout-direction-android-light.webp',
    darkSrc: '/static/images/expo-ui/examples/universal-host-layout-direction-android-dark.webp',
    alt: '从右到左排列的两个标签，其中 Second 位于 First 之前',
  }}
  ios={{
    src: '/static/images/expo-ui/examples/universal-host-layout-direction-ios-light.webp',
    darkSrc: '/static/images/expo-ui/examples/universal-host-layout-direction-ios-dark.webp',
    alt: '从右到左排列的两个标签，其中 Second 位于 First 之前',
  }}>

```tsx
import { useColorScheme } from 'react-native';
import { Host, Row, Text } from '@expo/ui';

export default function LayoutDirectionExample() {
  const colorScheme = useColorScheme();
  const ink = { color: colorScheme === 'dark' ? '#FFFFFF' : '#000000' };

  return (
    <Host
      layoutDirection="rightToLeft"
      matchContents={{ vertical: true }}
      style={{ width: '100%' }}>
      <Row spacing={8}>
        <Text textStyle={ink}>First</Text>
        <Text textStyle={ink}>Second</Text>
      </Row>
    </Host>
  );
}
```

</ComponentExample>

### 响应内容布局

使用 `onLayoutContent` 以获取 host 内容当前的尺寸变化通知。在 Android 和 iOS 上，这会转发到平台原生的 `Host`（精确的平台语义请参见 [Jetpack Compose](../jetpack-compose/host)/[SwiftUI](../swift-ui/host)）。在 web 上，它来源于底层 `View` 的 `onLayout` 回调。

<ComponentExample
  title="OnLayoutContentExample.tsx"
  android={{
    src: '/static/images/expo-ui/examples/universal-host-on-layout-content-android-light.webp',
    darkSrc: '/static/images/expo-ui/examples/universal-host-on-layout-content-android-dark.webp',
    alt: '尺寸适应自身内容的 Hello world 标签',
  }}
  ios={{
    src: '/static/images/expo-ui/examples/universal-host-on-layout-content-ios-light.webp',
    darkSrc: '/static/images/expo-ui/examples/universal-host-on-layout-content-ios-dark.webp',
    alt: '尺寸适应自身内容的 Hello world 标签',
  }}>

```tsx
import { useColorScheme } from 'react-native';
import { Host, Text } from '@expo/ui';

export default function OnLayoutContentExample() {
  const colorScheme = useColorScheme();

  return (
    <Host
      matchContents
      onLayoutContent={({ nativeEvent: { width, height } }) =>
        console.log(`内容尺寸：${width}x${height}`)
      }>
      <Text textStyle={{ color: colorScheme === 'dark' ? '#FFFFFF' : '#000000' }}>
        Hello, world!
      </Text>
    </Host>
  );
}
```

</ComponentExample>

### 填充视口

对于应按可用视口空间进行尺寸调整的内容，请使用 `useViewportSizeMeasurement`。在 Android 和 iOS 上，这会转发到平台原生的 `Host`（精确的平台语义请参见 [Jetpack Compose](../jetpack-compose/host)/[SwiftUI](../swift-ui/host)）。在 web 上，host 底层的 `View` 会获得当前窗口的宽度和高度；你传入的任何显式 `style` 仍然会优先生效。

### 忽略安全区域

默认情况下，`Host` 会遵循设备的安全区域边距（刘海、Home 指示条等）。使用 `ignoreSafeArea="all"` 可让内容延伸到边到边，或使用 `ignoreSafeArea="keyboard"` 来保留安全区域内边距但忽略键盘插入区域。在 Android 和 iOS 上，这会转发到平台原生的 `Host`（精确的平台语义请参见 [Jetpack Compose](../jetpack-compose/host)/[SwiftUI](../swift-ui/host)）。在 web 上，它通过将 CSS `env(safe-area-inset-*)` 值作为底层 `View` 的内边距来实现；默认情况下还会将 `env(keyboard-inset-*)` 叠加到为采用 [VirtualKeyboard API](https://developer.mozilla.org/en-US/docs/Web/API/VirtualKeyboard_API) 的页面所使用的内边距中。

<ComponentExample
  title="IgnoreSafeAreaExample.tsx"
  android={{
    src: '/static/images/expo-ui/examples/universal-host-ignore-safe-area-android-light.webp',
    darkSrc: '/static/images/expo-ui/examples/universal-host-ignore-safe-area-android-dark.webp',
    alt: '绘制在状态栏和导航栏下方的标签',
  }}
  ios={{

```tsx
import { useColorScheme } from 'react-native';
import { Host, Column, Spacer, Text } from '@expo/ui';

export default function IgnoreSafeAreaExample() {
  const colorScheme = useColorScheme();
  const ink = { color: colorScheme === 'dark' ? '#FFFFFF' : '#000000' };

  return (
    <Host ignoreSafeArea="all" style={{ flex: 1 }}>
      <Column style={{ flex: 1 }} alignment="center">
        <Text textStyle={ink}>Behind the status bar</Text>
        <Spacer flexible />
        <Text textStyle={ink}>Behind the home indicator</Text>
      </Column>
    </Host>
  );
}
```

</ComponentExample>
