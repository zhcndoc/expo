以下组件提供与常见 React Native 社区库 API 兼容的替代方案，由 `@expo/ui` 原生组件（Android 上的 Jetpack Compose 和 iOS 上的 SwiftUI）提供支持。

- **[BottomSheet](bottomsheet)**: 兼容 `@gorhom/bottom-sheet`
- **[DateTimePicker](datetimepicker)**: 兼容 `@react-native-community/datetimepicker`
- **[MaskedView](maskedview)**: 兼容 `@react-native-masked-view/masked-view`
- **[Menu](menu)**: 兼容 `@react-native-menu/menu`
- **[PagerView](pagerview)**: 兼容 `react-native-pager-view`
- **[Picker](picker)**: 兼容 `@react-native-picker/picker`
- **[SegmentedControl](segmentedcontrol)**: 兼容 `@react-native-segmented-control/segmented-control`
- **[Slider](slider)**: 兼容 `@react-native-community/slider`
