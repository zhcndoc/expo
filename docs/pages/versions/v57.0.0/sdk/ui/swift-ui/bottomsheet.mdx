### 基础底部弹窗

将打开弹窗的控件作为 `anchor` 属性传入。子元素是弹窗的内容。

<ComponentExample
  title="BasicBottomSheetExample.tsx"
  src="/static/images/expo-ui/examples/bottomsheet-basic-ios-light.webp"
  darkSrc="/static/images/expo-ui/examples/bottomsheet-basic-ios-dark.webp"
  alt="一个填满屏幕的底部弹窗，居中显示文本 Hello, world！">

```tsx
import { useState } from 'react';
import {
  Host,
  BottomSheet,
  Button,
  Text,
  VStack,
} from '@expo/ui/swift-ui';

export default function BasicBottomSheetExample() {
  const [isPresented, setIsPresented] = useState(false);

  return (
    <Host style={{ flex: 1 }}>
      <VStack>
        <BottomSheet
          isPresented={isPresented}
          onIsPresentedChange={setIsPresented}
          anchor={
            <Button
              label="Open sheet"
              onPress={() => setIsPresented(true)}
            />
          }>
          <Text>Hello, world!</Text>
        </BottomSheet>
      </VStack>
    </Host>
  );
}
```

</ComponentExample>

### 自定义背景颜色

默认情况下，sheet 使用系统的半透明材质背景（iOS 26 上为 Liquid Glass）。可以在 `Group` 上使用 [`presentationBackground`](modifiers/#presentationbackgroundcolor) 修饰符，将 sheet 改为纯色背景，这样也会让 sheet 不再使用这种半透明材质。

> **info** 优先使用 `presentationBackground`，而不是在 sheet 内容上使用 `background` 修饰符。`background` 位于内容自身背景的 _后面_，因此会被 `Form` 或 `List` 覆盖，并且当 sheet 在不同 detent 之间移动时，颜色显示会不一致。`presentationBackground` 作用于 sheet 表面本身，因此在每个 detent 下都能保持一致。当内容是 `Form` 或 `List` 时，还要添加 [`scrollContentBackground('hidden')`](modifiers/#scrollcontentbackgroundvisible)，这样 sheet 颜色才能透过分组背景显示出来。

  title="BottomSheetBackgroundColorExample.tsx"

  alt="一个处于中等 detent、具有纯白背景的底部弹窗">

```tsx

import {
```

### 颜色方案

底部弹窗默认跟随设备的浅色或深色外观。若要改用应用的外观，请将 [`preferredColorScheme`](modifiers/#preferredcolorschemecolorscheme) 修饰器添加到 `Group`。`Host` 的 `colorScheme` 属性会更改弹窗内容的外观，但不会更改其背景。

```tsx BottomSheetColorSchemeExample.tsx
import { useState } from 'react';
import {
  Host,
  BottomSheet,
  Button,
  Group,
  Text,
  VStack,
} from '@expo/ui/swift-ui';
import {
  padding,
  preferredColorScheme,
  presentationDetents,
} from '@expo/ui/swift-ui/modifiers';

export default function BottomSheetColorSchemeExample() {
  const [isPresented, setIsPresented] = useState(false);
  const appearance = 'dark';

  return (
    <Host style={{ flex: 1 }} colorScheme={appearance}>
      <VStack>
        <BottomSheet
          isPresented={isPresented}
          onIsPresentedChange={setIsPresented}
          anchor={
            <Button
              label="Open sheet"
              onPress={() => setIsPresented(true)}
            />
          }>
          <Group
            modifiers={[
              presentationDetents(['medium']),
              preferredColorScheme(appearance),
            ]}>
            <VStack modifiers={[padding({ all: 20 })]}>
              <Text>This sheet is always dark.</Text>
            </VStack>
          </Group>
        </BottomSheet>
      </VStack>
    </Host>
  );
}
```

### 带有 presentation detents 的底部弹窗

在 `Group` 上使用 [`presentationDetents`](modifiers/#presentationdetentsdetents-options) 修饰器来控制可用高度。你可以使用：

- `'medium'`：系统中等高度（约半屏）
- `'large'`：系统大高度（全屏）
- `{ fraction: number }`：屏幕高度的比例（0-1）
- `{ height: number }`：以点为单位的固定高度

<ComponentExample
  title="BottomSheetWithDetentsExample.tsx"

### 跟踪 detent 选择的底部弹窗

将 `selection` 和 `onSelectionChange` 选项传给 [`presentationDetents`](modifiers/#presentationdetentsdetents-options)，即可通过编程方式控制弹窗吸附到哪个锚点。

<ComponentExample
  title="BottomSheetWithDetentSelectionExample.tsx"
  src="/static/images/expo-ui/examples/bottomsheet-detent-selection-ios-light.webp"
  darkSrc="/static/images/expo-ui/examples/bottomsheet-detent-selection-ios-dark.webp"
  alt="一个列出 detent 选项的底部弹窗，当前 detent 显示为 medium">

```tsx
import { useState } from 'react';
import {
  Host,
  BottomSheet,
  Button,
  List,
  Section,
  Text,
  VStack,
  Group,
} from '@expo/ui/swift-ui';
import {
  presentationDetents,
  presentationDragIndicator,
  foregroundStyle,
} from '@expo/ui/swift-ui/modifiers';
import type { PresentationDetent } from '@expo/ui/swift-ui/modifiers';

export default function BottomSheetWithDetentSelectionExample() {
  const [isPresented, setIsPresented] = useState(false);
  const detents: PresentationDetent[] = [
    { height: 300 },
    { fraction: 0.3 },
    'medium',
    'large',
  ];
  const [selectedDetent, setSelectedDetent] =
    useState<PresentationDetent>('medium');

  const formatDetent = (detent: PresentationDetent): string => {
    if (typeof detent === 'string') return detent;
    if ('fraction' in detent) return `分数 ${detent.fraction}`;
    return `高度 ${detent.height}`;
  };

  return (
    <Host style={{ flex: 1 }}>
      <VStack>
        <BottomSheet
          isPresented={isPresented}
          onIsPresentedChange={setIsPresented}
          anchor={
            <Button
              label="Show sheet"
              onPress={() => setIsPresented(true)}
            />
          }>
          <Group
            modifiers={[
              presentationDetents(detents, {
                selection: selectedDetent,
                onSelectionChange: setSelectedDetent,
              }),
              presentationDragIndicator('visible'),
            ]}>
            <List>
              <Section title="Change detent">
                <Button
                  label="Height 300"
                  onPress={() => setSelectedDetent({ height: 300 })}
                />
                <Button
                  label="Fraction 0.3"
                  onPress={() =>
                    setSelectedDetent({ fraction: 0.3 })
                  }
                />
                <Button
                  label="Medium"
                  onPress={() => setSelectedDetent('medium')}
                />
                <Button
                  label="Large"
                  onPress={() => setSelectedDetent('large')}
                />
              </Section>
              <Section title="Current">
                <Text
                  modifiers={[foregroundStyle('secondaryLabel')]}>
                  {formatDetent(selectedDetent)}
                </Text>
              </Section>
            </List>
          </Group>
        </BottomSheet>
      </VStack>
    </Host>
  );
}
```

</ComponentExample>

### 在底部弹窗中使用 React Native 内容

使用 `RNHostView` 在底部弹窗中嵌入 React Native 组件。设置 `matchContents` 可自动调整宿主视图大小以适配其内容。

### 可滚动的 React Native 内容

将可滚动的 React Native 列表（如 `FlatList`、`ScrollView`，或像 [FlashList](https://shopify.github.io/flash-list/) 或 [Legend List](https://github.com/LegendApp/legend-list) 这样的高性能列表）嵌套在带有 `RNHostView` 的弹窗中。使用 [`presentationDetents`](modifiers/#presentationdetentsdetents-options) 设置弹窗高度，列表会在该高度内滚动。

```tsx
          anchor={
            <Button
              label="Open sheet"
              onPress={() => setIsPresented(true)}
            />
          }>
          <Group
            modifiers={[
              presentationDetents(['medium', 'large']),
              presentationDragIndicator('visible'),
            ]}>
            <RNHostView>
              <View style={{ padding: 16 }}>
                <FlatList
                  data={DATA}
                  keyExtractor={item => item}
                  renderItem={({ item }) => (
                    <RNText
                      style={{
                        paddingVertical: 16,
                        color: PlatformColor('label'),
                      }}>
                      {item}
                    </RNText>
                  )}
                />
              </View>
            </RNHostView>
          </Group>
        </BottomSheet>
      </VStack>
    </Host>
  );
}
```
