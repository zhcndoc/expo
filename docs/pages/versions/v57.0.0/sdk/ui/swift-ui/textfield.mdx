## 用法

### 非受控文本输入框

将一个 [`useNativeState`](usenativestate) 可观察对象绑定到 `text`。该输入框会自行跟踪用户输入，你可以从 `textState.value` 读取当前值。

<ComponentExample
  title="BasicTextFieldExample.tsx"
  src="/static/images/expo-ui/examples/textfield-basic-ios-light.webp"
  darkSrc="/static/images/expo-ui/examples/textfield-basic-ios-dark.webp"
  alt="显示占位符 Username 的空文本输入框">

```tsx
import { Host, TextField, useNativeState } from '@expo/ui/swift-ui';

export default function BasicTextFieldExample() {
  const textState = useNativeState('');

  // A text field stretches to the width it is given, so give the host a size.
  return (
    <Host style={{ flex: 1 }}>
      <TextField placeholder="Username" text={textState} />
    </Host>
  );
}
```

</ComponentExample>

### 受控文本输入框

传入一个 `onTextChange` worklet 来转换或验证输入，并将结果写回 [`useNativeState`](usenativestate) 可观察状态。下面的示例会在输入时将文本转换为大写。

> **注意：** Worklet 需要安装 [`react-native-worklets`](https://docs.swmansion.com/react-native-worklets/)。

<ComponentExample
  title="ControlledTextFieldExample.tsx"
  src="/static/images/expo-ui/examples/textfield-controlled-ios-light.webp"
  darkSrc="/static/images/expo-ui/examples/textfield-controlled-ios-dark.webp"
  alt="显示占位符 Name 的空文本输入框">

```tsx
import { Host, TextField, useNativeState } from '@expo/ui/swift-ui';
import { useCallback } from 'react';

export default function ControlledTextFieldExample() {
  const text = useNativeState('');

  const handleTextChange = useCallback(
    (value: string) => {
      'worklet';
      text.value = value.toUpperCase();
    },
    [text]
  );

  return (
    <Host style={{ flex: 1 }}>
      <TextField
        placeholder="Name"
        text={text}
        onTextChange={handleTextChange}
      />
    </Host>
  );
}
```

</ComponentExample>

### 多行文本输入框

设置 `axis="vertical"` 以允许文本输入框垂直扩展。使用 [`lineLimit`](modifiers/#linelimit) modifier 控制可见行数。为 `Host` 指定明确的尺寸，使输入框拥有可供扩展的宽度。

<ComponentExample
  title="MultilineTextFieldExample.tsx"
  src="/static/images/expo-ui/examples/textfield-multiline-ios-light.webp"
  darkSrc="/static/images/expo-ui/examples/textfield-multiline-ios-dark.webp"
  alt="显示占位符 Tell us about yourself 的空多行文本输入框">

```tsx
import { Host, TextField, useNativeState } from '@expo/ui/swift-ui';
import { lineLimit, fixedSize } from '@expo/ui/swift-ui/modifiers';

export default function MultilineTextFieldExample() {
  const textState = useNativeState('');

  return (
    <Host style={{ flex: 1 }}>
      <TextField
        axis="vertical"
        text={textState}
        placeholder="Tell us about yourself..."
        modifiers={[
          lineLimit(5),
          fixedSize({ horizontal: false, vertical: true }),
        ]}
      />
    </Host>
  );
}
```

</ComponentExample>

### 提交处理

使用 [`submitLabel`](modifiers/#submitlabelsubmitlabel) modifier 自定义回车键，并使用 [`onSubmit`](modifiers/#onsubmithandler) 处理提交操作。

<ComponentExample
  title="SubmitHandlingExample.tsx"
  src="/static/images/expo-ui/examples/textfield-submit-ios-light.webp"
  darkSrc="/static/images/expo-ui/examples/textfield-submit-ios-dark.webp"
  alt="显示占位符 Search 的空文本输入框">

```tsx
import { Host, TextField, useNativeState } from '@expo/ui/swift-ui';
import { submitLabel, onSubmit } from '@expo/ui/swift-ui/modifiers';

export default function SubmitHandlingExample() {
  const textState = useNativeState('');

  return (
    <Host style={{ flex: 1 }}>
      <TextField
        placeholder="Search..."
        text={textState}
        modifiers={[
          submitLabel('search'),
          onSubmit(() =>
            console.log('Submitted:', textState.value)
          ),
        ]}
      />
    </Host>
  );
}
```

</ComponentExample>

### 命令式 ref

使用 `ref` 以命令式方式设置文本、聚焦、失焦或选择文本。

> **注意：** `setSelection` 需要 iOS 18.0+ / tvOS 18.0+。其他 ref 方法可在所有受支持的版本上使用。

<ComponentExample
  title="ImperativeRefExample.tsx"
  src="/static/images/expo-ui/examples/textfield-imperative-ios-light.webp"
  darkSrc="/static/images/expo-ui/examples/textfield-imperative-ios-dark.webp"
  alt="一个显示 Select me! 的文本输入框，下方有 Focus、Blur、Set text、Clear 和 Select 按钮">

```tsx
import { useRef } from 'react';
import {
  Host,
  TextField,
  TextFieldRef,
  Button,
  HStack,
  VStack,
  useNativeState,
} from '@expo/ui/swift-ui';
import { buttonStyle } from '@expo/ui/swift-ui/modifiers';

export default function ImperativeRefExample() {
  const ref = useRef<TextFieldRef>(null);
  const textState = useNativeState('选择我！');

  return (
    <Host style={{ flex: 1 }}>
      <VStack spacing={12}>
        <TextField
          ref={ref}
          text={textState}
          placeholder="Imperative field"
        />
        <HStack spacing={12}>
          <Button
            modifiers={[buttonStyle('bordered')]}
            onPress={() => ref.current?.focus()}
            label="聚焦"
          />
          <Button
            modifiers={[buttonStyle('bordered')]}
            onPress={() => ref.current?.blur()}
            label="失焦"
          />
        </HStack>
        <HStack spacing={12}>
          <Button
            modifiers={[buttonStyle('bordered')]}
            onPress={() => ref.current?.setText('SwiftUI 很棒！')}
            label="设置文本"
          />
          <Button
            modifiers={[buttonStyle('bordered')]}
            onPress={() => ref.current?.clear()}
            label="清除"
          />
          <Button
            modifiers={[buttonStyle('bordered')]}
            onPress={() => ref.current?.setSelection(0, 7)}
            label="选择"
          />
        </HStack>
      </VStack>
    </Host>
  );
}
```

</ComponentExample>

### Worklet 文本遮罩

当 `onTextChange` 标记了 `'worklet'` 指令时，它会在 UI 线程上同步运行，因此回调内对 [`useNativeState`](usenativestate) 可观察对象的写入会在下一帧之前生效。键入文本与遮罩后的文本之间不会出现闪烁。下面的示例会在用户输入时对电话号码进行遮罩，并从 worklet 中同时写入 `text` 和 `selection`，以保持光标位于格式化后值的末尾。

> **注意：** Worklet 需要安装 [`react-native-worklets`](https://docs.swmansion.com/react-native-worklets/)。`selection` 属性需要 iOS 18.0+ / tvOS 18.0+。在较旧版本上，worklet 仍然可以更新文本，但无法进行光标定位。

<ComponentExample
  title="WorkletPhoneMaskExample.tsx"
  src="/static/images/expo-ui/examples/textfield-worklet-mask-ios-light.webp"
  darkSrc="/static/images/expo-ui/examples/textfield-worklet-mask-ios-dark.webp"
  alt="显示格式化电话号码占位符的空文本输入框">

```tsx
import { Host, TextField, useNativeState } from '@expo/ui/swift-ui';
import { keyboardType } from '@expo/ui/swift-ui/modifiers';
import { useEffectEvent } from 'react';

export default function WorkletPhoneMaskExample() {
  const phone = useNativeState('');
  const selection = useNativeState({ start: 0, end: 0 });

  const handleTextChange = useEffectEvent((v: string) => {
    'worklet';
    const digits = v.replace(/\D/g, '').slice(0, 10);
    let formatted = digits;
    if (digits.length > 6) {
      formatted = `(${digits.slice(0, 3)}) ${digits.slice(3, 6)}-${digits.slice(6)}`;
    } else if (digits.length > 3) {
      formatted = `(${digits.slice(0, 3)}) ${digits.slice(3)}`;
    }
    if (formatted !== v) {
      phone.value = formatted;
      // Snaps to end for demo. Real masks need smarter cursor handling.
      selection.value = {
        start: formatted.length,
        end: formatted.length,
      };
    }
  });

  return (
    <Host style={{ flex: 1 }}>
      <TextField
        text={phone}
        selection={selection}
        placeholder="(555) 123-4567"
        modifiers={[keyboardType('phone-pad')]}
        onTextChange={handleTextChange}
      />
    </Host>
  );
}
```

</ComponentExample>
