## 用法

### 基本折叠组

`DisclosureGroup` 最常用于 [`Form`](form) 中，这样它就会采用带有展开指示箭头的标准 iOS 列表样式。

<ComponentExample
  title="BasicDisclosureGroupExample.tsx"
  src="/static/images/expo-ui/examples/disclosuregroup-basic-ios-light.webp"
  darkSrc="/static/images/expo-ui/examples/disclosuregroup-basic-ios-dark.webp"
  alt="表单中展开的高级设置组，列出了三行设置">

```tsx
import { useState } from 'react';
import {
  DisclosureGroup,
  Form,
  Host,
  Section,
  Text,
} from '@expo/ui/swift-ui';

export default function BasicDisclosureGroupExample() {
  const [isExpanded, setIsExpanded] = useState(true);
  return (
    <Host style={{ flex: 1 }}>
      <Form>
        <Section>
          <DisclosureGroup
            label="高级设置"
            isExpanded={isExpanded}
            onIsExpandedChange={setIsExpanded}>
            <Text>自动更新应用</Text>
            <Text>应用下载</Text>
            <Text>卸载未使用的应用</Text>
          </DisclosureGroup>
        </Section>
      </Form>
    </Host>
  );
}
```

</ComponentExample>

### 初始展开

将 `isExpanded` 初始设置为 `true`，即可默认显示内容。

<ComponentExample
  title="InitiallyExpandedExample.tsx"
  src="/static/images/expo-ui/examples/disclosuregroup-initially-expanded-ios-light.webp"
  darkSrc="/static/images/expo-ui/examples/disclosuregroup-initially-expanded-ios-dark.webp"
  alt="表单外的 Details 组，展开后显示一行内容">

```tsx
import { useState } from 'react';
import { Host, DisclosureGroup, Text } from '@expo/ui/swift-ui';

export default function InitiallyExpandedExample() {
  const [isExpanded, setIsExpanded] = useState(true);

  // A disclosure group fills the width it is given, so `matchContents` collapses it.
  return (
    <Host style={{ flex: 1 }}>
      <DisclosureGroup
        label="Details"
        isExpanded={isExpanded}
        onIsExpandedChange={setIsExpanded}>
        <Text>This content is visible by default.</Text>
      </DisclosureGroup>
    </Host>
  );
}
```

</ComponentExample>

### 自定义标签

当标签需要自定义 SwiftUI 内容或修饰符，而不是 `label` 字符串属性时，请使用 `DisclosureGroup.Label`。

<ComponentExample
  title="CustomLabelDisclosureGroupExample.tsx"
  src="/static/images/expo-ui/examples/disclosuregroup-custom-label-ios-light.webp"
  darkSrc="/static/images/expo-ui/examples/disclosuregroup-custom-label-ios-dark.webp"
  alt="表单中折叠的组，其标签 Network options 为半粗体青绿色">

```tsx
import { useState } from 'react';
import {
  DisclosureGroup,
  Form,
  Host,
  Section,
  Text,
} from '@expo/ui/swift-ui';
import { font, foregroundStyle } from '@expo/ui/swift-ui/modifiers';

export default function CustomLabelDisclosureGroupExample() {
  const [isExpanded, setIsExpanded] = useState(false);

  return (
    <Host style={{ flex: 1 }}>
      <Form>
        <Section>
          <DisclosureGroup
            isExpanded={isExpanded}
            onIsExpandedChange={setIsExpanded}>
            <DisclosureGroup.Label>
              <Text
                modifiers={[
                  font({ weight: 'semibold' }),
                  foregroundStyle('#0a7ea4'),
                ]}>
                Network options
              </Text>
            </DisclosureGroup.Label>
            <Text>Wi-Fi</Text>
            <Text>蓝牙</Text>
            <Text>蜂窝数据</Text>
          </DisclosureGroup>
        </Section>
      </Form>
    </Host>
  );
}
```

</ComponentExample>
