Expo UI Alert 与官方 SwiftUI [alert API](<https://developer.apple.com/documentation/swiftui/view/alert(_:ispresented:actions:message:)>) 保持一致，并会展示一个原生 iOS 警告对话框，包含标题、操作，以及可选的消息。

`Alert` 是 [`ConfirmationDialog`](confirmationdialog) 的居中模态对应组件，后者会以从屏幕底部弹出的操作表形式渲染。两者共享相同的触发器／操作／消息槽位模型，因此调用方只需更改组件名称即可在它们之间切换。

## 用法

### 基本警告框

使用 `Alert.Trigger` 定义可见元素，使用 `Alert.Actions` 提供对话框按钮。

<ComponentExample
  title="BasicAlertExample.tsx"
  src="/static/images/expo-ui/examples/alert-basic-ios-light.webp"
  darkSrc="/static/images/expo-ui/examples/alert-basic-ios-dark.webp"
  alt="标题为 Saved、包含单个 OK 按钮的 Alert，位于 Show alert 触发器上方">

```tsx
import { useState } from 'react';
import { Host, Alert, Button } from '@expo/ui/swift-ui';

export default function BasicAlertExample() {
  const [isPresented, setIsPresented] = useState(false);

  return (
    <Host style={{ flex: 1 }}>
      <Alert
        title="Saved"
        isPresented={isPresented}
        onIsPresentedChange={setIsPresented}>
        <Alert.Trigger>
          <Button
            label="Show alert"
            onPress={() => setIsPresented(true)}
          />
        </Alert.Trigger>
        <Alert.Actions>
          <Button
            label="OK"
            onPress={() => setIsPresented(false)}
          />
        </Alert.Actions>
      </Alert>
    </Host>
  );
}
```

</ComponentExample>

### 取消与确认

将 `role="cancel"` 与确认按钮结合，构建标准的是否确认警告框。

<ComponentExample
  title="CancelConfirmAlertExample.tsx"
  src="/static/images/expo-ui/examples/alert-cancel-confirm-ios-light.webp"
  darkSrc="/static/images/expo-ui/examples/alert-cancel-confirm-ios-dark.webp"
  alt="标题为 Sign out？包含消息以及 Cancel 和 Sign out 按钮的 Alert">

```tsx
import { useState } from 'react';
import { Host, Alert, Button, Text } from '@expo/ui/swift-ui';

export default function CancelConfirmAlertExample() {
  const [isPresented, setIsPresented] = useState(false);

  return (
    <Host style={{ flex: 1 }}>
      <Alert
        title="Sign out?"
        isPresented={isPresented}
        onIsPresentedChange={setIsPresented}>
        <Alert.Trigger>
          <Button
            label="Sign out"
            onPress={() => setIsPresented(true)}
          />
        </Alert.Trigger>
        <Alert.Actions>
          <Button
            label="Sign out"
            onPress={() => console.log('Signed out')}
          />
          <Button label="Cancel" role="cancel" />
        </Alert.Actions>
        <Alert.Message>
          <Text>
            You will need to sign in again to access your account.
          </Text>
        </Alert.Message>
      </Alert>
    </Host>
  );
}
```

</ComponentExample>

### 危险操作

在 `Alert.Actions` 内的 `Button` 上使用 `role="destructive"`，将其样式设为危险操作。

<ComponentExample
  title="DestructiveAlertExample.tsx"
  src="/static/images/expo-ui/examples/alert-destructive-ios-light.webp"
  darkSrc="/static/images/expo-ui/examples/alert-destructive-ios-dark.webp"
  alt="标题为 Delete account？包含消息、Cancel 按钮和红色 Delete 按钮的 Alert">

```tsx
import { useState } from 'react';
import { Host, Alert, Button, Text } from '@expo/ui/swift-ui';

export default function DestructiveAlertExample() {
  const [isPresented, setIsPresented] = useState(false);

  return (
    <Host style={{ flex: 1 }}>
      <Alert
        title="Delete account?"
        isPresented={isPresented}
        onIsPresentedChange={setIsPresented}>
        <Alert.Trigger>
          <Button
            label="Delete account"
            role="destructive"
            onPress={() => setIsPresented(true)}
          />
        </Alert.Trigger>
        <Alert.Actions>
          <Button
            label="删除"
            role="destructive"
            onPress={() => {
              console.log('已删除');
              setIsPresented(false);
            }}
          />
          <Button label="取消" role="cancel" />
        </Alert.Actions>
        <Alert.Message>
          <Text>
            This permanently deletes your account and all data. This
            cannot be undone.
          </Text>
        </Alert.Message>
      </Alert>
    </Host>
  );
}
```

</ComponentExample>
