`expo-asset` 提供了一个访问 Expo 资源系统的接口。资源是与应用源代码放在一起、并且应用在运行时需要的任何文件。示例包括图片、字体和声音。Expo 的资源系统与 React Native 的资源系统集成，因此你可以使用 `require('path/to/file')` 来引用文件。例如，在 React Native 中，你就是通过这种方式引用静态图片文件，并在 `Image` 组件中使用它们。有关更多信息，请查看 React Native 关于[静态图片资源的文档](https://reactnative.dev/docs/images#static-image-resources)。这种引用静态图片资源的方法可以在 Expo 中开箱即用。

## 应用配置中的配置

如果你在项目中使用 config plugins（[连续原生生成（CNG）](/workflow/continuous-native-generation/)），你可以使用 `expo-asset` 内置的 [配置插件](/config-plugins/introduction/) 进行配置。该插件允许你配置一些无法在运行时设置的属性，并且需要构建新的应用二进制文件后才会生效。如果你的应用**不**使用 CNG，那么你需要手动配置该库。

<ConfigPluginExample>

```json app.json
{
  "expo": {
    "plugins": [
      [
        "expo-asset",
        {
          "assets": ["path/to/file.png", "path/to/directory"]
        }
      ]
    ]
  }
}
```
