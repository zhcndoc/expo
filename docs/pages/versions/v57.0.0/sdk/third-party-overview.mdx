Expo Go 游乐场使学生和学习者能够快速尝试构建原生 Android 和 iOS 应用。它支持一份经过筛选的第三方库列表，这些库由社区驱动，为常见应用功能提供 API，并且会随每个 Expo SDK 版本进行测试。

本节中列出的库与其他任何第三方库的区别在于，前者的支持已内置于 Expo Go 环境中。你可以在开发构建中使用任何你选择的库。
