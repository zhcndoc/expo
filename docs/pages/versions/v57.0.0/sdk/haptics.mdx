`expo-haptics` 为以下平台提供触觉（触摸）反馈：

- 使用 Vibrator 系统服务的 Android 设备。
- 使用 Taptic Engine 的 iOS 10+ 设备。
- 使用 Web Vibration API 的 Web 平台。

在 iOS 上，如果用户设备满足以下任一条件，Taptic 引擎将不会有任何反应：

- 已启用低电量模式。可使用 [`expo-battery`](./battery/) 检测。
- 用户在设置中禁用了 Taptic 引擎。
- iOS 相机处于活动状态（以防止系统不稳定）。
- iOS 听写处于活动状态（以免干扰麦克风输入）。

在 Web 上，该库使用 Web Vibration API。请注意以下几点：

- 浏览器必须支持该 API（请查看 [浏览器兼容性](https://caniuse.com/vibration)）
- 设备必须具备振动硬件
- 用户必须授予使用振动的权限（通常会自动授予）
- 某些浏览器可能会在特定上下文中忽略振动（例如，后台标签页）

> **info** 对于更高级的触觉控制，我们推荐使用 [Pulsar haptics SDK](https://docs.swmansion.com/pulsar/)。它支持创建自定义触觉模式、使用更广泛的预设、构建基于手势的触觉反馈，以及在 worklet 上运行触觉反馈。

## 用法

<SnackInline label='Haptics 用法' dependencies={['expo-haptics']}>

```jsx
import { StyleSheet, View, Text, Button } from 'react-native';
import * as Haptics from 'expo-haptics';

export default function App() {
  return (
    <View style={styles.container}>
      <Text style={styles.text}>Haptics.selectionAsync</Text>
      <View style={styles.buttonContainer}>
        <Button title="选择" onPress={() => /* @info */ Haptics.selectionAsync() /* @end */} />
      </View>
      <Text style={styles.text}>Haptics.notificationAsync</Text>
      <View style={styles.buttonContainer}>
        <Button
          title="成功"
          onPress={
            () =>
              /* @info */ Haptics.notificationAsync(
                Haptics.NotificationFeedbackType.Success
              ) /* @end */
          }
        />
        <Button
          title="错误"
          onPress={
            () =>
              /* @info */ Haptics.notificationAsync(
                Haptics.NotificationFeedbackType.Error
              ) /* @end */
          }
        />
        <Button
          title="警告"
          onPress={
            () =>
              /* @info */ Haptics.notificationAsync(
                Haptics.NotificationFeedbackType.Warning
              ) /* @end */
          }
        />
      </View>
      <Text style={styles.text}>Haptics.impactAsync</Text>
      <View style={styles.buttonContainer}>
        <Button
          title="轻"
          onPress={
            () => /* @info */ Haptics.impactAsync(Haptics.ImpactFeedbackStyle.Light) /* @end */
          }
        />
        <Button
          title="中"
          onPress={
            () => /* @info */ Haptics.impactAsync(Haptics.ImpactFeedbackStyle.Medium) /* @end */
          }
        />
        <Button
          title="重"
          onPress={
            () => /* @info */ Haptics.impactAsync(Haptics.ImpactFeedbackStyle.Heavy) /* @end */
          }
        />
        <Button
          title="刚性"
          onPress={
            () => /* @info */ Haptics.impactAsync(Haptics.ImpactFeedbackStyle.Rigid) /* @end */
          }
        />
        <Button
          title="柔和"
          onPress={
            () => /* @info */ Haptics.impactAsync(Haptics.ImpactFeedbackStyle.Soft) /* @end */
          }
        />
      </View>
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    justifyContent: 'center',
    paddingHorizontal: 16,
  },
  buttonContainer: {
    flexDirection: 'row',
    alignItems: 'stretch',
    marginTop: 10,
    marginBottom: 30,
    justifyContent: 'space-between',
  },
});
```
