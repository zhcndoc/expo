`expo-router` 是一个适用于 React Native 和 web 应用的路由库。它通过基于文件的路由系统来实现导航管理，并提供原生导航组件。

<BoxLink
  title="Expo Router 指南"
  description="了解 Expo Router 的基础知识、导航模式、核心概念等。"
  href="/router/introduction/"
  Icon={BookOpen02Icon}
/>

> **重要** 在 **SDK 56 及更高版本** 中，Expo Router 不再支持在应用代码中从外部的 `@react-navigation/*` 包进行导入。请将这些导入重定向到对应的 `expo-router` 入口点。运行 [codemod](/router/migrate/sdk-55-to-56#automated-migration) 或按照 [SDK 55 到 56 迁移指南](/router/migrate/sdk-55-to-56) 更新你的项目。

## 应用配置中的配置

如果你使用 [默认](/more/create-expo/#--template) 模板来创建新项目，`expo-router` 的 [配置插件](/config-plugins/introduction/) 已经在你的应用配置中完成配置。
