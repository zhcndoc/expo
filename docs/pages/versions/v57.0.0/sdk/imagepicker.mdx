`expo-image-picker` 提供了访问系统 UI 的能力，用于从手机相册中选择图片和视频，或使用相机拍照。

## 已知问题&ensp;<PlatformTags platforms={['ios']} />

在 iOS 上，当从相机胶卷中选择一张图像（通常是[更高分辨率](https://openradar.me/49866214)的图像）时，在某些情况下，裁剪图像的结果会为裁剪矩形提供错误的值。遗憾的是，此问题源于底层的 `UIImagePickerController`，这是由 iOS 内置的闭源工具中的一个错误导致的。

## app config 中的配置

如果你在项目中使用配置插件（[Continuous Native Generation (CNG)](/workflow/continuous-native-generation/)），可以使用 `expo-image-picker` 内置的[配置插件](/config-plugins/introduction/)进行配置。该插件允许你配置一些无法在运行时设置、且需要构建新的应用二进制文件后才会生效的属性。如果你的应用**没有**使用 CNG，那么你需要手动配置该库。

默认情况下，`expo-image-picker` 会在 Android 上添加 `RECORD_AUDIO` 权限。你可以通过在下面的配置中将 `microphonePermission` 设置为 false 来移除它。

## 用法

<SnackInline label='图像选择器' dependencies={['expo-image-picker']}>

```tsx
import { useState } from 'react';
import { Alert, Button, Image, View, StyleSheet } from 'react-native';
import * as ImagePicker from 'expo-image-picker';

export default function ImagePickerExample() {
  const [image, setImage] = useState<string | null>(null);

  const pickImage = async () => {
    // 启动图片库时无需请求权限。
    // 当 `allowsEditing` 设置为 `false`
    // 且 `videoExportPreset` 为 `'Passthrough'`（默认值）时，需要手动为 iOS 上的视频请求权限，最好在打开选择器之前执行，
    // 这样应用用户在选择视频后就不会因为系统对话框而感到意外。
    // 有关更多详细信息，请参见“调用视频权限”子章节。
    const permissionResult = await ImagePicker.requestMediaLibraryPermissionsAsync();

    if (!permissionResult.granted) {
      Alert.alert('需要权限', '需要访问媒体库的权限。');
      return;
    }

    let result = await ImagePicker.launchImageLibraryAsync({
      mediaTypes: ['images', 'videos'],
      allowsEditing: true,
      aspect: [4, 3],
      quality: 1,
    });

    console.log(result);

    if (!result.canceled) {
      setImage(result.assets[0].uri);
    }
  };

  const takePhoto = async () => {
    // Camera access always requires the user's permission.
    // Taking a photo also requires a device with a camera. The iOS Simulator
    // does not have one, so use a physical device to test this button.
    const permissionResult = await ImagePicker.requestCameraPermissionsAsync();

    if (!permissionResult.granted) {
      Alert.alert('Permission required', 'Permission to access the camera is required.');
      return;
    }

    let result = await ImagePicker.launchCameraAsync({
      allowsEditing: true,
      aspect: [4, 3],
      quality: 1,
    });

    console.log(result);

    if (!result.canceled) {
      setImage(result.assets[0].uri);
    }
  };

  return (
    <View style={styles.container}>
      <Button title="Pick an image from camera roll" onPress={pickImage} />
      <Button title="Take a photo" onPress={takePhoto} />
      {image && <Image source={{ uri: image }} style={styles.image} />}
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    alignItems: 'center',
    justifyContent: 'center',
  },
  image: {
    width: 200,
    height: 200,
  },
});
```

### 为视频调用权限 <PlatformTags platforms={['ios']} />

在 SDK 54 及更高版本中，默认配置会将 `allowsEditing` 保持为 `false`，并将 [`videoExportPreset`](#videoexportpreset) 设置为 `'Passthrough'`。这些设置会因为选择器跳过压缩而立即返回原始资源（包括 HEIC 和 AVIF 文件），但 iOS 需要媒体库权限才能访问原始文件，并且会在用户选择视频后立即显示权限对话框。

为了避免在选择后显示权限对话框，请在打开选择器之前，通过 [`requestMediaLibraryPermissionsAsync`](#imagepickerrequestmedialibrarypermissionsasyncwriteonly) 或 [`useMediaLibraryPermissions`](#usemedialibrarypermissionsoptions) **手动请求媒体库权限**。
