`expo-asset` 为 Expo 的资源系统提供了一个接口。资源是指与应用源代码一起存放、且应用在运行时需要的任何文件。例如图像、字体和声音。Expo 的资源系统与 React Native 的资源系统集成，因此你可以使用 `require('path/to/file')` 引用文件。例如，在 React Native 中，你可以通过这种方式引用静态图像文件，以便在 `Image` 组件中使用。有关更多信息，请查看 React Native 关于[静态图像资源的文档](https://reactnative.dev/docs/images#static-image-resources)。在 Expo 中，这种引用静态图像资源的方式可以直接使用。

## 在应用配置中配置

如果你的项目中使用配置插件（[Continuous Native Generation（CNG）](/workflow/continuous-native-generation/)），则可以使用内置的[配置插件](/config-plugins/introduction/)配置 `expo-asset`。该插件允许你配置各种无法在运行时设置、且需要构建新的应用二进制文件才能生效的属性。如果你的应用**不**使用 CNG，则需要手动配置该库。

<ConfigPluginExample>

```json app.json
{
  "expo": {
    "plugins": [
      [
        "expo-asset",
        {
          "assets": ["path/to/file.png", "path/to/directory"]
        }
      ]
    ]
  }
}
```
