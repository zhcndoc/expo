`expo-router/ui` 是 `expo-router` 库的子模块，导出用于构建自定义标签栏布局的组件和 Hook，而非使用 `expo-router` 提供的默认 [React Navigation](https://reactnavigation.org/) 导航器。

> 有关适用于原生和 Web 应用的基于文件的路由库的更多信息，请参阅 [Expo Router](./index) 参考文档。

## 安装

要在项目中使用 `expo-router/ui`，需要在项目中安装 `expo-router`。请按照 Expo Router 的安装指南进行操作：

<BoxLink
  title="安装 Expo Router"
  description="了解如何在项目中安装 Expo Router。"
  href="/router/installation/"
  Icon={RouterLogo}
/>

## 在 app config 中配置

如果使用 [默认](/more/create-expo/#--template) 模板创建新项目，`expo-router` 的[配置插件](/config-plugins/introduction/)已在 app config 中配置。

<ConfigPluginExample>

```json app.json
{
  "expo": {
    "plugins": ["expo-router"]
  }
}
```

</ConfigPluginExample>
