`expo-router` 是一个适用于 React Native 和 Web 应用的路由库。它通过基于文件的路由系统管理导航，并提供原生导航组件。

<BoxLink
  title="Expo Router guides"
  description="了解 Expo Router 基础知识、导航模式、核心概念等。"
  href="/router/introduction/"
  Icon={RouterLogo}
/>

> **Important** 在 **SDK 56 及更高版本**中，Expo Router 不再支持在应用代码中从外部 `@react-navigation/*` 软件包导入内容。请将这些导入改为对应的 `expo-router` 入口点。运行 [codemod](/router/migrate/sdk-55-to-56#automated-migration)，或遵循 [SDK 55 到 56 迁移指南](/router/migrate/sdk-55-to-56) 更新项目。

## 在应用配置中配置

如果你使用[默认](/more/create-expo/#--template)模板创建新项目，`expo-router` 的[配置插件](/config-plugins/introduction/)已在应用配置中完成配置。

<ConfigPluginExample>

```json app.json
{
  "expo": {
    "plugins": ["expo-router"]
  }
}
```
