> **重要** [`@expo/ui` 提供了 `@react-native-segmented-control/segmented-control` 的即插即用替代方案](./ui/drop-in-replacements/segmentedcontrol)，在 Android 上由 Jetpack Compose 提供支持，在 iOS 上由 SwiftUI 提供支持。

它就像一个更精致的单选按钮，或者用 Apple 的话说：“一种由多个分段组成的水平控件，每个分段都作为一个独立按钮运行”（[来源](https://developer.apple.com/documentation/uikit/uisegmentedcontrol)）。该组件在 iOS 上会渲染为 [`UISegmentedControl`](https://developer.apple.com/documentation/uikit/uisegmentedcontrol)，并在 Android 和 web 上忠实地重现该控件（因为这些平台的标准库中没有对应组件）。
