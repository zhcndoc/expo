> **重要** [`@expo/ui` 提供了一个可直接替换 `@react-native-masked-view/masked-view` 的组件](./ui/drop-in-replacements/maskedview)，由 Android 上的 Jetpack Compose 和 iOS 上的 SwiftUI 提供支持。

`@react-native-masked-view/masked-view` 提供了一个蒙版视图，该视图仅显示与其蒙版元素中渲染的视图重叠的像素。

> **警告** 你的项目中同一时间只能安装 `@react-native-community/masked-view`（已弃用）或 `@react-native-masked-view/masked-view` 中的一个。React Navigation v6 及更高版本需要 `@react-native-masked-view/masked-view`，因此如果你使用的是最新版本的 React Navigation，应改用该软件包。

> **重要** 此库对 Android 的支持为[实验性](/more/release-statuses/#experimental)，你可能会遇到跨平台行为不一致的情况。请将遇到的问题报告至 [`react-native-masked-view` GitHub 仓库](https://github.com/react-native-masked-view/masked-view)。
