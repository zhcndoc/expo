`AuthSession` 通过利用 [WebBrowser](webbrowser.mdx) 和 [Crypto](crypto.mdx)，在你的应用中启用基于 Web 浏览器的身份验证（例如，基于浏览器的 OAuth 流程）。有关实现细节，请参阅此参考文档；有关使用方法，请参阅[身份验证](/guides/authentication/)指南。

> **注意：** `AuthSession` 支持通用的 OAuth 和 OpenID Connect 基于浏览器的身份验证流程。在可用的情况下，我们建议使用由你的身份提供商提供的库，因为它会处理该提供商特有的实现细节。例如，使用 [`@react-native-google-signin/google-signin`](/guides/google-authentication/) 进行 Google 身份验证，使用 [`react-native-fbsdk-next`](/guides/facebook-authentication/) 进行 Facebook 身份验证。有关更多信息，请参阅[身份验证](/develop/authentication/)概览。

### 在独立应用中使用

```json app.json
{
  "expo": {
    "scheme": "mycoolredirect"
  }
}
```

要使深层链接能够返回你的应用，你需要在项目的应用配置中设置 `scheme`，然后构建独立应用（它无法通过更新进行设置）。如果不包含 scheme，身份验证流程将完成，但无法将信息传回你的应用，并且用户必须手动退出身份验证模态框（从而产生一个已取消事件）。

## 基于 Web 浏览器的身份验证流程如何工作

移动应用中基于浏览器的身份验证通常流程如下：

- **发起**：用户按下登录按钮
- **打开 Web 浏览器**：应用打开 Web 浏览器，进入身份验证提供商的登录页面。打开的登录页面 URL 通常包含用于识别应用的信息，以及在成功时重定向到的 URL。_注意：Web 浏览器应与系统 Web 浏览器共享 Cookie，这样如果用户已经在系统浏览器中完成身份验证，就无需再次登录——Expo 的 [WebBrowser](webbrowser.mdx) API 会负责处理此事。_
- **身份验证提供商重定向**：身份验证成功后，身份验证提供商应通过重定向到应用在登录页面查询参数中提供的 URL，将用户重定向回应用（[详细了解移动应用中的链接工作方式](/linking/overview/)），_前提是该 URL 位于允许的重定向 URL 白名单中_。将重定向 URL 加入白名单非常重要，可以防止恶意行为者冒充你的应用。重定向会在 URL 中包含数据（例如用户 ID 和令牌），这些数据可能位于 location hash、查询参数中，或同时位于两者中。
- **应用处理重定向**：应用处理重定向，并从重定向 URL 中解析数据。

## 安全注意事项

- **绝不要将任何密钥放入应用代码中，这样做没有安全的方法！**相反，你应将密钥存储在服务器上，并公开一个端点，由该端点代表客户端发起 API 调用并传回数据。

## 高级用法

### 在 Linking 处理程序中过滤 AuthSession 事件

你可能希望处理传入应用的链接的原因有很多，例如推送通知或常规深层链接（你可以在 [Linking](/linking/overview/) 中了解更多信息）；身份验证重定向只是深层链接的一种类型，而 `AuthSession` 会为你处理这些特定链接。在你自己的 `Linking.addEventListener` 处理程序中，可以通过检查 URL 是否包含 `+expo-auth-session` 字符串来过滤由 `AuthSession` 处理的深层链接——如果包含，则可以忽略它。这是因为 `AuthSession` 会将 `+expo-auth-session` 添加到默认的 `returnUrl` 中；但是，如果你提供了自己的 `returnUrl`，可以考虑添加类似的标识符，以便从其他处理程序中过滤掉 `AuthSession` 事件。

### 与 React Navigation 一起使用

如果你在 React Navigation 中使用深层链接，通过 `Linking.addEventListener` 进行过滤将不够，因为深层链接的[处理方式不同](https://reactnavigation.org/docs/configuring-links/#advanced-cases)。要过滤这些事件，请在链接配置中添加自定义的 `getStateFromPath` 函数，然后按照上述相同方式根据 URL 进行过滤。
