用于在 Jetpack Compose 中渲染 Material Symbol XML 矢量可绘制对象的图标组件。推荐使用 [`@expo/material-symbols`](https://www.npmjs.com/package/@expo/material-symbols) 作为图标来源 — 它将 Google 的 [Material Symbols](https://fonts.google.com/icons) 作为独立的资源子路径提供，因此 Metro 只会打包你实际导入的图标。如需使用其他样式（圆角、锐利、填充）或自定义轴，该软件包的 [CLI](#custom-styles-via-expomaterial-symbols-cli) 可直接将任意变体下载到你的项目中。

## 用法

### 基本图标

直接从 `@expo/material-symbols` 的独立子路径导入任意图标 — 每个图标都会解析为 `Icon` 可原生渲染的 Metro 资源。对于你添加到项目中的本地 XML 文件，请改用 `require()`（见下文的[自定义样式](#custom-styles-via-expomaterial-symbols-cli)）。

<ComponentExample
  title="BasicIcon.tsx"
  src="/static/images/expo-ui/examples/icon-basic-android-light.webp"
  darkSrc="/static/images/expo-ui/examples/icon-basic-android-dark.webp"
  alt="默认尺寸的房屋轮廓图标">

```tsx
import {
  Host,
  Icon,
  useMaterialColors,
} from '@expo/ui/jetpack-compose';
import Home from '@expo/material-symbols/home.xml';

export default function BasicIcon() {
  const colors = useMaterialColors();

  return (
    <Host matchContents>
      <Icon
        source={Home}
        tint={colors.onBackground}
        contentDescription="Home"
      />
    </Host>
  );
}
```

</ComponentExample>

### 带色调的图标

使用 `tint` 属性为图标应用颜色叠加。

<ComponentExample
  title="TintedIcon.tsx"
  src="/static/images/expo-ui/examples/icon-tinted-android-light.webp"
  darkSrc="/static/images/expo-ui/examples/icon-tinted-android-dark.webp"
  alt="以紫色绘制的心形轮廓图标">

```tsx
import { Host, Icon } from '@expo/ui/jetpack-compose';
import Favorite from '@expo/material-symbols/favorite.xml';

export default function TintedIcon() {
  return (
    <Host matchContents>
      <Icon
        source={Favorite}
        tint="#6200ee"
        contentDescription="Favorite"
      />
    </Host>
  );
}
```

</ComponentExample>

### 带尺寸的图标

使用 `size` 属性指定以 dp 为单位的自定义尺寸。

<ComponentExample
  title="SizedIcon.tsx"

  darkSrc="/static/images/expo-ui/examples/icon-sized-android-dark.webp"

```tsx
import {
  Host,
  Icon,
  useMaterialColors,
} from '@expo/ui/jetpack-compose';

export default function SizedIcon() {
  const colors = useMaterialColors();

  return (
    <Host matchContents>
      <Icon
        source={Settings}
        size={48}
        tint={colors.onBackground}
        contentDescription="Settings"

    </Host>
  );
}
```

</ComponentExample>

### 通过 `@expo/material-symbols` CLI 使用自定义样式

`@expo/material-symbols` 提供默认轴的**轮廓**样式。需要其他样式（`rounded`、`sharp`）、填充变体，或自定义粗细、等级或光学尺寸时，可使用其 CLI 从 Google Fonts 直接获取指定的可绘制对象并下载到你的项目中。

<Terminal
  cmd={[
    '# 按名称下载图标（默认值：outlined、粗细 400、24px）',
    '$ npx @expo/material-symbols star home',
    '',
    '# 圆角样式',
    '$ npx @expo/material-symbols --style rounded star home',
    '',
    '# 锐利 + 填充',
    '$ npx @expo/material-symbols --style sharp --fill favorite',
    '',
    '# 粘贴 fonts.google.com/icons 上的 URL，以保留你在那里选择的轴',
    '$ npx @expo/material-symbols "https://fonts.google.com/icons?selected=Material+Symbols+Outlined:check_box:FILL@1;wght@300;GRAD@0;opsz@24"',
  ]}
/>

| 选项                  | 说明                                     | 默认值     |
| --------------------- | ---------------------------------------- | ---------- |
| `-o, --output <dir>`  | 输出目录                                 | `./assets` |
| `-s, --style <style>` | 图标样式：`outlined`、`rounded`、`sharp` | `outlined` |
| `-f, --fill`          | 使用填充变体                             |            |
| `-w, --weight <wght>` | 粗细：`100`–`700`                        | `400`      |
| `-g, --grade <grad>`  | 等级：`-25`、`0`、`200`                  | `0`        |
| `--opsz <size>`       | 光学尺寸：`20`、`24`、`40`、`48`         | `24`       |

CLI 会将可直接使用的 XML 矢量可绘制对象写入你的项目。使用 `require()` 加载它们并传递给 `Icon`。

<ComponentExample
  title="CustomIcon.tsx"
  src="/static/images/expo-ui/examples/icon-custom-android-light.webp"
  darkSrc="/static/images/expo-ui/examples/icon-custom-android-dark.webp"
  alt="使用 Material Symbols 命令行工具下载的圆角星形轮廓图标">

```tsx
import {
  Host,
  Icon,
  useMaterialColors,
} from '@expo/ui/jetpack-compose';

export default function CustomIcon() {
  const colors = useMaterialColors();

  return (
    <Host matchContents>
      <Icon
        source={require('./assets/star_rounded.xml')}
        size={32}
        tint={colors.onBackground}
        contentDescription="Star"
      />
    </Host>
  );
}
```

</ComponentExample>
