## 用法

### 基本延迟加载列

[`LazyColumn`](#lazycolumn) 的每个子项都是一行。使用 `verticalArrangement` 属性设置行之间的间距，使用 `contentPadding` 属性为列表内容添加内边距。

<ComponentExample
  title="BasicLazyColumn.tsx"
  src="/static/images/expo-ui/examples/lazycolumn-static-android-light.webp"
  darkSrc="/static/images/expo-ui/examples/lazycolumn-static-android-dark.webp"
  alt="包含三个设置行的列表，每行都有标题和描述">

```tsx
import {
  Host,
  LazyColumn,
  ListItem,
  Text,
} from '@expo/ui/jetpack-compose';

export default function BasicLazyColumn() {
  return (
    <Host style={{ height: 400 }}>
      <LazyColumn verticalArrangement={{ spacedBy: 8 }}>
        <ListItem>
          <ListItem.HeadlineContent>
            <Text>Wi-Fi</Text>
          </ListItem.HeadlineContent>
          <ListItem.SupportingContent>
            <Text>Connected to Home</Text>
          </ListItem.SupportingContent>
        </ListItem>
        <ListItem>
          <ListItem.HeadlineContent>
            <Text>Bluetooth</Text>
          </ListItem.HeadlineContent>
          <ListItem.SupportingContent>
            <Text>On</Text>
          </ListItem.SupportingContent>
        </ListItem>
        <ListItem>
          <ListItem.HeadlineContent>
            <Text>Notifications</Text>
          </ListItem.HeadlineContent>
          <ListItem.SupportingContent>
            <Text>Allowed for all apps</Text>
          </ListItem.SupportingContent>
        </ListItem>
      </LazyColumn>
    </Host>
  );
}
```

</ComponentExample>

### 大型列表

使用 [`LazyColumn.Items`](#lazyitems) 从数组渲染行。将项目作为 `data` 传入，使用 `keyExtractor` 为每个项目提供唯一键，并传入一个返回项目行的 `children` 函数。`LazyColumn.Items` 只渲染可见区域附近的行，并在滚动时复用这些行。

<ComponentExample
  title="LargeLazyColumn.tsx"
  src="/static/images/expo-ui/examples/lazycolumn-large-android-light.webp"
  darkSrc="/static/images/expo-ui/examples/lazycolumn-large-android-dark.webp"
  alt="显示一万名联系人的前七行的可滚动列表">

```tsx
import {
  Host,
  LazyColumn,
  ListItem,
  Text,
} from '@expo/ui/jetpack-compose';

type Contact = { id: string; name: string };

const contacts: Contact[] = Array.from(
  { length: 10000 },
  (_, i) => ({
    id: String(i),
    name: `Contact ${i + 1}`,
  })
);

function renderContact({ item }: { item: Contact }) {
  return (
    <ListItem>
      <ListItem.HeadlineContent>
        <Text>{item.name}</Text>
      </ListItem.HeadlineContent>
    </ListItem>
  );
}

export default function LargeLazyColumn() {
  return (
    <Host style={{ height: 400 }}>
      <LazyColumn>
        <LazyColumn.Items
          data={contacts}
          keyExtractor={contact => contact.id}>
          {renderContact}
        </LazyColumn.Items>
      </LazyColumn>
    </Host>
  );
}
```

</ComponentExample>

### 设置排列方式

使用 `verticalArrangement` 属性控制列表中各项之间的间距。传入 `'spaceBetween'` 这样的字符串值，或传入 `{ spacedBy: 8 }` 这样的对象，以设置固定的 dp 间距。

<ComponentExample
  title="LazyColumnArrangement.tsx"
  src="/static/images/expo-ui/examples/lazycolumn-arrangement-android-light.webp"
  darkSrc="/static/images/expo-ui/examples/lazycolumn-arrangement-android-dark.webp"
  alt="三个列表项之间有八个密度无关像素的间隔">

```tsx
import {
  Host,
  LazyColumn,
  ListItem,
  Text,
} from '@expo/ui/jetpack-compose';

export default function LazyColumnArrangement() {
  return (
    <Host style={{ height: 400 }}>
      <LazyColumn
        verticalArrangement={{ spacedBy: 8 }}
        horizontalAlignment="center">
        <ListItem>
          <ListItem.HeadlineContent>
            <Text>Spaced Item 1</Text>
          </ListItem.HeadlineContent>
        </ListItem>
        <ListItem>
          <ListItem.HeadlineContent>
            <Text>Spaced Item 2</Text>
          </ListItem.HeadlineContent>
        </ListItem>
        <ListItem>
          <ListItem.HeadlineContent>
            <Text>Spaced Item 3</Text>
          </ListItem.HeadlineContent>
        </ListItem>
      </LazyColumn>
    </Host>
  );
}
```

</ComponentExample>

### 设置内容内边距

使用 `contentPadding` 属性为列表内容添加 dp 单位的内边距。

<ComponentExample
  title="LazyColumnPadding.tsx"
  src="/static/images/expo-ui/examples/lazycolumn-padding-android-light.webp"
  darkSrc="/static/images/expo-ui/examples/lazycolumn-padding-android-dark.webp"
  alt="三个列表项通过内容内边距与列表边缘保持间隔">

```tsx
import {
  Host,
  LazyColumn,
  ListItem,
  Text,
} from '@expo/ui/jetpack-compose';

export default function LazyColumnPadding() {
  return (
    <Host style={{ height: 400 }}>
      <LazyColumn
        contentPadding={{ start: 16, top: 8, end: 16, bottom: 8 }}>
        <ListItem>
          <ListItem.HeadlineContent>
            <Text>Padded item 1</Text>
          </ListItem.HeadlineContent>
        </ListItem>
        <ListItem>
          <ListItem.HeadlineContent>
            <Text>Padded item 2</Text>
          </ListItem.HeadlineContent>
        </ListItem>
        <ListItem>
          <ListItem.HeadlineContent>
            <Text>Padded item 3</Text>
          </ListItem.HeadlineContent>
        </ListItem>
      </LazyColumn>
    </Host>
  );
}
```

</ComponentExample>
渲染行时请遵循以下规则：

- 在组件外定义 `children` 函数，或使用 `useCallback` 包装它。否则，每次组件渲染时，可见区域附近的行都会重新渲染。
- 复用的行会保留之前显示项目的本地状态（`useState`）。项目变化时重置状态，或将状态保存在行外部。
- 尚未准备好的行会显示空占位符。将 `estimatedItemSize` 设置为接近行高的值，单位为密度无关像素（dp）。
- 使用 `overscanCount` 在可见行的上方和下方预先准备更多行。
- 要更新行，请传入新的 `data` 数组。不要原地修改数组。
- 设置 `recycling={false}` 可预先渲染每一行。
