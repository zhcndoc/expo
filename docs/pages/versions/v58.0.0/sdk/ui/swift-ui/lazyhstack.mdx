Expo UI LazyHStack 与官方 SwiftUI [LazyHStack API](https://developer.apple.com/documentation/swiftui/lazyhstack) 一致，并沿水平方向排列其子项。

## 用法

### 基本的惰性水平堆栈

应在 `axes="horizontal"` 的 `ScrollView` 内使用 [`LazyHStack`](#lazyhstack)。`LazyHStack` 的每个子项都是一个项目。使用 `spacing` 和 `alignment` 属性设置项目之间的间距和对齐方式。

<ComponentExample
  title="BasicLazyHStackExample.tsx"
  src="/static/images/expo-ui/examples/lazyhstack-static-ios-light.webp"
  darkSrc="/static/images/expo-ui/examples/lazyhstack-static-ios-dark.webp"
  alt="一行水平排列的三个项目，彼此之间有小间距">

```tsx
import {
  Host,
  ScrollView,
  LazyHStack,
  Text,
} from '@expo/ui/swift-ui';

export default function BasicLazyHStackExample() {
  return (
    <Host style={{ flex: 1 }}>
      <ScrollView axes="horizontal">
        <LazyHStack spacing={12}>
          <Text>Photos</Text>
          <Text>Music</Text>
          <Text>Videos</Text>
        </LazyHStack>
      </ScrollView>
    </Host>
  );
}
```

</ComponentExample>

### 大型列表

使用 [`LazyHStack.ForEach`](#lazyhstackforeach) 从数组渲染项目。将项目作为 `data` 传入，使用 `keyExtractor` 为每个项目提供唯一键，并传入一个返回项目视图的 `children` 函数。`LazyHStack.ForEach` 只渲染可见区域附近的项目，并在滚动时复用这些项目。

<ComponentExample
  title="LargeLazyHStackExample.tsx"
  src="/static/images/expo-ui/examples/lazyhstack-large-ios-light.webp"
  darkSrc="/static/images/expo-ui/examples/lazyhstack-large-ios-dark.webp"
  alt="一行水平排列的项目，滚动后会移出屏幕右侧">

```tsx
import {
  Host,
  ScrollView,
  LazyHStack,
  Text,
} from '@expo/ui/swift-ui';

const items = Array.from(
  { length: 10000 },
  (_, i) => `Item ${i + 1}`
);

function renderItem({ item }: { item: string }) {
  return <Text>{item}</Text>;
}

export default function LargeLazyHStackExample() {
  return (
    <Host style={{ flex: 1 }}>
      <ScrollView axes="horizontal">
        <LazyHStack spacing={12}>
          <LazyHStack.ForEach
            data={items}
            keyExtractor={item => item}
            estimatedItemSize={80}>
            {renderItem}
          </LazyHStack.ForEach>
        </LazyHStack>
      </ScrollView>
    </Host>
  );
}
```

</ComponentExample>

渲染项目时请遵循以下规则：

- 在组件外定义 `children` 函数，或使用 `useCallback` 包装它。否则，每次组件渲染时，可见区域附近的项目都会重新渲染。
- 复用的视图会保留之前显示项目的本地状态（`useState`）。项目变化时重置状态，或将状态保存在视图外部。
- 尚未准备好的项目会显示空占位符。将 `estimatedItemSize` 设置为接近项目宽度的值，单位为点。
- 使用 `overscanCount` 在可见项目前后预先准备更多项目。
- 要更新项目，请传入新的 `data` 数组。不要原地修改数组。
- 设置 `recycling={false}` 可预先渲染每个项目。
