Expo UI 的 LazyVStack 与官方 SwiftUI [LazyVStack API](https://developer.apple.com/documentation/swiftui/lazyvstack) 相对应，会垂直排列其子项，并仅在需要时（滚动过程中变为可见时）创建内容

> **info** `LazyVStack` 目前还不是真正的惰性加载：原生端只会构建可见项，但 React 仍会预先创建所有子项，因此大型列表可能需要较长时间才能挂载。我们正在努力改进这一点。对于大型列表，我们推荐使用 [FlashList](https://shopify.github.io/flash-list/) 或 [Legend List](https://github.com/LegendApp/legend-list)。

## 用法

### 基本惰性垂直堆栈

应在 `ScrollView` 中使用 LazyVStack，以启用惰性渲染。

<ComponentExample
  title="BasicLazyVStackExample.tsx"
  src="/static/images/expo-ui/examples/lazyvstack-basic-ios-light.webp"
  darkSrc="/static/images/expo-ui/examples/lazyvstack-basic-ios-dark.webp"
  alt="一个垂直列表，包含编号从零到二十四的项目。">

```tsx
import {
  Host,
  ScrollView,
  LazyVStack,
  Text,
} from '@expo/ui/swift-ui';

export default function BasicLazyVStackExample() {
  return (
    <Host style={{ flex: 1 }}>
      <ScrollView>
        <LazyVStack spacing={12}>
          {Array.from({ length: 100 }, (_, i) => (
            <Text key={i}>{`Item ${i}`}</Text>
          ))}
        </LazyVStack>
      </ScrollView>
    </Host>
  );
}
```

</ComponentExample>

### 使用对齐方式

`alignment` 属性用于控制子项的水平对齐方式。可用选项有：`leading`、`center` 和 `trailing`。

<ComponentExample
  title="LazyVStackAlignmentExample.tsx"
  src="/static/images/expo-ui/examples/lazyvstack-alignment-ios-light.webp"
  darkSrc="/static/images/expo-ui/examples/lazyvstack-alignment-ios-dark.webp"
  alt="三个宽度不同的矩形垂直堆叠，并与前缘对齐。">

```tsx
import {
  Host,
  ScrollView,
  LazyVStack,
  Rectangle,
} from '@expo/ui/swift-ui';
import { frame } from '@expo/ui/swift-ui/modifiers';

export default function LazyVStackAlignmentExample() {
  return (
    <Host
      matchContents={{ vertical: true }}
      style={{ width: '100%' }}>
      <ScrollView>
        <LazyVStack spacing={12} alignment="leading">
          <Rectangle
            modifiers={[frame({ width: 50, height: 50 })]}
          />
          <Rectangle
            modifiers={[frame({ width: 100, height: 50 })]}
          />
          <Rectangle
            modifiers={[frame({ width: 75, height: 50 })]}
          />
        </LazyVStack>
      </ScrollView>
    </Host>
  );
}
```

</ComponentExample>
