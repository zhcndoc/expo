## 用法

### 基础底部工作表

将打开工作表的控件作为 `anchor` 属性传入。子元素就是工作表的内容

<ComponentExample
  title="BasicBottomSheetExample.tsx"
  src="/static/images/expo-ui/examples/bottomsheet-basic-ios-light.webp"
  darkSrc="/static/images/expo-ui/examples/bottomsheet-basic-ios-dark.webp"
  alt="一个充满屏幕的底部工作表，中间显示文本 Hello, world!">

```tsx
import { useState } from 'react';
import {
  Host,
  BottomSheet,
  Button,
  Text,
  VStack,
} from '@expo/ui/swift-ui';

export default function BasicBottomSheetExample() {
  const [isPresented, setIsPresented] = useState(false);

  return (
    <Host style={{ flex: 1 }}>
      <VStack>
        <BottomSheet
          isPresented={isPresented}
          onIsPresentedChange={setIsPresented}
          anchor={
            <Button
              label="Open sheet"
              onPress={() => setIsPresented(true)}
            />
          }>
          <Text>Hello, world!</Text>
        </BottomSheet>
      </VStack>
    </Host>
  );
}
```

### 将 React Native 视图作为锚点

锚点可以是 React Native 视图。请将其包裹在 [`RNHostView`](rnhostview) 中

  alt="底部工作表上方的蓝色 React Native 按钮，工作表大小适应其内容">

```tsx

import {
  Host,
  BottomSheet,
  Button,
  RNHostView,
  Text,
  VStack,
} from '@expo/ui/swift-ui';

  const [isPresented, setIsPresented] = useState(false);

  return (
    <Host style={{ flex: 1 }}>

        <BottomSheet

          onIsPresentedChange={setIsPresented}
          fitToContents
          anchor={
            <RNHostView matchContents>
              <Pressable
                onPress={() => setIsPresented(true)}
                style={{
                  backgroundColor: '#007AFF',
                  padding: 12,
                  borderRadius: 8,
                  alignSelf: 'flex-start',
                }}>
                <RNText
                  style={{ color: 'white', fontWeight: '600' }}>
                  Open sheet
                </RNText>
              </Pressable>
            </RNHostView>
          }>
          <VStack>
            <Text>Opened from a React Native anchor.</Text>
            <Button
              label="Close"
              onPress={() => setIsPresented(false)}
            />
          </VStack>
        </BottomSheet>
      </VStack>
    </Host>
  );
}
```

### 自定义背景

默认情况下，工作表使用系统的半透明材质背景（iOS 26 上为 Liquid Glass）。在 `Group` 上使用 [`presentationBackground`](modifiers/#presentationbackgroundstyle) 修饰符来自定义工作表背景，同时工作表也不会再使用该半透明材质。它接受任何 `ShapeStyle`：纯色、材质或渐变

> **info** iOS 26 会将材质（例如 `{ type: 'material', material: 'ultraThin' }`）渲染为纯色，而不是半透明模糊效果。请选择在不透明状态下也清晰易读的背景

> **info** 建议优先使用 `presentationBackground`，而不是在工作表内容上使用 `background` 修饰符。`background` 位于内容自身背景的后面，因此 `Form` 或 `List` 会覆盖它，并且当工作表在不同 detent 之间移动时，颜色显示也不一致。`presentationBackground` 会直接设置工作表表面的颜色，因此在每个 detent 下都能保持一致。当内容为 `Form` 或 `List` 时，还应添加 [`scrollContentBackground('hidden')`](modifiers/#scrollcontentbackgroundvisible)，以便工作表颜色透过分组背景显示

### 带有 presentation detent 的底部工作表

在 `Group` 上使用 [`presentationDetents`](modifiers/#presentationdetentsdetents-options) 修饰符来控制可用高度。你可以使用：

- `'medium'`：系统中等高度（约为屏幕的一半）
- `'large'`：系统大高度（全屏）
- `{ fraction: number }`：屏幕高度的比例（0-1）
- `{ height: number }`：以点为单位的固定高度

<ComponentExample
  title="BottomSheetWithDetentsExample.tsx"

```tsx
import { useState } from 'react';
import {
  Host,
  BottomSheet,
  Button,
  Group,
  Text,
  VStack,
} from '@expo/ui/swift-ui';
import { presentationDetents } from '@expo/ui/swift-ui/modifiers';

export default function BottomSheetWithDetentsExample() {
  const [isPresented, setIsPresented] = useState(false);

  return (
    <Host style={{ flex: 1 }}>
      <VStack>
        <BottomSheet
          isPresented={isPresented}
          onIsPresentedChange={setIsPresented}
          anchor={
            <Button
              label="Open sheet"
              onPress={() => setIsPresented(true)}
            />
          }>
          <Group
            modifiers={[
              presentationDetents([
                'medium',
                'large',
                { fraction: 0.3 },
                { height: 200 },
              ]),
            ]}>
            <Text>This sheet can snap to multiple heights.</Text>
          </Group>
        </BottomSheet>
      </VStack>
    </Host>
  );
}
```

### 跟踪底部工作表的 detent 选择

将 `selection` 和 `onSelectionChange` 选项传递给 [`presentationDetents`](modifiers/#presentationdetentsdetents-options)，以便以编程方式控制工作表吸附到哪个 detent

<ComponentExample
  title="BottomSheetWithDetentSelectionExample.tsx"
  src="/static/images/expo-ui/examples/bottomsheet-detent-selection-ios-light.webp"
  darkSrc="/static/images/expo-ui/examples/bottomsheet-detent-selection-ios-dark.webp"
  alt="列出 detent 选项的底部工作表，当前 detent 显示为 medium">

```tsx
import { useState } from 'react';
import {
  Host,
  BottomSheet,
  Button,
  List,
  Section,
  Text,
  VStack,
  Group,
} from '@expo/ui/swift-ui';
import {
  presentationDetents,
  presentationDragIndicator,
  foregroundStyle,
} from '@expo/ui/swift-ui/modifiers';
import type { PresentationDetent } from '@expo/ui/swift-ui/modifiers';

export default function BottomSheetWithDetentSelectionExample() {
  const [isPresented, setIsPresented] = useState(false);
  const detents: PresentationDetent[] = [
    { height: 300 },
    { fraction: 0.3 },
    'medium',
    'large',
  ];
  const [selectedDetent, setSelectedDetent] =
    useState<PresentationDetent>('medium');

  const formatDetent = (detent: PresentationDetent): string => {
    if (typeof detent === 'string') return detent;
    if ('fraction' in detent) return `Fraction ${detent.fraction}`;
    return `Height ${detent.height}`;
  };

  return (
    <Host style={{ flex: 1 }}>
      <VStack>
        <BottomSheet
          isPresented={isPresented}
          onIsPresentedChange={setIsPresented}
          anchor={
            <Button
              label="Show sheet"
              onPress={() => setIsPresented(true)}
            />
          }>
          <Group
            modifiers={[
              presentationDetents(detents, {
                selection: selectedDetent,
                onSelectionChange: setSelectedDetent,
              }),
              presentationDragIndicator('visible'),
            ]}>
            <List>
              <Section title="Change detent">
                <Button
                  label="Height 300"
                  onPress={() => setSelectedDetent({ height: 300 })}
                />
                <Button
                  label="Fraction 0.3"
                  onPress={() =>
                    setSelectedDetent({ fraction: 0.3 })
                  }
                />
                <Button
                  label="Medium"
                  onPress={() => setSelectedDetent('medium')}
                />
                <Button
                  label="Large"
                  onPress={() => setSelectedDetent('large')}
                />
              </Section>
              <Section title="Current">
                <Text
                  modifiers={[foregroundStyle('secondaryLabel')]}>
                  {formatDetent(selectedDetent)}
                </Text>
              </Section>
            </List>
          </Group>
        </BottomSheet>
      </VStack>
    </Host>
  );
}
```

</ComponentExample>

### 带有 React Native 内容的底部工作表

### 可滚动的 React Native 内容

使用 `RNHostView` 将可滚动的 React Native 列表（例如 `FlatList`、`ScrollView`，或 [FlashList](https://shopify.github.io/flash-list/)、[Legend List](https://github.com/LegendApp/legend-list) 等高性能列表）嵌套在工作表中。使用 [`presentationDetents`](modifiers/#presentationdetentsdetents-options) 设置工作表大小，列表会在该高度范围内滚动

  PlatformColor,
  Text as RNText,
  View,

  Button,
  Group,
  RNHostView,
  VStack,
} from '@expo/ui/swift-ui';
import {
  presentationDetents,
  presentationDragIndicator,
} from '@expo/ui/swift-ui/modifiers';

const DATA = Array.from({ length: 50 }, (_, i) => `Item ${i + 1}`);

export default function BottomSheetWithScrollableContentExample() {
  const [isPresented, setIsPresented] = useState(false);

  return (
    <Host style={{ flex: 1 }}>
      <VStack>
        <BottomSheet
          isPresented={isPresented}
          onIsPresentedChange={setIsPresented}
          anchor={
            <Button
              label="打开工作表"
              onPress={() => setIsPresented(true)}
            />
          }>
          <Group
            modifiers={[
              presentationDetents(['medium', 'large']),
              presentationDragIndicator('visible'),
            ]}>
            <RNHostView>
              <View style={{ padding: 16 }}>
                <FlatList
                  data={DATA}
                  keyExtractor={item => item}
                  renderItem={({ item }) => (
                    <RNText
                      style={{
                        paddingVertical: 16,
                        color: PlatformColor('label'),
                      }}>
                      {item}
                    </RNText>
                  )}
                />
              </View>
            </RNHostView>
          </Group>
        </BottomSheet>
      </VStack>
    </Host>
  );
}
