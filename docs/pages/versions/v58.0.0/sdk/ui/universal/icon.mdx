一个平台原生图标。在 Android 上，它会渲染 Material Symbol XML vector drawable（推荐来源：[`@expo/material-symbols`](https://www.npmjs.com/package/@expo/material-symbols)）。在 iOS 上，它会渲染 [SF Symbol](https://developer.apple.com/sf-symbols/)。

> **注意：**`Icon` 不会在 web 上渲染

## 安装

<APIInstallSection />

可选安装 [`@expo/material-symbols`](https://www.npmjs.com/package/@expo/material-symbols)，以便在 Android 上使用捆绑的图标。如需不同的样式或自定义轴，请参阅 [Jetpack Compose Icon 页面上的自定义样式](/versions/latest/sdk/ui/jetpack-compose/icon/#custom-styles-via-expomaterial-symbols-cli)——无需安装。

## 用法

### 使用 `Icon.select` 的跨平台图标

[`Icon.select`](#selectspec) 会为当前平台选择正确的资源。将其与 [`@expo/ui/babel-plugin`](https://github.com/expo/expo/tree/main/packages/expo-ui/plugin) 搭配使用（由 `babel-preset-expo` 自动加载），这样 Metro 就能按平台对未使用的一侧进行 tree-shaking。

<ComponentExample

  android={{

```tsx
import { Host, Icon } from '@expo/ui';

export default function IconSelectExample() {
  return (
    <Host matchContents>
      <Icon
        name={Icon.select({
          ios: 'star.fill',
          android: import('@expo/material-symbols/star.xml'),
        })}
        size={32}
        color="orange"
      />
    </Host>
  );
}
```

</ComponentExample>

### 提升 `Icon.select`

在多个调用位置重复使用同一个图标时，将 [`Icon.select`](#selectspec) 调用提升到外部。

<ComponentExample
  title="HoistedIconExample.tsx"
  android={{
    src: '/static/images/expo-ui/examples/universal-icon-hoisted-android-light.webp',
    darkSrc: '/static/images/expo-ui/examples/universal-icon-hoisted-android-dark.webp',

  ios={{

```tsx
import { Host, Row, Icon } from '@expo/ui';

const STAR = Icon.select({
  ios: 'star.fill',
  android: import('@expo/material-symbols/star.xml'),
});

export default function HoistedIconExample() {
  return (
    <Host matchContents>
      <Row spacing={4}>
        <Icon name={STAR} size={20} color="gold" />
        <Icon name={STAR} size={20} color="gold" />
        <Icon name={STAR} size={20} color="gold" />
      </Row>
    </Host>
  );
}
```

</ComponentExample>

### 平台专用文件

在 **.android.tsx** 文件中，直接导入 XML 资源。在 **.ios.tsx** 文件中，将 SF Symbol 名称作为字符串传入。

```tsx Icon.android.tsx
import StarIcon from '@expo/material-symbols/star.xml';
import { Host, Icon } from '@expo/ui';

export default function StarRow() {
  return (
    <Host matchContents>
      <Icon name={StarIcon} size={24} />
    </Host>
  );
}
```

```tsx Icon.ios.tsx
import { Host, Icon } from '@expo/ui';

export default function StarRow() {
  return (
    <Host matchContents>
      <Icon name="star.fill" size={24} />
    </Host>
  );
}
```
