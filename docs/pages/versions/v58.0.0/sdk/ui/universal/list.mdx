`List` 提供一个虚拟化的垂直行容器，通常填充 [`ListItem`](#listitem) 子元素。它提供平台原生的界面样式（分隔线、内嵌样式、下拉刷新）。`ListItem` 是一个可点击的行，带有 `leading`／`trailing`／`supportingText` 插槽。

> **info** `List` 目前还不会延迟渲染行：React 会预先创建每一行，因此大型列表的挂载速度可能较慢。我们正在努力改进这一点。对于大型列表，我们推荐使用 [FlashList](https://shopify.github.io/flash-list/) 或 [Legend List](https://github.com/LegendApp/legend-list)。

## 原生实现

| 平台    | 底层组件                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| ------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Android | Jetpack Compose [`LazyColumn`](https://developer.android.com/develop/ui/compose/lists#lazy)。当你提供 `onRefresh` 时，`List` 会将其包装在 [`PullToRefreshBox`](<https://developer.android.com/reference/kotlin/androidx/compose/material3/pulltorefresh/package-summary#PullToRefreshBox(kotlin.Boolean,kotlin.Function0,androidx.compose.ui.Modifier,androidx.compose.ui.Alignment,androidx.compose.material3.pulltorefresh.PullToRefreshState,androidx.compose.material3.ExperimentalMaterial3Api,kotlin.Function0)>) 中。 |
| iOS     | SwiftUI [`List`](https://developer.apple.com/documentation/swiftui/list)。当你提供 `onRefresh` 时，`List` 会应用 [`refreshable`](<https://developer.apple.com/documentation/swiftui/view/refreshable(action:)>) 修饰符。                                                                                                                                                                                                                                                                                                     |
| Web     | 带有滚动溢出的 React Native [`View`](https://reactnative.dev/docs/view)。                                                                                                                                                                                                                                                                                                                                                                                                                                                    |

### 基本列表

<ComponentExample
  title="ListExample.tsx"
  android={{
    src: '/static/images/expo-ui/examples/universal-list-basic-android-light.webp',
    darkSrc: '/static/images/expo-ui/examples/universal-list-basic-android-dark.webp',
    alt: 'Material 3 列表中的三种早餐食品',
  }}
  ios={{
    src: '/static/images/expo-ui/examples/universal-list-basic-ios-light.webp',
    darkSrc: '/static/images/expo-ui/examples/universal-list-basic-ios-dark.webp',
    alt: '分组 iOS 列表中的三种早餐食品',
  }}>

```tsx
import { useState } from 'react';
import { useColorScheme } from 'react-native';
import { Host, List, ListItem, Text } from '@expo/ui';

const ITEMS = [
  { id: 1, name: 'Avocado toast' },
  { id: 2, name: 'Bagel with cream cheese' },
  { id: 3, name: 'Cappuccino' },
];

export default function ListExample() {
  const [selected, setSelected] = useState<string | null>(null);
  const colorScheme = useColorScheme();
  const ink = { color: colorScheme === 'dark' ? '#FFFFFF' : '#000000' };

  return (
    <Host style={{ flex: 1 }}>
      <List>
        {ITEMS.map(item => (
          <ListItem key={item.id} onPress={() => setSelected(item.name)}>
            {item.name}
          </ListItem>
        ))}
      </List>
      {selected != null && <Text textStyle={ink}>{`Selected: ${selected}`}</Text>}
    </Host>
  );
}
```

</ComponentExample>

### 带插槽的行

`ListItem` 接受 `leading`、`trailing` 和 `supportingText` 简写属性，用于常见场景。当需要更丰富的内容时，为其中任意属性传入一个 `ReactNode`。

  ios={{

```tsx
import { Host, Icon, List, ListItem } from '@expo/ui';

const CHEVRON = Icon.select({
  ios: 'chevron.right',
  android: require('@expo/material-symbols/chevron_right.xml'),
});

export default function ListItemSlotsExample() {
  return (
    <Host style={{ flex: 1 }}>
      <List>
        <ListItem
          onPress={() => {}}
          trailing={<Icon name={CHEVRON} size={14} color="gray" />}
          supportingText="Secondary line below the headline">
          Profile
        </ListItem>
        <ListItem onPress={() => {}} trailing={<Icon name={CHEVRON} size={14} color="gray" />}>

}
```

### 复合插槽子元素

要完全控制插槽内容，请使用复合 API：`<ListItem.Leading>`、`<ListItem.Trailing>` 和 `<ListItem.Supporting>`。任何未包裹在插槽中的内容都会成为标题。

<ComponentExample
  title="ListItemCompoundExample.tsx"
  android={{
    src: '/static/images/expo-ui/examples/universal-list-compound-android-light.webp',
    darkSrc: '/static/images/expo-ui/examples/universal-list-compound-android-dark.webp',
    alt: '一个带星形图标、复合标题和辅助文本的行',
  }}
  ios={{
    src: '/static/images/expo-ui/examples/universal-list-compound-ios-light.webp',
    darkSrc: '/static/images/expo-ui/examples/universal-list-compound-ios-dark.webp',
    alt: '一个带星形图标、复合标题和辅助文本的行',
  }}>

```tsx
import { useColorScheme } from 'react-native';
import { Host, Icon, List, ListItem, Row, Text } from '@expo/ui';

const STAR = Icon.select({
  ios: 'star.fill',
  android: require('@expo/material-symbols/star.xml'),
});

export default function ListItemCompoundExample() {
  const colorScheme = useColorScheme();
  const ink = { color: colorScheme === 'dark' ? '#FFFFFF' : '#000000' };

  return (
    <Host style={{ flex: 1 }}>
      <List>
        <ListItem onPress={() => {}}>
          <ListItem.Leading>
            <Icon name={STAR} size={20} color="#FFD60A" />
          </ListItem.Leading>
          <Row spacing={0}>
            <Text textStyle={{ color: 'gray' }}>{`#42: `}</Text>
            <Text textStyle={ink}>Composite headline</Text>
          </Row>
          <ListItem.Supporting>Richer slot content</ListItem.Supporting>
        </ListItem>
      </List>
    </Host>
  );
}
```

</ComponentExample>

### 下拉刷新

传入一个 `async` `onRefresh` 处理函数。平台原生的刷新指示器会一直显示，直到返回的 promise 完成（resolve 或 reject）。

<ComponentExample
  title="ListRefreshExample.tsx"
  android={{
    src: '/static/images/expo-ui/examples/universal-list-refresh-android-light.webp',
    darkSrc: '/static/images/expo-ui/examples/universal-list-refresh-android-dark.webp',
    alt: '包含三个编号项目的列表',
  }}
  ios={{
    src: '/static/images/expo-ui/examples/universal-list-refresh-ios-light.webp',
    darkSrc: '/static/images/expo-ui/examples/universal-list-refresh-ios-dark.webp',
    alt: '包含三个编号项目的列表',
  }}>

```tsx
import { useState } from 'react';
import { Host, List, ListItem } from '@expo/ui';

export default function ListRefreshExample() {
  const [items, setItems] = useState([1, 2, 3]);

  const handleRefresh = async () => {
    await new Promise(resolve => setTimeout(resolve, 1500));
    setItems(prev => [Math.max(...prev) + 1, ...prev]);
  };

  return (
    <Host style={{ flex: 1 }}>
      <List onRefresh={handleRefresh}>
        {items.map(id => (
          <ListItem key={id}>{`Item #${id}`}</ListItem>
        ))}
      </List>
    </Host>
  );
}
```

</ComponentExample>

> 下拉刷新目前尚未在 Web 上实现。为保持 API 一致性，处理函数会被接受，但指示器只会在 Android 和 iOS 上显示
