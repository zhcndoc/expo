## API

要导入此库，请使用：

```js
import NetInfo from '@react-native-community/netinfo';
```

如果你只想获取一次网络连接的信息，可以使用：

```js
NetInfo.fetch().then(state => {
  console.log('Connection type', state.type);
  console.log('Is connected?', state.isConnected);
});
```

或者，如果你更希望订阅网络状态更新（这样你就可以在网络状态发生变化时随时运行代码／执行操作），请使用：

```js
const unsubscribe = NetInfo.addEventListener(state => {
  console.log('Connection type', state.type);
  console.log('Is connected?', state.isConnected);
});

// To unsubscribe to these update, just use:
unsubscribe();
```

## 访问 SSID

要访问 `ssid` 属性（位于 `state.details.ssid` 下），还需要完成一些额外的配置步骤：

- 使用 [`Location.requestForegroundPermissionsAsync()`](location.mdx#locationrequestforegroundpermissionsasync) 或 [`Location.requestBackgroundPermissionsAsync()`](location.mdx#locationrequestbackgroundpermissionsasync) 请求位置权限。

### 仅限 iOS

- 在 **app.json** 的 `ios.entitlements` 下添加 `com.apple.developer.networking.wifi-info` 权限：

  ```json app.json
    "ios": {
      "entitlements": {
        "com.apple.developer.networking.wifi-info": true
      }
    }
  ```

- 在你的应用 App Identifier 中勾选 **Access Wi-Fi Information**， [可在此处找到该选项](https://developer.apple.com/account/resources/identifiers/list)。
- 使用 [`eas build --platform ios`](/build/setup/#run-a-build) 或 [`npx expo run:ios`](/more/expo-cli/#compiling) 重新构建你的应用。
