> **重要提示** 为了更快地发布更新，`expo-calendar` 目前不受 Expo Go 和 Snack 支持。要使用它，请创建一个[开发构建](/develop/development-builds/introduction/#how-would-you-like-to-build-your-development-build)。

`expo-calendar` 提供了一个 API，可用于与设备的系统日历、事件、提醒事项及相关记录进行交互。

此外，它还提供了用于启动系统提供的日历 UI 的方法，让用户查看或编辑事件。在 iOS 上，这些方法会以模态形式呈现 [`EKEventViewController`](https://developer.apple.com/documentation/eventkitui/ekeventviewcontroller) 或 [`EKEventEditViewController`](https://developer.apple.com/documentation/eventkitui/ekeventeditviewcontroller)。

## 在应用配置中进行配置

如果项目中使用了配置插件（[Continuous Native Generation（CNG）](/workflow/continuous-native-generation/)），则可以使用内置的[配置插件](/config-plugins/introduction/)来配置 `expo-calendar`。此插件允许你配置各种无法在运行时设置、且必须重新构建应用二进制文件才能生效的属性。如果应用**不**使用 CNG，则需要手动配置此库。

若要本地化 iOS 日历或提醒事项的权限提示信息，请将对应的使用说明键添加到每个[语言环境文件](/guides/localization/#translating-app-metadata)的 `ios` 对象中。`calendarPermission` 属性会同时设置 `NSCalendarsUsageDescription` 和 `NSCalendarsFullAccessUsageDescription`，而 `remindersPermission` 会同时设置 `NSRemindersUsageDescription` 和 `NSRemindersFullAccessUsageDescription`。Expo 会在预构建期间将本地化值写入 **InfoPlist.strings**。

<ConfigReactNative>

如果你未使用 Continuous Native Generation（[CNG](/workflow/continuous-native-generation/)）（而是手动使用原生 **ios** 项目），则需要在原生项目中配置以下权限：

- 对于 iOS，请将 `NSCalendarsUsageDescription`、`NSCalendarsFullAccessUsageDescription` 和 `NSRemindersUsageDescription` 添加到项目的 **ios/[app]/Info.plist** 中：

  ```xml
  <key>NSCalendarsUsageDescription</key>
  <string>Allow $(PRODUCT_NAME) to access your calendar</string>
  <key>NSCalendarsFullAccessUsageDescription</key>
  <string>Allow $(PRODUCT_NAME) to access your calendar</string>
  <key>NSRemindersUsageDescription</key>
  <string>Allow $(PRODUCT_NAME) to access your reminders</string>
  ```

  在 iOS 17+ 上请求仅写入日历权限时，请添加 `NSCalendarsWriteOnlyAccessUsageDescription`，而不是 `NSCalendarsFullAccessUsageDescription`：

  ```xml
  <key>NSCalendarsWriteOnlyAccessUsageDescription</key>
  <string>Allow $(PRODUCT_NAME) to add events to your calendars</string>
  ```

## 用法

```jsx
import * as Calendar from 'expo-calendar';
import { useEffect } from 'react';
import { StyleSheet, View, Text, Button } from 'react-native';

const BasicUsage = () => {
  useEffect(() => {
    (async () => {
      const { status } = await Calendar.requestCalendarPermissions();
      if (status === 'granted') {
        const calendars = Calendar.getCalendars(Calendar.EntityTypes.EVENT);
        console.log('Here are all your calendars:');
        console.log(JSON.stringify(calendars));
      }
    })();
  }, []);

  return (
    <View style={styles.container}>
      <Text>Calendar Module Example</Text>
      <Button title="Create a new calendar" onPress={createCalendar} />
    </View>
  );
};

async function createCalendar() {
  const newCalendar = await Calendar.createCalendar({
    title: 'Expo Calendar',
    color: 'blue',
    entityType: Calendar.EntityTypes.EVENT,
  });
  console.log(`Your new calendar: ${JSON.stringify(newCalendar)}`);
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    backgroundColor: '#fff',
    alignItems: 'center',
    justifyContent: 'space-around',
  },
});
```

## 权限

### Android

如果你只打算使用系统提供的日历 UI，则无需请求任何权限。

否则，必须将以下权限添加到 **app.json** 中的 [`expo.android.permissions`](../config/app/#permissions) 数组中。

<AndroidPermissions permissions={['READ_CALENDAR', 'WRITE_CALENDAR']} />

### iOS

如果只需添加事件而不读取现有日历数据，请在[配置插件](#configuration-in-app-config)中启用 `writeOnlyAccess` 选项，并将 `true` 传递给 [`requestCalendarPermissions`](#calendarrequestcalendarpermissionswriteonly) 以请求仅写入权限。这足以用于 [`ExpoCalendar.createEvent`](#createeventdetails) 等方法。读取日历数据的方法（例如 [`getCalendars`](#calendargetcalendarsentitytype)、[`listEvents`](#calendarlisteventscalendars-startdate-enddate) 或 [`presentPicker`](#calendarpresentpicker)）则需要完整的日历访问权限。
