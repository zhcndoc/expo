`expo-linear-gradient` 提供一个原生 React 视图，可沿线性方向在多种颜色之间进行渐变。

> **信息** React Native 还为 `View` 组件提供了 `experimental_backgroundImage`（Android 和 iOS）和 `backgroundImage`（Web）样式属性，支持 CSS 渐变语法，例如 [`linear-gradient()`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/gradient/linear-gradient) 和 [`radial-gradient()`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/gradient/radial-gradient)。无需添加额外依赖，即可使用此功能替代渐变背景。由于这是一个实验性属性，如果遇到任何问题，请[向 React Native 仓库报告](https://github.com/facebook/react-native/issues)。

## 用法

<SnackInline label='线性渐变' dependencies={['expo-linear-gradient']}>

```tsx
import { StyleSheet, Text, View } from 'react-native';
import { LinearGradient } from 'expo-linear-gradient';

export default function App() {
  return (
    <View style={styles.container}>
      <LinearGradient
        // Background Linear Gradient
        colors={['rgba(0,0,0,0.8)', 'transparent']}
        style={styles.background}
      />
      <LinearGradient
        // Button Linear Gradient
        colors={['#4c669f', '#3b5998', '#192f6a']}
        style={styles.button}>
        <Text style={styles.text}>Sign in with Facebook</Text>
      </LinearGradient>
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    alignItems: 'center',
    justifyContent: 'center',
    backgroundColor: 'orange',
  },
  background: {
    position: 'absolute',
    left: 0,
    right: 0,
    top: 0,
    height: 300,
  },
  button: {
    padding: 15,
    alignItems: 'center',
    borderRadius: 5,
  },
  text: {
    backgroundColor: 'transparent',
    fontSize: 15,
    color: '#fff',
  },
});
```
