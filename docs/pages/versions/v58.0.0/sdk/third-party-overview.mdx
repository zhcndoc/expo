Expo Go playground 让学生和学习者能够快速尝试构建原生 Android 和 iOS 应用。它支持一份精选的第三方库列表，这些库由社区驱动、提供常见应用功能的 API，并且会随每个 Expo SDK 版本进行测试。

本节列出的库与其他任何第三方库的区别在于，前者的支持已内置于 Expo Go 环境中。你可以在 development builds 中使用任何自己选择的库。
