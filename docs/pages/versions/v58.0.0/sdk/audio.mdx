`expo-audio` 是一个跨平台音频库，用于访问设备的原生音频功能。

[Android 媒体格式支持文档](https://developer.android.com/media/media3/exoplayer/supported-formats)介绍了在 Android 上使用 Expo Player 时支持的格式。[iOS 音频和视频格式文档](https://developer.apple.com/documentation/coreaudiotypes/audio-format-identifiers)列出了 Apple 设备支持的媒体格式。

请注意，如果耳机／蓝牙音频设备断开连接，音频会自动停止。

### 录制声音

<SnackInline label='录制声音' dependencies={['expo-audio', 'expo-asset']}>

```jsx
import { useState, useEffect } from 'react';
import { View, StyleSheet, Button, Alert } from 'react-native';
import {
  useAudioRecorder,
  AudioModule,
  RecordingPresets,
  setAudioModeAsync,
  useAudioRecorderState,
} from 'expo-audio';

export default function App() {
  const audioRecorder = useAudioRecorder(RecordingPresets.HIGH_QUALITY);
  const recorderState = useAudioRecorderState(audioRecorder);

  const record = async () => {
    await audioRecorder.prepareToRecordAsync();
    audioRecorder.record();
  };

  const stopRecording = async () => {
    // The recording will be available on `audioRecorder.uri`.
    await audioRecorder.stop();
  };

  useEffect(() => {
    (async () => {
      const status = await AudioModule.requestRecordingPermissionsAsync();
      if (!status.granted) {
        Alert.alert('Permission to access microphone was denied');
      }

      setAudioModeAsync({
        playsInSilentMode: true,
        allowsRecording: true,
        // To record in the background, also set allowsBackgroundRecording: true
        // and enable the enableBackgroundRecording config plugin option.
      });
    })();
  }, []);

  return (
    <View style={styles.container}>
      <Button
        title={recorderState.isRecording ? 'Stop recording' : 'Start recording'}
        onPress={recorderState.isRecording ? stopRecording : record}
      />
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    justifyContent: 'center',
    backgroundColor: '#ecf0f1',
    padding: 10,
  },
});
```

</SnackInline>

在 Android 和 iOS 上，`expo-audio` 默认将录音保存到应用的缓存目录中。当设备存储空间不足时，系统可能会删除缓存文件。若要将新录音保存到更持久的位置，请将 `{ ...RecordingPresets.HIGH_QUALITY, directory: 'document' }` 传递给 `useAudioRecorder` 或 `prepareToRecordAsync()`。录音会保存到应用的文档目录中。对于已保存在缓存中的录音，请使用返回的录音 URI，通过 [`expo-file-system`](./filesystem/) 移动文件。

### 在后台播放音频

后台音频播放功能允许应用在切换到后台或设备屏幕锁定时继续播放音频。

#### 配置

要启用后台音频播放，请在[应用配置](/workflow/configuration/)中使用配置插件：

```json app.json
{
  "expo": {
    "plugins": [
      [
        "expo-audio",
        {
          "enableBackgroundPlayback": true
        }
      ]
    ]
  }
}
```

以上配置会自动配置所需的原生设置：

- <PlatformTags platforms={['android']} /> 添加 `FOREGROUND_SERVICE` 和
  `FOREGROUND_SERVICE_MEDIA_PLAYBACK` 权限。还会在应用的 **AndroidManifest.xml** 中声明媒体播放前台服务
  （`AudioControlsService`）。
- <PlatformTags platforms={['ios']} /> 添加 `audio` `UIBackgroundMode` 功能

#### 用法

使用配置插件配置应用后，你需要：

1. **配置音频会话**以允许后台播放
2. **启用锁屏控件**（Android 上持续后台播放所必需）

```jsx
import { View, Button } from 'react-native';
import { useAudioPlayer, setAudioModeAsync } from 'expo-audio';
import { useEffect } from 'react';

export default function AudioPlayerScreen() {
  const audioSource = require('./assets/audio.mp3');
  const player = useAudioPlayer(audioSource);

  useEffect(() => {
    // Configure audio session for background playback
    setAudioModeAsync({
      playsInSilentMode: true,
      shouldPlayInBackground: true,
      interruptionMode: 'doNotMix',
    });
  }, []);

  const handlePlay = () => {
    // Enable lock screen controls with metadata
    player.setActiveForLockScreen(true, {
      title: 'My Audio Title',
      artist: 'Artist Name',
      albumTitle: 'Album Name',
      artworkUrl: 'https://example.com/artwork.jpg', // optional
    });

    // Start playback - this will continue in the background
    player.play();
  };

  const handleStop = () => {
    player.pause();
    // Optionally disable lock screen controls when done
    player.setActiveForLockScreen(false);
  };

  return (
    <View>
      <Button title="Play" onPress={handlePlay} />
      <Button title="Stop" onPress={handleStop} />
    </View>
  );
}
```

<PlatformTags platforms={['android']} />

> **注意**：在 Android 上，要实现持续后台播放，必须通过 [`setActiveForLockScreen`](#setactiveforlockscreenactive-metadata-options) 启用锁屏控件。否则，后台播放约 3 分钟后音频会停止（操作系统限制）。请确保正确[配置配置插件](#configuration-in-app-config)。

- 通知抽屉中会显示带有播放控件的媒体通知
- 音频会在后台持续播放
- 用户可以通过锁屏界面和通知控制播放
- 前台服务会在播放期间维持播放

<PlatformTags platforms={['ios']} />

在 iOS 上，将音频会话配置为 `shouldPlayInBackground: true` 后，音频播放便会在后台无缝持续。锁屏控件为可选项，但可在锁屏界面和控制中心提供播放控件，从而提升用户体验。

<ConfigReactNative>

如果你未使用 Continuous Native Generation（[CNG](/workflow/continuous-native-generation/)）（即手动使用原生 **android** 和 **ios** 项目），则需要进行以下配置以支持后台播放：

- 对于 Android，在 **android/app/src/main/AndroidManifest.xml** 中添加：

  ```xml android/app/src/main/AndroidManifest.xml
  <uses-permission android:name="android.permission.FOREGROUND_SERVICE" />
  <uses-permission android:name="android.permission.FOREGROUND_SERVICE_MEDIA_PLAYBACK" />

  <application>
    <!-- Other application components -->
    <service
      android:name="expo.modules.audio.service.AudioControlsService"
      android:exported="false"
      android:foregroundServiceType="mediaPlayback">
      <intent-filter>
        <action android:name="androidx.media3.session.MediaSessionService" />
      </intent-filter>
    </service>
  </application>
  ```

- 对于 iOS，在 **ios/YourApp/Info.plist** 中添加：

  ```xml ios/YourApp/Info.plist
  <key>UIBackgroundModes</key>
  <array>
    <string>audio</string>
  </array>
  ```

</ConfigReactNative>

### 在后台录制音频

> **警告** 后台录音可能会显著影响电池续航。仅在应用功能需要时启用此功能。

后台音频录制功能允许应用在切换到后台或设备屏幕锁定时继续录制。

要启用后台录制，请在[应用配置](/workflow/configuration/)中使用配置插件：

```json app.json
{
  "expo": {
    "plugins": [
      [
        "expo-audio",
        {
          "microphonePermission": "Allow $(PRODUCT_NAME) to record audio.",
          "enableBackgroundRecording": true
        }
      ]
    ]
  }
}
```

以上配置会自动配置所需的原生设置：

- <PlatformTags platforms={['android']} /> 添加 `FOREGROUND_SERVICE`、
  `FOREGROUND_SERVICE_MICROPHONE` 和 `POST_NOTIFICATIONS` 权限。还会在应用的
  **AndroidManifest.xml** 中声明音频录制前台服务。
- <PlatformTags platforms={['ios']} /> 添加 `audio` `UIBackgroundMode` 功能

<ConfigReactNative>

如果你未使用 Continuous Native Generation（[CNG](/workflow/continuous-native-generation/)）（即手动使用原生 **android** 和 **ios** 项目），则需要在原生项目中配置以下权限：

- 对于 Android，在 **android/app/src/main/AndroidManifest.xml** 中添加：

  ```xml android/app/src/main/AndroidManifest.xml
  <uses-permission android:name="android.permission.FOREGROUND_SERVICE_MICROPHONE" />
  <uses-permission android:name="android.permission.POST_NOTIFICATIONS" />
  ```

- 对于 iOS，在 **ios/YourApp/Info.plist** 中添加：

  ```xml ios/YourApp/Info.plist
  <key>UIBackgroundModes</key>
  <array>
    <string>audio</string>
  </array>
  ```

</ConfigReactNative>

#### 用法

配置应用后，使用 [`setAudioModeAsync`](#audiosetaudiomodeasyncmode) 在运行时启用后台录制：

```jsx
import { setAudioModeAsync, useAudioRecorder, RecordingPresets } from 'expo-audio';

await setAudioModeAsync({
  playsInSilentMode: true,
  allowsRecording: true,
  allowsBackgroundRecording: true,
});

const recorder = useAudioRecorder(RecordingPresets.HIGH_QUALITY);
await recorder.prepareToRecordAsync();
await recorder.record();

// Recording continues in background
```

<PlatformTags platforms={['android']} />

在 Android 上，后台录制需要前台服务，该服务会显示一条包含“正在录制音频”文本和停止按钮的持久通知。录制期间无法关闭此通知；录制停止后，通知会自动消失。

<PlatformTags platforms={['ios']} />

在 iOS 上，应用处于后台或屏幕锁定时，后台录制会无缝持续。除系统状态栏外，不会向应用用户显示其他通知或指示器。

### 直接使用 AudioPlayer

大多数情况下，使用 [`useAudioPlayer`](#useaudioplayersource-options) hook 创建 `AudioPlayer` 实例。它会管理播放器的生命周期，并确保组件卸载时正确释放资源。不过，在某些高级用例中，你可能需要创建一个生命周期超出组件的 `AudioPlayer`。
在这种情况下，请使用 [`createAudioPlayer`](#audiocreateaudioplayersource-options) 函数。你需要了解此方法带来的风险，因为当播放器不再需要时，必须由你负责调用 [`release()`](../sdk/expo/#release) 方法。如果处理不当，可能会导致内存泄漏。

```tsx
import { createAudioPlayer } from 'expo-audio';
const player = createAudioPlayer(audioSource);
```

### Web 使用说明

- Chrome 中的 MediaRecorder 问题会导致 WebM 文件缺少时长元数据。[查看 Chromium 上未解决的问题](https://bugs.chromium.org/p/chromium/issues/detail?id=642012)。
- MediaRecorder 的编码选项和其他配置在不同浏览器之间并不一致。在应用中使用 [kb​​umsik/opus-media-recorder](https://github.com/kbumsik/opus-media-recorder) 或 [ai/audio-recorder-polyfill](https://github.com/ai/audio-recorder-polyfill) 等 polyfill，可以改善使用体验。传递给 `prepareToRecordAsync` 的任何选项都会直接传递给 MediaRecorder API 以及相应的 polyfill。
- Web 浏览器要求网站通过安全连接提供服务，才能访问麦克风。有关详情，请参阅 [MediaDevices `getUserMedia()` 安全性](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia#security)。
