`expo-screen-capture` 可保护应用中的屏幕，防止被截屏或录制，也可以在应用处于前台时，有人截屏后通知你。最常见的两种需要阻止屏幕捕获的情况是：

- 屏幕上显示敏感信息（密码、信用卡信息等）
- 你正在展示不希望被录制和分享的付费内容

这在 Android 上尤为重要，因为 [`android.media.projection`](https://developer.android.com/about/versions/android-5.0.html#ScreenCapture) API 允许第三方应用执行屏幕捕获或屏幕共享（即使应用在后台运行）。

在 Android 上，屏幕捕获回调无需额外权限即可在 Android 14+ 上使用。**在 Android 14+ 上，阻止屏幕捕获或使用回调都无需请求或检查权限。**

如果你想在 Android 13 或更低版本上使用屏幕捕获回调，则需要将 `READ_MEDIA_IMAGES` 权限添加到 **AndroidManifest.xml** 文件中。你可以在应用配置中使用 `android.permissions` 键。有关更多信息，请参阅 [Android 权限](/guides/permissions/#android)。

> **warning** 只有需要广泛访问照片的应用才能添加 `READ_MEDIA_IMAGES` 权限。请参阅 [Google Play 照片和视频权限政策详情](https://support.google.com/googleplay/android-developer/answer/14115180)。

> **important** 测试屏幕捕获功能：在 Android Emulator 上，在单独的终端中运行 `adb shell input keyevent 120` 以触发截屏。在 iOS Simulator 上，你可以从菜单栏中选择 **Device** > **Trigger Screenshot** 来触发截屏。

## 用法

### 示例：hook

<SnackInline label="屏幕捕获 hook" dependencies={["expo-screen-capture"]}>

```jsx
import { usePreventScreenCapture } from 'expo-screen-capture';
import { Text, View } from 'react-native';

export default function ScreenCaptureExample() {
  usePreventScreenCapture();

  return (
    <View style={{ flex: 1, alignItems: 'center', justifyContent: 'center' }}>
      <Text>只要此组件处于挂载状态，此屏幕就无法被录制！</Text>
    </View>
  );
}
```

</SnackInline>

### 示例：以命令式方式阻止屏幕捕获

<SnackInline label="阻止屏幕捕获" dependencies={["expo-screen-capture", "expo-media-library"]}>

```jsx
import * as ScreenCapture from 'expo-screen-capture';
import { useEffect } from 'react';
import { Button, StyleSheet, View } from 'react-native';

export default function ScreenCaptureExample() {
  const activate = async () => {
    await ScreenCapture.preventScreenCaptureAsync();
  };

  const deactivate = async () => {
    await ScreenCapture.allowScreenCaptureAsync();
  };

  return (
    <View style={styles.container}>
      <Button title="Activate" onPress={activate} />
      <Button title="Deactivate" onPress={deactivate} />
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    alignItems: 'center',
    justifyContent: 'center',
  },
});
```

</SnackInline>

### 示例：屏幕捕获回调

<SnackInline label="屏幕捕获回调" dependencies={["expo-screen-capture", "expo-media-library"]}>

```jsx
import * as ScreenCapture from 'expo-screen-capture';
import { useEffect } from 'react';
import { Button, StyleSheet, View } from 'react-native';

export default function useScreenCaptureCallback() {
  // 只有在将 READ_MEDIA_IMAGES 权限添加到 AndroidManifest.xml 后才使用此功能
  const hasPermissions = async () => {
    const { status } = await ScreenCapture.requestPermissionsAsync();
    return status === 'granted';
  };

  useEffect(() => {
    let subscription;

    const addListenerAsync = async () => {
      if (await hasPermissions()) {
        subscription = ScreenCapture.addScreenshotListener(() => {
          alert('感谢你为我这个漂亮的应用截屏 😊');
        });
      } else {
        console.error('缺少订阅截屏事件所需的权限！');
      }
    };
    addListenerAsync();

    return () => {
      subscription?.remove();
    };
  }, []);
}
```

</SnackInline>
