`expo-linking` 提供了一些实用工具，让你的应用可以通过深层链接与其他已安装的应用交互。它还提供了用于构建深层链接以及解析指向你的应用的深层链接的辅助方法。该库是 React Native [`Linking`](https://reactnative.dev/docs/linking) 的扩展。

有关如何使用 `expo-linking` 的更全面说明，请参阅[链接到其他应用](/linking/into-other-apps/)。
