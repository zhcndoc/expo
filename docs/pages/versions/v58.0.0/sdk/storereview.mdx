`expo-store-review` 是一个库，可在 Android 5 及更高版本上使用 `ReviewManager` API，并在 iOS 上使用 `SKStoreReviewController` API。它允许你在不离开应用的情况下请求用户为应用评分。

## 用法

使用此 API 时，请务必遵循适用于 iOS 的[人机界面指南](https://developer.apple.com/design/human-interface-guidelines/ratings-and-reviews)和适用于 Android 的[指南](https://developer.android.com/guide/playcore/in-app-review#when-to-request)。

**具体来说：**

- 不要在按钮的点击事件中调用 `StoreReview.requestReview()`，而应尝试在用户完成某项重要的应用交互后调用。
- 不要频繁向用户请求评价。
- 不要在用户进行导航等对时间要求较高的操作时请求评价。
- 不要在显示评分按钮或卡片之前或期间向用户提问。

### 撰写评价

#### Android

Android 上没有对应的跳转方式，但你仍可以使用查询参数 `showAllReviews=true` 打开 Play Store 的评价页面，如下所示：

```ts Android Play Store example
const androidPackageName = 'host.exp.exponent';
// Open the Android Play Store in the browser -> redirects to Play Store on Android
Linking.openURL(
  `https://play.google.com/store/apps/details?id=${androidPackageName}&showAllReviews=true`
);
// Open the Android Play Store directly
Linking.openURL(`market://details?id=${androidPackageName}&showAllReviews=true`);
```

#### iOS

你可以使用查询参数 `action=write-review`，将应用用户重定向到 iOS App Store 中应用的**“撰写评价”**页面。例如：

```ts iOS App Store example
const itunesItemId = 982107779;
// Open the iOS App Store in the browser -> redirects to App Store on iOS
Linking.openURL(`https://apps.apple.com/app/apple-store/id${itunesItemId}?action=write-review`);
// Open the iOS App Store directly
Linking.openURL(
  `itms-apps://itunes.apple.com/app/viewContentsUserReviews/id${itunesItemId}?action=write-review`
);
```

## 错误代码

### `ERR_STORE_REVIEW_FAILED`

当商店评价请求未成功时，会发生此错误。
