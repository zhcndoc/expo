`expo-dev-menu` 可作为任何 Expo 项目中的**独立库**使用。它特别适用于不需要完整 [`expo-dev-client`](/versions/latest/sdk/dev-client/) 启动器界面的 [brownfield apps](/versions/latest/sdk/brownfield/)。

`expo-dev-menu` 为 React Native 应用提供开发者菜单 UI，其中包括：

- 可通过摇晃手势或三指长按访问的强大且可扩展的菜单 UI
- 快速访问常见开发操作
- 支持自定义菜单项以扩展功能

## 使用

安装完成后，开发者菜单将在调试构建中可用。你可以通过以下方式打开它：

- **摇晃手势**：摇晃设备
- **三指长按**：在屏幕上用三根手指长按
- **以编程方式**：在代码中调用 `DevMenu.openMenu()`

## 扩展开发者菜单

可以使用 `registerDevMenuItems` API 为开发者菜单添加额外按钮：

```tsx
import { registerDevMenuItems } from 'expo-dev-menu';

const devMenuItems = [
  {
    name: 'My Custom Button',
    callback: () => console.log('Hello world!'),
  },
];

registerDevMenuItems(devMenuItems);
```

这将在开发者菜单中创建一个新部分，其中包含你注册的按钮：

## 与 expo-dev-client 一起使用

如果你正在使用[开发构建](/develop/development-builds/introduction/)，请改为安装 `expo-dev-client`。它包含 `expo-dev-menu` 以及其他开发工具：

- 用于在开发服务器之间切换的可配置启动器 UI
- 改进的调试工具
- 支持从 [EAS Update](/eas-update/introduction/) 加载更新
