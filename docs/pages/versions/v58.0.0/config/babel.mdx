Babel 用作 JavaScript 编译器，将现代 JavaScript（ES6+）转换为与移动设备上的 JavaScript 引擎兼容的版本。

每个使用 `npx create-expo-app` 创建的新 Expo 项目都会自动配置 Babel，并使用 [`babel-preset-expo`](https://github.com/expo/expo/tree/main/packages/babel-preset-expo) 作为默认 preset。除非你需要自定义 Babel 配置，否则无需创建 **babel.config.js** 文件。

## 创建 babel.config.js

如果你的项目需要自定义 Babel 配置，则需要按照以下步骤在项目中创建 **babel.config.js** 文件：

1. 进入项目根目录，并在终端中运行以下命令。这将在项目根目录中生成一个 **babel.config.js** 文件。

<Terminal cmd={['$ npx expo customize babel.config.js']} />

2. **babel.config.js** 文件包含以下默认配置：

```js babel.config.js
module.exports = function (api) {
  api.cache(true);
  return {
    presets: ['babel-preset-expo'],
  };
};
```

3. 如果你修改了 **babel.config.js** 文件，则需要重启 Metro bundler 以应用更改，并使用 Expo CLI 的 `--clear` 选项清除 Metro bundler 缓存：

<Terminal cmd={['$ npx expo start --clear']} />

## babel-preset-expo

[`babel-preset-expo`](https://github.com/expo/expo/tree/main/packages/babel-preset-expo) 是 Expo 项目中使用的默认 preset。它扩展了默认的 React Native preset（`@react-native/babel-preset`），并增加了对 decorators、tree-shaking web libraries 以及加载字体图标的支持。
