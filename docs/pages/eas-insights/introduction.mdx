**EAS Insights** 是一个仪表板，可展示你项目中的趋势，让你一眼就能看出应用的运行情况。在 EAS 仪表板中打开你的项目，并从导航菜单中选择 [**Insights**](https://expo.dev/accounts/[account]/projects/[project]/insights)。

Insights 将数据分为三个选项卡：

- **[应用使用情况](/eas-insights/app-usage/)**：按平台、应用商店版本和时间汇总的应用使用情况，数据来自 EAS Update 请求和 `expo-insights` 库。
- **[工作流](/eas-insights/workflows/)**：你的 [EAS Workflows](/eas/workflows/introduction/) 的运行次数、成功率和趋势。
- **[Maestro](/eas-insights/maestro/)**：你在 EAS Workflows 中运行的 [Maestro](https://maestro.dev/) 端到端测试的通过、偶发失败和失败趋势。
