> **重要** **App usage** 处于 [预览](/more/release-statuses/#preview) 阶段，可能会发生破坏性变更。在预览期间，使用它是免费的。

**App usage** 选项卡提供了项目性能、使用情况和覆盖范围的视图。它允许你查看应用的状态，并提供有关跨平台、应用商店版本和时间范围的使用信息。

## 与 EAS Update 集成

如果你已经在使用 [EAS Update](/eas-update/introduction/)，那么无需进行任何额外的客户端更改，你就能获得某些高级使用洞察。这是通过将你的应用已经发出的更新检查请求汇总起来，形成一个受限的 Insights 视图，以按时间和平台展示使用情况来实现的。

## 使用 `expo-insights` 库

开发者可以将 `expo-insights` 库添加到他们的项目中，从而获得比仅汇总更新请求更精确的使用指标，以及按应用商店版本划分的更多细分数据。目前，该库仅限于发送与应用冷启动相关的客户端事件，但未来 `expo-insights` 将扩展以提供新的事件类型和负载，以支持更高级的功能。

### 安装

要使用 `expo-insights`，请确保你的应用已通过运行 `eas init` 在 [app config](/workflow/configuration/) 中链接到你的 EAS 项目，然后安装该库。

安装库后，使用 [EAS](/build/setup/) 或 [本地](/guides/local-app-development/) 创建一个构建。该库会在应用启动时自动向 EAS Insights 发送事件。

### 查看洞察

要查看你的应用使用数据，请在 EAS 控制台中打开你的项目，在导航菜单中选择 **Insights**，然后选择 **App usage** 选项卡。
