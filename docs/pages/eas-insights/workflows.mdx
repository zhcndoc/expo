> **信息** Workflows insights 仅适用于 Production 和 Enterprise 方案。了解更多请参阅 [EAS pricing](https://expo.dev/pricing)。

仪表板中的 **Workflows** 选项卡显示你的 [EAS Workflows](/eas/workflows/introduction/) 随时间的运行情况：运行频率、成功频率，以及哪些工作流失败最多。随着工作流运行，数据会自动显示。

- 要查看这些洞察，请在 EAS 仪表板中打开你的项目，从导航菜单中选择 **Insights**，然后选择 **Workflows** 选项卡。
- 选择一个时间范围以加载数据。每个指标还会与相同长度的上一时段进行比较，这样你就可以看出某个数值是在上升还是下降。

## 概览

选定时间范围内的标签页顶部会汇总活动情况：

- **总运行次数**：启动了多少次工作流运行。
- **成功率**：成功完成的运行所占比例。
- **活跃工作流**：运行了多少个不同的工作流。
- **失败运行次数**：有多少次运行失败。

## 随时间变化的运行情况

图表按天（对于较短的时间范围，则按小时或分钟）将运行拆分为总数、成功、失败和已取消的运行。可在折线视图和堆叠视图之间切换，并可打开或关闭各个状态，以便聚焦于你关心的内容。

## 工作流表

在图表下方，有一个表格列出了在该时间范围内运行的每个工作流，包含：

- **运行次数**：总次数，按成功、失败和取消分类。
- **成功率**：成功运行所占的比例。
- **上次运行**：工作流上次运行的时间。

## 过滤器

按工作流、运行状态（成功、失败、已取消）、触发类型（手动、计划，或 GitHub 事件）或 git 引用缩小数据范围。你也可以按工作流名称搜索。

## 导出

将与当前筛选条件和时间范围匹配的工作流运行导出为 CSV 或换行分隔的 JSON（NDJSON），以便进一步分析。

> **信息** 洞察数据是为趋势分析而聚合的，可能会滞后于实时数据，或遗漏最近的运行。请使用导出功能来调查趋势，而不是将其作为计费或审计的权威记录。
