Claude Code、Codex、Cursor 和其他 AI 编码代理可以帮助你构建、升级、调试和部署你的 Expo 和 React Native 项目。当你使用 [`create-expo-app`](/more/create-expo/) 创建一个新项目时，该新项目已经配置好了 AI 代理所需的配置文件。这个设置也会提交到你的项目中，因此你团队中的每个人都从相同的 SDK 版本和项目说明开始，并且他们的代理会读取相同的项目上下文。

## 快速开始

Claude Code 和 Codex 有官方 Expo 插件。一条命令即可安装 [Expo Skills](/skills/) 并注册 [Expo Model Context Protocol（MCP）Server](/mcp/)。

<Tabs>

<Tab label="Claude Code">

<Terminal cmd={['$ claude plugin install expo@claude-plugins-official']} />

然后在 Claude Code 会话中运行 `/mcp`，登录你的 Expo 账户。

</Tab>

<Tab label="Codex">

<Terminal cmd={['$ codex plugin add expo@openai-curated']} />

然后登录你的 Expo 账户：

<Terminal cmd={['$ codex mcp login expo']} />

</Tab>

</Tabs>

Cursor 和其他代理没有官方 Expo 插件。要配置它们，请分别安装 [Expo Skills](/skills/) 和 [Expo MCP Server](/mcp/)。

## Expo 如何支持 AI 代理

有三个部分协同工作，为 AI 代理提供一致的、特定于 Expo 的上下文：

- **Expo Skills：** `expo` 插件会向代理添加 Expo 专属说明和斜杠命令。代理会应用经过验证的 Expo 模式（SDK 升级、EAS Workflows、使用 Jetpack Compose 和 SwiftUI 构建原生 UI、API 路由），而不是根据训练数据进行猜测。Skills 在每台机器上只需安装一次。
- **Expo MCP Server：** 一个远程 Model Context Protocol（MCP）服务器，为代理提供对最新 Expo 文档、EAS Build 历史记录、EAS Update 通道和 TestFlight 元数据的实时访问权限。代理可以通过它安装与 SDK 匹配的包、读取构建日志，以及截取模拟器屏幕截图。对于 Claude Code 和 Codex，`expo` 插件会注册此服务器，因此无需单独添加。
- **项目上下文文件：** `create-expo-app` 会在项目根目录写入 **AGENTS.md**，指引代理查阅与你的项目目标 SDK 版本相匹配的 Expo 文档。安装 Claude Code 时，它还会写入 **.claude/settings.json** 以启用 Expo 插件。

## 代理的项目上下文文件

`create-expo-app` CLI 会将 **AGENTS.md** 添加到新项目的根目录。安装 Claude Code 时，它还会添加 **.claude/settings.json**：

| 文件                      | 读取者                         | 用途                                                                                                                             |
| ------------------------- | ------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| **AGENTS.md**             | Claude Code、Codex 和 Cursor。 | 指引代理查阅与你的项目 SDK 相匹配的 Expo 文档。这是项目级说明的事实来源。 |
| **.claude/settings.json** | Claude Code 启动时。         | 预先启用 Claude Code 插件市场中的官方 Expo 插件。                                                       |

将共享的项目说明添加到 **AGENTS.md**，这样 Claude Code、Codex 和 Cursor 就会读取相同的上下文。

## 设置现有项目

`create-expo-app` 仅在创建新项目时写入项目上下文文件。对于现有项目，请自行在项目根目录添加相同的文件。

<Step label="1">

### 下载 AGENTS.md

下载 `create-expo-app` 随 Expo 项目一起提供、位于项目根目录中的规范 **AGENTS.md**：

<Terminal
  cmd={[
    '$ curl -o AGENTS.md https://raw.githubusercontent.com/expo/expo/main/packages/create-expo/template/agent-files/AGENTS.md',
  ]}
/>

如果你的项目已经有 **AGENTS.md**，请将下载的内容追加到该文件中，而不是替换该文件。

</Step>

<Step label="2">

### 为 Claude Code 启用 Expo 插件

创建 **.claude/settings.json**，以启用 Claude Code 插件市场中的官方 Expo 插件：

```json .claude/settings.json
{
  "enabledPlugins": {
    "expo@claude-plugins-official": true
  }
}
```

此文件会为所有打开该项目的人启用插件。每位开发者仍需在自己的机器上安装一次，运行 `claude plugin install expo@claude-plugins-official` 即可。

</Step>

提交这两个文件，使团队中的每个代理会话都从相同的项目上下文开始。Codex 和 Cursor 只需要 **AGENTS.md**，因此第 2 步仅适用于 Claude Code。

## 验证设置

为确认代理可以读取你的项目，请在你的 Expo 项目中为 AI 代理打开一个会话，并运行以下提示：

```text Example prompt
打开 package.json，并告诉我这个项目目标使用的是哪个 Expo SDK 版本。
```

如果代理从 **package.json** 中回复了 SDK 版本，则说明代理正在正确读取你的项目。
