Codex 是 OpenAI 的基于终端的 AI 编程代理。它可以跨你的项目读取和写入文件、运行终端命令，并浏览网页。使用 `create-expo-app` 创建的 Expo 项目会附带一个 **AGENTS.md** 文件，Codex 会直接读取它。它还可以查看 EAS 和 Expo CLI 日志，从 Expo 模型上下文协议（MCP）服务器获取文档，使用 Expo Skills 获取最佳实践，管理你的 EAS 部署工作流，等等。

## 快速开始

<Step label="1">

### 安装 Codex

安装 Codex，然后从任意项目中启动它。其他安装方法请参阅 [Codex CLI 文档](https://developers.openai.com/codex/cli)。

<Terminal cmd={['$ curl -fsSL https://chatgpt.com/codex/install.sh | sh']} />

</Step>

<Step label="2">

### 创建一个新的 Expo 项目

使用以下命令创建项目，或者确保你现有的项目已安装最新的 expo 包。

<Terminal
  cmd={{
    npm: ['$ npx create-expo-app@latest --template default@sdk-57'],
    yarn: ['$ yarn create expo-app --template default@sdk-57'],
    pnpm: ['$ pnpm create expo-app --template default@sdk-57'],
    bun: ['$ bun create expo --template default@sdk-57'],
  }}
/>

</Step>

<Step label="3">

### 设置 Expo Skills 和 Expo MCP Server

安装 Expo Skills 并连接 Expo MCP Server，这样 Codex 就能了解 Expo 约定并访问你的 EAS。

<BoxLink
  title="Expo Skills"
  description="安装该插件，它会向 agent 教授经过验证的 Expo 模式，并浏览可用技能的完整列表。"
  href="/skills/#install-expo-skills"
  Icon={BookOpen02Icon}
/>

<BoxLink
  title="Expo MCP Server"
  description="连接远程 Expo MCP Server，让 agent 实时访问 Expo 文档和 EAS。"
  href="/mcp/#installation-and-setup"
  Icon={BookOpen02Icon}
/>

</Step>

<Step label="4">

### 打开你的项目并开始提问

从项目根目录运行 Codex，然后描述你想要做什么。

<Terminal cmd={['$ cd my-app', '', '$ codex']} />

</Step>

<Step label="5">

### 验证设置

在 Codex 会话中粘贴以下提示，以确认它可以读取你的项目：

```text Example prompt
打开 package.json，告诉我这个项目面向哪个 Expo SDK 版本。
```

如果 agent 回复的是 **package.json** 中的 SDK 版本，就说明 agent 正在正确读取你的项目。

</Step>

## Codex 如何读取你的 Expo 项目

当你在项目中启动 Codex 时，它会读取脚手架生成的 **AGENTS.md** 文件。该文件会将 Codex 指向你项目所使用的 Expo SDK 版本的文档，并包含你添加的任何项目级说明。

**AGENTS.md** 会提交到你的项目中，因此开发者的 Codex 会话会从相同的上下文开始。

## 示例提示词

设置完成后，用通俗的语言描述 Expo 任务。例如：

| 任务              | 示例提示词                                                                      |
| ----------------- | --------------------------------------------------------------------------------- |
| 升级 SDK         | 将此项目升级到最新的 Expo SDK，并修复任何破坏性更改。                                   |
| 添加导航          | 使用 Expo Router 添加一个标签导航器和一个新的设置屏幕。                                 |
| 自动化构建        | 创建一个 EAS Workflow，在每次拉取请求时构建应用。                                      |
| 调试构建          | 我最近的 iOS 构建失败了。请阅读 EAS Build 日志并告诉我哪里出了问题。                     |
| 添加通知          | 配置 expo-notifications，并在应用启动时显示本地通知。                                  |
| 设置 CI/CD        | 创建一个在每次 PR 时都会构建的 CI/CD 工作流。                                          |
| 添加原生 UI       | 向我的 Expo 应用添加一个 SwiftUI 选择器组件。                                          |
| 检查反馈          | 显示我应用的 TestFlight 反馈。                                                        |
| 验证 UI           | 截取屏幕截图并验证蓝色圆形视图。                                                      |

更多示例请参阅 [Expo Skills](/skills/#example-prompts) 和 [Expo MCP Server](/mcp/#what-does-expo-mcp-server-do) 的示例提示词部分。
