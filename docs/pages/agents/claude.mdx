Claude Code 是 Anthropic 基于终端的 AI 编码代理。它可以理解你的整个代码库、提出编辑建议、运行终端命令并管理 git 操作。使用 `create-expo-app` 创建的 Expo 项目包含 **AGENTS.md**，用于提供项目上下文。安装 Claude Code 后，这些项目还会包含 **.claude/settings.json**，以启用 Expo 插件。它还可以检查 EAS 和 Expo CLI 日志，从 Expo Model Context Protocol（MCP）Server 获取文档，使用 Expo Skills 获取最佳实践，管理 EAS 部署工作流等。

## 快速开始

<Step label="1">

### 安装 Claude Code

全局安装 Claude Code，然后从任意项目中启动它。其他安装方法请参阅 [Claude Code 文档](https://code.claude.com/docs)。

<Terminal cmd={['$ curl -fsSL https://claude.ai/install.sh | bash']} />

</Step>

<Step label="2">

### 创建一个新的 Expo 项目

使用以下命令创建一个项目，或者确保你现有的项目已安装最新的 expo 包。

<Terminal
  cmd={{
    npm: ['$ npx create-expo-app@latest'],
    yarn: ['$ yarn create expo-app'],
    pnpm: ['$ pnpm create expo-app'],
    bun: ['$ bun create expo'],
  }}
/>

</Step>

<Step label="3">

### 安装 Expo 插件

安装官方 Expo 插件，让 Claude Code 了解 Expo 约定，并能够使用你的 EAS 项目。一条命令即可安装 Expo Skills 并注册 Expo MCP Server：

<Terminal cmd={['$ claude plugin install expo@claude-plugins-official']} />

然后在 Claude Code 会话中运行 `/mcp`，登录你的 Expo 账号。

以下指南介绍了可用的 skills，以及 MCP Server 可以执行的其他操作：

<BoxLink
  title="Expo Skills"
  description="浏览插件提供的完整 skills 列表，并查看其他 agents 的安装选项。"
  href="/skills/#install-expo-skills"
  Icon={Star06Icon}
/>

<BoxLink
  title="Expo MCP Server"
  description="连接远程 Expo MCP Server，让 agent 可以实时访问 Expo 文档和 EAS。"
  href="/mcp/#installation-and-setup"
  Icon={Star06Icon}
/>

</Step>

<Step label="4">

### 打开你的项目并开始提问

从项目根目录运行 Claude Code，然后描述你想要做什么。

<Terminal cmd={['$ cd my-app', '', '$ claude']} />

</Step>

<Step label="5">

### 验证设置

将以下提示粘贴到你的 Claude Code 会话中，以确认它可以读取你的项目：

```text Example prompt
打开 package.json，并告诉我这个项目目标使用的是哪个 Expo SDK 版本。
```

如果 agent 返回了 **package.json** 中的 SDK 版本，说明 agent 正在正确读取你的项目。

</Step>

## Claude Code 如何读取你的 Expo 项目

当你在项目中启动 Claude Code 时，它会读取两个脚手架生成的文件：

- **AGENTS.md** 会指引 Claude Code 查阅与你的项目 Expo SDK 版本对应的文档。将项目级指令添加到此文件中，以便你的 agents 读取相同的上下文。
- **.claude/settings.json** 会从 Claude Code 插件市场启用官方 Expo 插件（[`expo@claude-plugins-official`](https://claude.com/plugins/expo)）。

这两个文件都会提交到你的项目中，因此开发者的 Claude Code 会话会从相同的上下文开始。

> **info** 直接读取 **AGENTS.md** 需要 Claude Code v2.1.277 或更高版本。有关加载规则和可用性，请参阅 [Claude Code 文档](https://code.claude.com/docs/en/memory#agentsmd)。

## 示例提示词

完成设置后，用通俗语言描述 Expo 任务。例如：

| 任务              | 示例提示词                                                                    |
| ----------------- | --------------------------------------------------------------------------------- |
| 升级 SDK          | 将此项目升级到最新的 Expo SDK，并修复所有破坏性变更。                                 |
| 添加导航          | 使用 Expo Router 添加一个选项卡导航器和一个新的设置屏幕。                             |
| 自动化构建        | 创建一个 EAS Workflow，在每次拉取请求时构建应用。                                      |
| 调试构建          | 我最新的 iOS 构建失败了。读取 EAS Build 日志并告诉我出了什么问题。                     |
| 添加通知          | 配置 expo-notifications，并在应用启动时显示本地通知。                                 |
| 设置 CI/CD        | 创建一个在每次 PR 时构建的 CI/CD 工作流。                                              |
| 添加原生 UI       | 向我的 Expo 应用添加一个 SwiftUI 选择器组件。                                           |
| 查看反馈          | 显示我的应用的 TestFlight 反馈。                                                       |
| 验证 UI           | 截取屏幕截图并验证蓝色圆形视图。                                                       |

更多示例，请参阅 [Expo Skills](/skills/#example-prompts) 和 [Expo MCP Server](/mcp/#what-does-expo-mcp-server-do) 的示例提示词部分。

## 故障排除

<Collapsible summary="项目设置中已启用插件 'expo'，但此处未安装。">

如果你在 Claude Code 会话中看到此错误，那么你需要在开发机器上安装官方 [Expo 插件](https://claude.com/plugins/expo)。要安装它，请在终端窗口中运行以下命令，然后重新启动你的 Claude Code 会话：

<Terminal cmd={['$ claude plugin install expo@claude-plugins-official']} />

上述命令会全局安装 Expo 插件。如果你只想为当前项目安装它，请在命令中添加 `--scope project`：

<Terminal cmd={['$ claude plugin install expo@claude-plugins-official --scope project']} />

</Collapsible>
