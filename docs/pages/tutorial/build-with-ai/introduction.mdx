在本教程中，你将为 Android、iOS 和 Web 构建一个完整的应用，而无需自己编写代码。相反，你将指导一个 AI 编码代理，例如 Claude Code、Codex 或 Cursor，并在每一步之后直接在自己的手机上实时检查结果。

本教程面向 **构建者**：那些有应用创意但没有编程背景的人。如果你更愿意学习自己编写代码，请改为阅读 [Expo 教程](/tutorial/introduction/)。它会通过一次一个代码片段的方式构建同样的应用。

## 你将构建什么

你将构建 **StickerSmash**，这是一款允许你选择一张照片、在照片上放置一个表情贴纸、用手指移动和调整贴纸大小，并将结果保存到照片库中的应用：

## 本教程的工作方式

每一章都遵循相同的循环：

1. **提示**：将建议的提示词粘贴到你的 AI 代理中。
2. **构建**：代理编写代码，应用会在几秒钟内更新到你的手机上。
3. **验证**：检查应用是否按你的要求运行，就在你的手机上。
4. **重新提示**：如果看起来有问题，告诉代理你看到了什么，让它修复问题。

你是产品负责人，也是测试人员。代理是程序员。

AI 代理每次都不会生成完全相同的结果，所以你的应用不会与我们的截图像素级一致。这是正常的。提示词描述的是你想要的结果，而截图显示的是你大致应该看到的内容。欢迎随意编辑提示词以符合你自己的品味：选择不同的颜色，修改按钮上的措辞，让它更像你自己的作品。

## 你将需要

- 一台运行 macOS、Windows 或 Linux 的电脑。
- 一部 Android 或 iOS 手机。
- 大约一个小时。第一章会带你从零开始安装所有工具，所以你不需要提前准备任何环境。
