<Step label="1">

## 打开终端

终端是你与 AI 代理交流的应用。

- 在 macOS 上，打开系统自带的 **Terminal** 应用。你可以通过打开 Spotlight 搜索（<kbd>Cmd ⌘</kbd> + <kbd>Space</kbd>）并输入“Terminal”来找到它。
- 在 Windows 上，从开始菜单打开 **PowerShell**。在本章中，你会在其中输入一些命令。每个命令都已提供好，供你复制粘贴。

> 如果你打算使用 **Cursor**，在本教程的大部分内容中，你会在它的可视化编辑器里操作，而不是在终端中操作，但仍然要保留一个终端，因为你之后还需要用它来运行应用。

</Step>

<Step label="2">

## 安装一个 AI 代理

如果你已经在使用 AI 编程代理，可以跳到下一步。否则，请从下面选择一个。本教程与它们中的任何一个都适用。

<Tabs>

<Tab label="Claude Code">

在终端窗口中运行以下命令来安装 [Claude Code](https://claude.com/claude-code)：

<Terminal cmd={['$ curl -fsSL https://claude.ai/install.sh | bash']} />

> **在 Windows 上：** 如果你使用 PowerShell 安装 Claude Code，请运行 `irm https://claude.ai/install.ps1 | iex`。

然后在终端中运行 `claude` 并按照说明登录。如果遇到问题，请查看 [Claude Code 设置指南](https://code.claude.com/docs/en/setup)。

</Tab>

<Tab label="Codex">

在终端窗口中运行以下命令来安装 [Codex](https://developers.openai.com/codex/cli)：

<Terminal cmd={['$ curl -fsSL https://chatgpt.com/codex/install.sh | sh']} />

然后在终端中运行 `codex` 并按照说明使用你的 ChatGPT 账户登录。如果遇到问题，请查看 [Codex CLI 文档](https://developers.openai.com/codex/cli)。

</Tab>

<Tab label="Cursor">

下载 [Cursor](https://cursor.com) 并像安装其他应用一样安装它。Cursor 是一个带有内置 AI 代理的可视化代码编辑器，你将会在它的代理面板中输入提示词，而不是在终端中输入。

</Tab>

</Tabs>

其他代理也可以。只要你的代理能够在你的电脑上编辑文件并运行命令，你就可以继续跟着做。

</Step>

<Step label="3">

## 安装 Node.js

让我们运行你的第一个提示词并安装 Node.js。

Node.js 是驱动 Expo 开发者工具的运行时。运行下面这个提示词，它会指示你的代理从 [nodejs.org](https://nodejs.org/en) 下载 **长期支持版（LTS）**。

```text Prompt|wrap
I'm following the Expo "Build with AI" tutorial on a brand-new setup and I have no programming experience. Please install the latest LTS version of Node.js on my computer.

- First, tell me in one or two plain sentences what you're about to do.
- Detect my operating system and use the most reliable method for it.
- When you're done, verify it worked by showing me the output of `node --version` and `npm --version`, and tell me if I need to reopen anything for it to take effect.
```

要确认它是否生效，请通过打开一个新的终端窗口运行以下命令。它应该会打印当前安装的 Node.js 版本号：

<Terminal cmd={['$ node --version']} />

</Step>

<Step label="4">

## 安装 Expo Go 并创建 Expo 账户

Expo Go 是一个免费的应用，让你在构建项目时可以在手机上测试它，而无需发布到应用商店。每当你的代理修改代码时，手机上的应用会在几秒内更新。

1. 在手机上从 Google Play 商店或 Apple App Store 安装 [Expo Go](https://expo.dev/go)。
2. 在电脑上前往 [expo.dev/signup](https://expo.dev/signup) 创建一个免费账户。
3. 在手机上打开 Expo Go，并使用同一个账户登录。

</Step>

<Step label="5">

## 让你的代理了解 Expo

Expo Skills 是一组指令文件，用来教 AI 代理如何更好地构建 Expo 应用：该使用哪些库、如何组织界面，以及如何避免常见错误。安装它们是让你的代理获得良好结果最重要的一步。

<Tabs>

<Tab label="Claude Code">

先运行 `claude`，然后在其中运行以下命令：

<Terminal cmd={['$ /plugin install expo@claude-plugins-official']} />

</Tab>

<Tab label="Codex">

在终端中运行以下命令：

<Terminal cmd={['$ codex plugin add expo@openai-curated']} />

</Tab>

<Tab label="Cursor">

在终端中运行以下命令：

<Terminal cmd={['$ npx skills add expo/skills']} />

{/* vale off */}

然后重新打开 Cursor，并确认这些技能出现在 **Settings** > **Rules, Skills, Subagents** > **Skills** 下。

{/* vale on */}

</Tab>

</Tabs>

<Step label="6">

## 连接 Expo MCP 服务器

Expo MCP 服务器让你的代理可以直接访问 Expo 的工具：它可以读取最新的 Expo 文档、安装正确的软件包，并检查你的项目。

<Tabs>

<Tab label="Claude Code">

在终端中运行以下命令：

<Terminal cmd={['$ claude mcp add --transport http expo https://mcp.expo.dev/mcp']} />

然后启动 `claude`，并在其中运行 `/mcp`，使用你在上一步创建的 Expo 账户登录。

</Tab>

<Tab label="Codex">

在终端中运行以下命令，并在提示时使用你在上一步创建的 Expo 账户登录：

<Terminal cmd={['$ codex mcp add expo --url https://mcp.expo.dev/mcp']} />

</Tab>

<Step label="7">

## 测试你的设置

让我们确认一切都已正确连接。把下面这个提示词粘贴到你的代理中：

```text Prompt|wrap
Use the Expo MCP server to search the Expo documentation for "expo-image-picker" and tell me in one sentence what it does.
```

**你应该看到的结果**：代理会调用一个 Expo 文档工具，并用一句话回复，说明它可以从设备的照片库中选择图片。如果它返回连接或身份验证错误，请重复上一步中的登录部分。

</Step>
