## Configuration

> **info** For Android and iOS projects, additional configuration is required to support switching between light and dark modes. For web, no additional configuration is needed.

To configure the supported appearance style, you can use the [`userInterfaceStyle`](/versions/latest/config/app/#userinterfacestyle) property in your project’s [app config](/versions/latest/config/app). By default, when you create a new project using the [default template](/get-started/create-a-project/), this property is set to `automatic`.

Here is a configuration example:

```json app.json
{
  "expo": {
    "userInterfaceStyle": "automatic"
  }
}
```

You can also configure the `userInterfaceStyle` property for a specific platform by setting [`android.userInterfaceStyle`](/versions/latest/config/app/#userinterfacestyle-2) or [`ios.userInterfaceStyle`](/versions/latest/config/app/#userinterfacestyle-1) to the preferred value.

> **info** If this property is missing, the app will default to the `light` style.

When you create a development build, you must install [`expo-system-ui`](/versions/latest/sdk/system-ui/#installation) to support the Android appearance style. Otherwise, the `userInterfaceStyle` property will be ignored.

<Terminal
  cmd={{
    npm: ['$ npx expo install expo-system-ui'],
    yarn: ['$ yarn expo install expo-system-ui'],
    pnpm: ['$ pnpm expo install expo-system-ui'],
    bun: ['$ bun expo install expo-system-ui'],
  }}
/>

If the project is misconfigured and `expo-system-ui` is not installed, the following warning will appear in the terminal:

<Terminal
  cmd={[
    '» android: userInterfaceStyle: Install expo-system-ui in your project to enable this feature.',
  ]}
/>

You can also use the following command to check whether the project is misconfigured:

<Terminal
  cmd={{

    yarn: ['$ yarn expo config --type introspect'],
    pnpm: ['$ pnpm expo config --type introspect'],
    bun: ['$ bun expo config --type introspect'],
  }}

#### Android

Make sure to include the `uiMode` flag on `MainActivity` (and any other activity that needs this behavior) in **AndroidManifest.xml**:

```xml
<activity android:configChanges="keyboard|keyboardHidden|orientation|screenSize|uiMode">
```

Implement the `onConfigurationChanged` method in **MainActivity.java**:

```java
/* @info Import the `Intent` and `Configuration` classes. */
import android.content.Intent;
import android.content.res.Configuration;
/* @end */
public class MainActivity extends ReactActivity {
  /* @hide ... */ /* @end */

  @Override
  public void onConfigurationChanged(Configuration newConfig) {
    super.onConfigurationChanged(newConfig);
    Intent intent = new Intent("onConfigurationChanged");
    intent.putExtra("newConfig", newConfig);
    sendBroadcast(intent);
  }
  /* @hide ... */ /* @end */
}
```

#### iOS

You can use the [`UIUserInterfaceStyle`](https://developer.apple.com/documentation/bundleresources/information_property_list/uiuserinterfacestyle) key in your app’s **Info.plist** to configure the supported styles. Use `Automatic` to support both light and dark modes.

### Supported appearance styles

The `userInterfaceStyle` property supports the following values:

- `automatic`: Follows the system appearance setting and notifies you when the user makes any changes.
- `light`: Restricts the app to support only the light theme.
- `dark`: Restricts the app to support only the dark theme.

## 检测配色方案

要在项目中检测配色方案，请使用 `react-native` 中的 `Appearance` 或 `useColorScheme`：

```tsx src/app/index.tsx
import { Appearance, useColorScheme } from 'react-native';
```

然后，你可以像下面这样使用 `useColorScheme()` 钩子：

```tsx src/app/index.tsx
function MyComponent() {
  let colorScheme = useColorScheme();

  if (colorScheme === 'dark') {
    // 渲染一些深色内容
  } else {
    // 渲染一些浅色内容
  }
}
```

在某些情况下，你可能会发现通过 [`Appearance.getColorScheme()` 获取当前配色方案，或者使用 `Appearance.addChangeListener()` 监听变化](https://reactnative.dev/docs/appearance) 会很有帮助。

### 最小示例

```tsx
import { Text, StyleSheet, View, /* @info 从 react-native 导入 `useColorScheme` */ useColorScheme /* @end */ } from 'react-native';
/* @info 根据主题自动切换状态栏样式。 */
import { StatusBar } from 'expo-status-bar';
/* @end */

export default function App() {
  const colorScheme = useColorScheme();

  const themeTextStyle = colorScheme === 'light' ? styles.lightThemeText : styles.darkThemeText;
  const themeContainerStyle =
    colorScheme === 'light' ? styles.lightContainer : styles.darkContainer;

  return (
    <View style={[styles.container, themeContainerStyle]}>
      <Text style={[styles.text, themeTextStyle]}>配色方案：{colorScheme}</Text>
      <StatusBar />
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    alignItems: 'center',
    justifyContent: 'center',
  },
  text: {
    fontSize: 20,
  },
  lightContainer: {
    backgroundColor: '#d0d0c0',
  },
  darkContainer: {
    backgroundColor: '#242c40',
  },
  lightThemeText: {
    color: '#242c40',
  },
  darkThemeText: {
    color: '#d0d0c0',
  },
});
```

### 提示

在开发项目时，你可以使用以下快捷键更改模拟器或设备的外观：

- 如果使用 Android 模拟器，你可以运行 `adb shell "cmd uimode night yes"` 来启用深色模式，运行 `adb shell "cmd uimode night no"` 来禁用深色模式。
- 如果使用实体 Android 设备或 Android 模拟器，你可以在设备设置中切换系统深色模式设置。
- 如果在本地使用 iOS 模拟器，你可以使用 <kbd>Cmd ⌘</kbd> + <kbd>Shift</kbd> + <kbd>A</kbd> 快捷键在浅色和深色模式之间切换。
