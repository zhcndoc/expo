当你使用 [`create-expo-app`](/get-started/create-a-project/) 创建新的 Expo 应用时，你会从一个项目开始：在本地计算机上更新 TypeScript/JavaScript 代码，并在 Expo Go 应用中查看更改。**开发构建**本质上是**你自己的 Expo Go 版本**，你可以自由使用任何原生库并更改任何原生配置。

**当你想创建自己的应用并将其发布到应用商店时，建议使用开发构建**。它包含 [`expo-dev-client`](/versions/latest/sdk/dev-client/) 库，用于增强内置的 React Native 开发工具。该工具还支持检查网络请求，以及提供一个["启动器"界面](/develop/development-builds/use-development-builds/#the-launcher-screen)，让你可以在不同的开发服务器之间切换（例如在运行于你自己的计算机上的服务器与运行于队友计算机上的服务器之间切换），还可以在应用的不同部署版本之间切换（例如使用 [EAS Update](/eas-update/introduction/) 发布的更新）。

## 安装开发版本后

从设备的主屏幕启动开发版本，并在启动器屏幕中连接到开发服务器，以开始开发应用。要了解如何使用新的开发版本，包括启动器屏幕、重新构建和调试，请参阅[使用开发版本](/develop/development-builds/use-development-builds/)。如需了解有关开发版本和 Expo Go 的常见问题，包括在 Expo Go 中无法执行的操作及其原因，请参阅[常见问题](/develop/development-builds/faq/)。
