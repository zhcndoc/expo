让我们开始一段构建通用应用的旅程吧。在本教程中，你将使用一套代码库创建一个可在 Android、iOS 和 web 上运行的 Expo 应用。让我们马上开始吧！

## 关于 React Native 和 Expo 教程

本教程的目的是让你开始使用 Expo，并熟悉 Expo SDK。我们将涵盖以下主题：

- 使用启用了 TypeScript 的默认模板创建应用
- 使用 Expo Router 实现一个包含两个屏幕的底部标签布局
- 将应用布局拆分，并使用 flexbox 实现
- 使用各个平台的系统 UI 从媒体库中选择图片
- 使用 React Native 的 `<Modal>` 和 `<FlatList>` 组件创建贴纸模态框
- 添加用于操作贴纸的触摸手势
- 使用第三方库拍摄屏幕截图并保存到磁盘
- 处理 Android、iOS 和 web 平台之间的差异
- 最后，配置状态栏、启动画面和图标，完成应用

这些主题将作为你学习构建 Expo 应用基础知识的起点。本教程可按自己的节奏进行，完成大约需要最多 2 小时。

为了让初学者也能轻松上手，本教程被分为 9 章。你可以继续一口气完成，也可以先暂停，之后再回来继续。每一章都包含完成步骤所需的代码片段，因此你既可以从零开始边写边学，也可以直接复制并粘贴这些片段来推进进度。
