## 将项目构建为应用

要在自己的机器上开始创建一个新应用，请使用 `npx create-expo-app@latest --template default@sdk-57`，然后继续进行[开发环境设置](/get-started/set-up-your-environment/)。

> **注：** 在迁移到 SDK 57 的期间，如果不带 `--template` 标志运行 `create-expo-app@latest`，将会创建一个 SDK 54 项目。如果你打算在真机上使用 Expo Go，请使用 SDK 54 项目。否则，请指定 `--template default@sdk-57` 来创建 SDK 57 项目。

### 推荐资源

在创建新项目之后，你可以继续了解各种有助于应用开发的工具和概念。

- [开发工具](/develop/tools/)：这是 Expo 工具的参考文档，在构建应用的各种场景中都很有帮助。
- [开发构建](/develop/development-builds/introduction/)：使用开发构建后，你可以完全控制应用的构建流程，并在设备或模拟器上测试应用。
- [开发概览](/workflow/overview/)：从高层次讲解在 Expo 中开发应用时的重要概念，以及核心开发循环的流程。
- [Expo Router](/router/introduction/)：教程中介绍了 Expo Router 的基础知识，并实现了标签导航器。有关该库的更多详情，请参阅文档。
- [应用图标](/develop/user-interface/splash-screen-and-app-icon/#app-icon) 和 [启动画面](/develop/user-interface/splash-screen-and-app-icon/#splash-screen)：可以在指南中详细了解应用图标和启动画面的自定义方法。另外，关于可在 **app.json** 文件中配置的属性，请参阅[应用配置参考](/workflow/configuration)。
- 面向应用商店的 [应用分发](/deploy/build-project/) 和 [提交](/deploy/submit-to-app-stores/)：在应用准备发布之后，这是了解如何将应用发布到应用商店并提交的资源。
- [调试](/debugging/runtime-issues/)：当出现问题时，可以使用调试工具来查找并修复错误。

## 学习

### React

在教程中，我们使用了 React 的组件和 API。要在 Expo 中构建应用，扎实理解 React 是必不可少的。建议阅读 React 官方文档中的 [快速开始](https://react.dev/learn) 和 [Hooks](https://react.dev/reference/react/hooks) 章节。

### React Native

在开发教程应用时，我们广泛使用了 React Native。想要进一步学习，可以从 [React Native 基础指南](https://reactnative.dev/docs/getting-started) 开始。此外，也可以参考以下文档：

- [View API 参考](https://reactnative.dev/docs/view)
- [Text API 参考](https://reactnative.dev/docs/text)
- [平台特定代码](https://reactnative.dev/docs/platform-specific-code)
- [在列表中显示数据](https://reactnative.dev/docs/using-a-listview)

我们使用 Flexbox 来布局组件。想进一步了解 Flexbox，请查看以下资源：

- [Height 和 Width](https://reactnative.dev/docs/height-and-width)
- [使用 Flexbox 进行布局](https://reactnative.dev/docs/flexbox)

### 手势和动画

要学习如何实现各种类型的手势和动画，推荐阅读以下文档：

- [React Native Gesture Handler](https://docs.swmansion.com/react-native-gesture-handler/docs/)
- [React Native Reanimated](https://docs.swmansion.com/react-native-reanimated/docs/fundamentals/getting-started)
