## 声明用于显示按钮的状态变量

在实现模态框之前，我们先添加 3 个新按钮。这些按钮会在用户从媒体库中选择图片或使用占位图片后显示。其中一个按钮会打开表情符号选择器模态框。

在 **app/(tabs)/index.tsx** 中：

1. 声明一个布尔状态变量 `showAppOptions`，用于控制模态框打开按钮和其他选项的显示与隐藏。在应用屏幕加载时将其设为 `false`，这样在用户选择图片之前不会显示选项。用户选择图片或使用占位图片后，将其设为 `true`。
2. 更新 `pickImageAsync()` 函数，在用户选择图片后将 `showAppOptions` 的值设为 `true`。
3. 为尚未设置主题的按钮添加 `onPress` 属性，并使用以下值进行更新。

## 创建表情符号选择器模态框

在模态框中，用户可以从可用的表情符号列表中选择一个表情。先在 **components** 目录中创建 **EmojiPicker.tsx** 文件。这个组件接收 3 个属性：

- `isVisible`：决定模态框显示状态的布尔值。
- `onClose`：关闭模态框的函数。
- `children`：稍后用于显示表情符号列表。

{/* prettier-ignore */}
```tsx components/EmojiPicker.tsx|collapseHeight=430
import { Modal, View, Text, Pressable, StyleSheet } from 'react-native';
import { PropsWithChildren } from 'react';
import MaterialIcons from '@expo/vector-icons/MaterialIcons';

type Props = PropsWithChildren<{
  isVisible: boolean;
  onClose: () => void;
}>;

export default function EmojiPicker({ isVisible, children, onClose }: Props) {
  return (
    <View>
      <Modal animationType="slide" transparent={true} visible={isVisible}>
        <View style={styles.modalContent}>
          <View style={styles.titleContainer}>
            <Text style={styles.title}>选择一个贴纸</Text>
            <Pressable onPress={onClose}>
              <MaterialIcons name="close" color="#fff" size={22} />
            </Pressable>
          </View>
          {children}
        </View>
      </Modal>
    </View>
  );
}

const styles = StyleSheet.create({
  modalContent: {
    height: '25%',
    width: '100%',
    backgroundColor: '#25292e',
    borderTopRightRadius: 18,
    borderTopLeftRadius: 18,
    position: 'absolute',
    bottom: 0,
  },
  titleContainer: {
    height: '16%',
    backgroundColor: '#464C55',
    borderTopRightRadius: 10,
    borderTopLeftRadius: 10,
    paddingHorizontal: 20,
    flexDirection: 'row',
    alignItems: 'center',
    justifyContent: 'space-between',
  },
  title: {
    color: '#fff',
    fontSize: 16,
  },
});
```

让我们看看上面的代码在做什么。

- `<Modal>` 组件会显示标题和关闭按钮。
- `visible` 属性接收 `isVisible` 的值，用于控制模态框是打开还是关闭。
- `transparent` 属性是一个布尔值，决定模态框是否会填充整个视图。
- `animationType` 属性决定模态框显示和消失时的动画效果。在这里，它会从屏幕底部滑入。
- 最后，当用户按下关闭的 `<Pressable>` 时，`<EmojiPicker>` 会执行 `onClose` 属性。

1. 导入 `<EmojiPicker>` 组件。

## 显示表情符号列表

让我们在模态框内容中添加一个横向表情列表。这里将使用 React Native 的 [`<FlatList>`](https://reactnative.dev/docs/flatlist) 组件。

在 **components** 目录中创建 **EmojiList.tsx** 文件，并添加以下代码。

{/* prettier-ignore */}
```tsx components/EmojiList.tsx
import { useState } from 'react';
import { ImageSourcePropType, StyleSheet, FlatList, Platform, Pressable } from 'react-native';
import { Image } from 'expo-image';

type Props = {
  onSelect: (image: ImageSourcePropType) => void;
  onCloseModal: () => void;
};

export default function EmojiList({ onSelect, onCloseModal }: Props) {
  const [emoji] = useState<ImageSourcePropType[]>([
    require("../assets/images/emoji1.png"),
    require("../assets/images/emoji2.png"),
    require("../assets/images/emoji3.png"),
    require("../assets/images/emoji4.png"),
    require("../assets/images/emoji5.png"),
    require("../assets/images/emoji6.png"),
  ]);

  return (
    <FlatList
      horizontal
      showsHorizontalScrollIndicator={Platform.OS === 'web'}
      data={emoji}
      contentContainerStyle={styles.listContainer}
      renderItem={({ item, index }) => (
        <Pressable
          onPress={() => {
            onSelect(item);
            onCloseModal();
          }}>
          <Image source={item} key={index} style={styles.image} />
        </Pressable>
      )}
    />
  );
}

const styles = StyleSheet.create({
  listContainer: {
    borderTopRightRadius: 10,
    borderTopLeftRadius: 10,
    paddingHorizontal: 20,
    flexDirection: 'row',
    alignItems: 'center',
    justifyContent: 'space-between',
  },
  image: {
    width: 100,
    height: 100,
    marginRight: 20,
  },
});
```

让我们看看上面的代码在做什么。

- 上面的 `<FlatList>` 组件使用被 `<Pressable>` 包裹的 `Image` 组件来渲染所有表情图片。之后我们会进一步改进，让用户点击屏幕上的表情后，图片中显示为贴纸。
- 它还将 `emoji` 数组变量中的项目数组作为 `data` 属性的值。`renderItem` 属性从 `data` 中接收每个项目，并将其作为列表项返回。最后，我们为展示这个项目添加了 `Image` 和 `<Pressable>` 组件。
- `horizontal` 属性会让列表横向而不是纵向渲染。`showsHorizontalScrollIndicator` 通过 React Native 的 `Platform` 模块判断平台，在 web 端显示横向滚动条。

## 显示选中的表情

接下来，我们将在图片上放置表情贴纸。在 **components** 目录中新建一个文件，命名为 **EmojiSticker.tsx**。然后添加以下代码。

```tsx components/EmojiSticker.tsx|collapseHeight=300
import { ImageSourcePropType, View } from 'react-native';
import { Image } from 'expo-image';

type Props = {
  imageSize: number;
  stickerSource: ImageSourcePropType;
};

export default function EmojiSticker({ imageSize, stickerSource }: Props) {
  return (
    <View style={{ top: -350 }}>
      <Image source={stickerSource} style={{ width: imageSize, height: imageSize }} />
    </View>
  );
}
```

这个组件接收 2 个属性：

- `imageSize`：在 `Index` 组件中定义的值。下一章中，我们将用它在点击时改变图片大小。
- `stickerSource`：所选表情图片的来源。
