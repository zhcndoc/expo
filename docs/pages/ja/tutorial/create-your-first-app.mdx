## 初始化一个新的 Expo 应用

我们将使用 [`create-expo-app`](/more/create-expo/) 来初始化一个新的 Expo 应用。这是一个用于创建新的 React Native 项目的命令行工具。现在，在终端中运行下面的命令。

<Terminal
  cmd={{
    npm: [
      '# 创建一个名为 StickerSmash 的项目',
      '$ npx create-expo-app@latest StickerSmash',
      '',
      '# CLI will prompt you to choose a template. Select SDK 57.',
      '$ Select an Expo SDK version > SDK 57',
      '',
      '# 进入项目目录',
      '$ cd StickerSmash',
    ],
    yarn: [
      '# 创建一个名为 StickerSmash 的项目',
      '$ yarn create expo-app StickerSmash',
      '',
      '# CLI will prompt you to choose a template. Select SDK 57.',
      '$ Select an Expo SDK version > SDK 57',
      '',
      '# 进入项目目录',
      '$ cd StickerSmash',
    ],
    pnpm: [
      '# 创建一个名为 StickerSmash 的项目',
      '$ pnpm create expo-app StickerSmash',
      '',
      '# CLI will prompt you to choose a template. Select SDK 57.',
      '$ Select an Expo SDK version > SDK 57',
      '',
      '# 进入项目目录',
      '$ cd StickerSmash',
    ],
    bun: [
      '# 创建一个名为 StickerSmash 的项目',
      '$ bun create expo StickerSmash',
      '',
      '# CLI will prompt you to choose a template. Select SDK 57.',
      '$ Select an Expo SDK version > SDK 57',
      '',
      '# 进入项目目录',
      '$ cd StickerSmash',
    ],
  }}
/>

此命令会使用 [默认](/more/create-expo/#--template) 模板创建一个名为 StickerSmash 的新项目目录。该模板包含构建应用所需的基础样板代码和库，包括 Expo Router。我们会在教程过程中按需添加库。

<Collapsible summary="使用默认模板的优势">

- 创建一个已安装 `expo` 包的全新 React Native 项目
- 包含 Expo CLI 等推荐工具
- 包含 Expo Router 的标签页导航器，用于提供基础导航系统
- 自动配置为可在 Android、iOS 和 web 等多个平台上运行项目
- 默认配置 TypeScript

</Collapsible>

## 运行 reset-project 脚本

{/* vale on */}

在本教程中，你将从零开始构建应用，并学习添加基于文件的导航的基础知识。为了移除样板代码，让我们运行 `reset-project` 脚本。

<Terminal
  cmd={{
    npm: ['$ npm run reset-project'],
    yarn: ['$ yarn run reset-project'],
    pnpm: ['$ pnpm run reset-project'],
    bun: ['$ bun run reset-project'],
  }}
/>

运行上述命令后，**src/app** 目录中会剩下 2 个文件（**index.tsx** 和 **\_layout.tsx**）。之前的文件会由脚本从 **src** 目录（包含 **components**、**constants** 和 **hooks**）移动到 **example** 目录中。随着教程的进行，我们会创建自己的目录和组件文件。

<Collapsible summary={<><CODE>reset-project</CODE> 脚本会做什么？</>}>

`reset-project` 脚本会重置项目中的 **src/app** 目录结构，并将项目 **src** 目录中原有的样板文件移动到名为 **example** 的单独子目录中。由于这些文件不是主应用结构的一部分，因此可以将其删除。

</Collapsible>

</Step>

## 在移动端和 web 上运行应用

在项目目录中，运行以下命令，从终端启动 [开发服务器](/more/glossary-of-terms/#development-server)。

<Terminal
  cmd={{
    npm: ['$ npx expo start'],
    yarn: ['$ yarn expo start'],
    pnpm: ['$ pnpm expo start'],
    bun: ['$ bun expo start'],
  }}
/>

运行上述命令后：

1. 开发服务器会启动，并在终端窗口中显示一个二维码。
2. 扫描该二维码即可在设备上打开应用。在 Android 上使用 Expo Go > **扫描二维码** 选项，在 iOS 上使用默认相机应用。
3. 要运行 web 应用，请在终端中按 <kbd>W</kbd>。web 应用会在默认的 web 浏览器中打开。

> **info** 在 iOS 实体设备上，只有当 Expo CLI 和 Expo Go 都使用同一个 Expo 账户登录时，Expo Go 才会打开项目。请在电脑上运行 `npx expo login`，并在 Expo Go 中登录同一个账户。如果错误仍未解决，请参阅[需要登录 Expo Go](/troubleshooting/expo-go-sign-in-required/)。

## 编辑 index 屏幕

{/* vale on */}

**src/app/index.tsx** 文件定义了显示在应用屏幕上的文本。这是应用的入口点，在开发服务器启动时运行。我们将使用 React Native 的 `<View>` 和 `<Text>` 等核心组件来显示背景和文本。

这些组件所应用的样式使用的是 JavaScript 对象，而不是 web 中使用的 CSS。不过，如果你以前在 web 上使用过 CSS，很多属性会让你感到熟悉。大多数 React Native 组件都接受 `style` 属性，并且该属性的值是一个 JavaScript 对象。更多信息请参见 [Styling in React Native](https://reactnative.dev/docs/style)。

让我们更改 **src/app/index.tsx** 屏幕。

1. 从 `react-native` 中导入 `StyleSheet`，并创建一个定义自定义样式的 `styles` 对象。
2. 为 `<View>` 添加 `styles.container.backgroundColor` 属性，并将值设为 `#25292e`。这将更改背景颜色。
3. 将 `<Text>` 的默认值替换为“Home screen”。
4. 为 `<Text>` 添加 `styles.text.color` 属性，并将值设为 `#fff`（白色），以更改文本颜色。

{/* prettier-ignore */}
```tsx src/app/index.tsx|collapseHeight=340
import { Text, View, /* @tutinfo スタイルを定義するため `StyleSheet` をインポートします。 */ StyleSheet/* @end */ } from 'react-native';

export default function Index() {
  return (
    <View style={styles.container}>
      /* @tutinfo 以前は "Edit src/app/index.tsx to edit this screen" と表示されていましたが、現在は "Home screen" と表示されます。 */
      <Text style={styles.text}>Home screen</Text>
      /* @end */
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    /* @tutinfo 将 `backgroundColor` 属性的值设置为 `'#25292e'`。*/
    backgroundColor: '#25292e',
    /* @end */
    alignItems: 'center',
    justifyContent: 'center',
  },
  text: {
    color: '#fff',
  },
});
```

> React Native 使用与 web 相同的颜色格式。它支持十六进制三位缩写（即 `#fff` 这种形式）、`rgba`、`hsl`，以及 `red`、`green`、`blue`、`peru`、`papayawhip` 等命名颜色。更多信息请参见 [Colors in React Native](https://reactnative.dev/docs/colors)。

保存更改后，正在连接到开发服务器的运行中应用会接收到这些更改并应用它们。

<Collapsible summary="蓝色齿轮图标是什么？">

蓝色齿轮图标是 Android 和 iOS 平台上的 **Tools button**。这是一个用于打开[开发者菜单](/debugging/tools/#developer-menu)的浮动快捷方式，你可以使用其中的重新加载应用和切换 Fast Refresh 等调试功能。它只会在开发期间显示，不会包含在生产版本中。

在本教程后续的屏幕截图中，我们会隐藏此图标。要隐藏它：

1. 打开开发者菜单。摇动设备，或者如果你使用的是模拟器、仿真器或通过 USB 连接的设备，请在运行开发服务器的终端中按 <kbd>M</kbd>。
2. 找到 **Tools button** 选项，并将其切换为关闭。

隐藏此图标不会禁用开发者菜单。需要时，你可以随时使用步骤 1 中介绍的方法打开它。
