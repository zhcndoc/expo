本章将添加最后一项核心功能：将带有贴纸的照片保存到智能手机的照片图库中。

<Step label="1">

## 保存到照片图库

请将以下提示粘贴到代理中。

```text プロンプト|wrap
在选项行中添加带有下载图标的“Save”。点击后，使用 react-native-view-shot 库仅捕获带有贴纸的照片，而不是整个屏幕，并使用 expo-media-library 库将其保存到智能手机的照片图库中。如有必要，请在首次使用时请求访问权限，并显示提示，告知用户图片已保存。
```

<Collapsible summary="英文原始提示">

```text Prompt|wrap
Add a "Save" option to the row of options, with a download icon. When I tap it, capture just the photo with the sticker on it (not the whole screen) using the react-native-view-shot library, and save the result to my phone's photo library using the expo-media-library library. Ask for permission the first time if needed, and show an alert confirming that the image was saved.
```

</Collapsible>

**显示内容**：点击 **Save** 后，首次使用时会请求保存到照片的权限。点击 **Allow**（允许）后，应用会显示确认消息。现在试着打开智能手机的照片图库吧。带有贴纸的照片已经在那里，并且可以分享到任何地方。

</Step>

<Step label="2">

## 让它也能在 web 上运行（可选）

这个应用并不只适用于智能手机。同一个项目也可以在 web 浏览器中运行。在运行开发服务器的终端窗口中按下 <kbd>W</kbd>，应用就会在浏览器中打开。除了 **Save** 以外，其他功能都可以运行。这是因为用于在智能手机上捕获图片的库无法在 web 上运行。

<Collapsible summary="如果希望 Save 选项也能在 web 上运行">

请将以下提示粘贴到代理中。

```text プロンプト|wrap
让应用在 web 浏览器中运行时也可以使用 Save 选项。react-native-view-shot 库不支持 web，因此当平台为 web 时，请改用 dom-to-image 库来捕获图片，并将其作为文件下载。
```

<Collapsible summary="英文原始提示">

```text Prompt|wrap
Make the Save option also work when the app runs in a web browser. The react-native-view-shot library doesn't support the web, so when the platform is web, use the dom-to-image library to capture the image and download it as a file instead.
```

</Collapsible>

**显示内容**：在浏览器中选择照片、添加贴纸并点击 **Save** 后，图片会作为文件下载。这就是在 Expo 应用中处理不同平台差异的方法。在一个应用中，只需在必要的位置添加简短的平台分支即可。

</Collapsible>

</Step>
