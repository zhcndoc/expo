<Step label="1">

## 打开终端

终端是用于与 AI 代理交互的应用。

- 在 macOS 上，打开预装的 **Terminal** 应用。打开 Spotlight 搜索（<kbd>Cmd ⌘</kbd> + <kbd>Space</kbd>），输入 "Terminal" 即可找到它。
- 在 Windows 上，从开始菜单打开 **PowerShell**。本章会在这里输入一些命令。每条命令都已准备好，可以直接复制和粘贴。

> **Cursor** 如果你打算使用 **Cursor**，本教程的大部分内容都将在 Cursor 的可视化编辑器中进行，而不是终端。不过，运行应用时仍需要使用终端，因此请准备好终端。

</Step>

<Step label="2">

## 安装 AI 代理

如果你已经在使用 AI 编程代理，请继续下一步。如果还没有，请从以下选项中选择一个。本教程无论选择哪个都可以按照相同的方式进行。

<Tabs>

<Tab label="Claude Code">

在终端窗口中运行以下命令，安装 [Claude Code](https://claude.com/claude-code)。

<Terminal cmd={['$ curl -fsSL https://claude.ai/install.sh | bash']} />

> **Windows 用户：** 要在 PowerShell 中安装 Claude Code，请运行 `irm https://claude.ai/install.ps1 | iex`。

接着在终端中运行 `claude`，并按照提示登录。如果遇到问题，请参阅 [Claude Code 设置指南](https://code.claude.com/docs/en/setup)。

</Tab>

<Tab label="Codex">

在终端窗口中运行以下命令，安装 [Codex](https://developers.openai.com/codex/cli)。

<Terminal cmd={['$ curl -fsSL https://chatgpt.com/codex/install.sh | sh']} />

接着在终端中运行 `codex`，并按照提示使用 ChatGPT 账户登录。如果遇到问题，请参阅 [Codex CLI 文档](https://developers.openai.com/codex/cli)。

</Tab>

<Tab label="Cursor">

下载 [Cursor](https://cursor.com)，然后像安装其他应用一样进行安装。Cursor 是一款内置 AI 代理的可视化代码编辑器，你可以在代理面板中输入提示词来使用它，而不是使用终端。

</Tab>

</Tabs>

其他代理也可以。只要代理能够编辑文件并在计算机上运行命令，就可以继续本教程。

</Step>

<Step label="3">

## 安装 Node.js

运行第一个提示词，安装 Node.js。

Node.js 是运行 Expo 开发工具的运行时。运行以下提示词，要求代理从 [nodejs.org](https://nodejs.org/en) 下载 **长期支持（LTS）** 版本。

```text プロンプト|wrap
私はまっさらな環境で Expo の "Build with AI" チュートリアルを進めていて、プログラミングの経験はありません。私のコンピュータに Node.js の最新の LTS 版をインストールして。

- まず、これからやることを 1〜2 文の平易な言葉で教えて。
- 私の OS を検出して、その OS に最も確実な方法でインストールして。
- 完了したら、`node --version` と `npm --version` の出力を見せてうまくいったか確認して。反映させるために何か開き直す必要があれば、それも教えて。
```

<Collapsible summary="英文原始提示词">

```text Prompt|wrap
I'm following the Expo "Build with AI" tutorial on a brand-new setup and I have no programming experience. Please install the latest LTS version of Node.js on my computer.

- First, tell me in one or two plain sentences what you're about to do.
- Detect my operating system and use the most reliable method for it.
- When you're done, verify it worked by showing me the output of `node --version` and `npm --version`, and tell me if I need to reopen anything for it to take effect.
```

</Collapsible>

要确认是否成功，请打开一个新的终端窗口并运行以下命令。应该会显示当前安装的 Node.js 版本号。

<Terminal cmd={['$ node --version']} />

</Step>

<Step label="4">

## 安装 Expo Go 并创建 Expo 账户

Expo Go 是一款免费应用，无需发布到应用商店，就可以在智能手机上测试开发中的项目。每当代理修改代码后，智能手机上的应用都会在几秒钟内更新。

1. 在智能手机上，从 Google Play 商店或 Apple App Store 安装 [Expo Go](https://expo.dev/go)。
2. 在计算机上访问 [expo.dev/signup](https://expo.dev/signup)，创建免费账户。
3. 在智能手机上打开 Expo Go，使用同一账户登录。

</Step>

<Step label="5">

## 告诉代理有关 Expo 的信息

Expo Skills 是一组用于指导 AI 代理正确构建 Expo 应用的指令文件。它会告诉代理应该使用哪些库、如何构建界面，以及如何避免常见错误。安装它是从代理获得良好结果的最有效方法。

<Tabs>

<Tab label="Claude Code">

启动 `claude`，然后在其中运行以下命令。

<Terminal cmd={['$ /plugin install expo@claude-plugins-official']} />

</Tab>

<Tab label="Codex">

在终端中运行以下命令。

<Terminal cmd={['$ codex plugin add expo@openai-curated']} />

</Tab>

<Tab label="Cursor">

在终端中运行以下命令。

<Terminal cmd={['$ npx skills add expo/skills']} />

{/* vale off */}

接着重启 Cursor，并确认在 **Settings** > **Rules, Skills, Subagents** > **Skills** 中可以看到这些技能。

{/* vale on */}

</Tab>

</Tabs>

<Step label="6">

## 连接 Expo MCP 服务器

Expo MCP 服务器可以让代理直接访问 Expo 工具。代理将能够阅读最新的 Expo 文档、安装合适的软件包，以及检查项目。

<Tabs>

<Tab label="Claude Code">

在终端中运行以下命令。

<Terminal cmd={['$ claude mcp add --transport http expo https://mcp.expo.dev/mcp']} />

接着启动 `claude`，并在其中运行 `/mcp`，使用上一步创建的 Expo 账户登录。

</Tab>

<Tab label="Codex">

在终端中运行以下命令，并在出现提示时使用上一步创建的 Expo 账户登录。

<Terminal cmd={['$ codex mcp add expo --url https://mcp.expo.dev/mcp']} />

</Tab>

<Step label="7">

## 验证设置

让我们确认一切是否都已顺利连接。将以下提示词粘贴到代理中。

```text プロンプト|wrap
Expo MCP サーバーを使って Expo のドキュメントで "expo-image-picker" を検索して、それが何をするものか 1 文で教えて。
```

<Collapsible summary="英文原始提示词">

```text Prompt|wrap
Use the Expo MCP server to search the Expo documentation for "expo-image-picker" and tell me in one sentence what it does.
```

</Collapsible>

**你将看到的内容**：代理会调用 Expo 的文档工具，并用一句话返回有关从设备的照片图库中选择图像的功能说明。如果显示连接错误或身份验证错误，请重新完成上一步中的登录操作。

</Step>
