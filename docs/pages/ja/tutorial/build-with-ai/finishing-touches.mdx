应用已经运行起来了。接下来只需要完成最后的润色。本章将处理那些用户可能不会特别注意、却能感受到的细节：状态栏、启动画面和应用图标。

<Step label="1">

## 修复状态栏

请查看应用的最顶部。时钟和电池图标颜色较深，在深色背景上难以阅读。请将以下提示词粘贴给代理。

```text プロンプト|wrap
スマートフォンのステータスバー（画面上部の時計とバッテリーのアイコン）が、暗い背景の上で読みづらいです。expo-status-bar ライブラリを使って、すべての画面でステータスバーの文字を明るい色にして。
```

<Collapsible summary="英文原文提示词">

```text Prompt|wrap
The phone's status bar (the clock and battery icons at the top of the screen) is hard to read against our dark background. Use the expo-status-bar library to make the status bar text light on every screen.
```

</Collapsible>

**显示效果**：屏幕顶部的时钟、电池和信号图标会变成明亮的颜色，更易于阅读。

  alt="深色应用背景上显示着明亮文字的状态栏"

  className="max-w-[480px]"
/>

</Step>

<Step label="2">

## 设置应用图标和启动画面

之前获取的资源包中还包含应用图标和启动画面的图片。请将以下提示词粘贴给代理。

```text プロンプト|wrap
アプリのアイコンを assets/images/icon.png に設定して。そして expo-splash-screen の config プラグインを使って、Android・iOS・web で assets/images/splash-icon.png を #25292e の背景の中央に表示するスプラッシュスクリーンを設定して。
```

<Collapsible summary="英文原文提示词">

```text Prompt|wrap
Set the app's icon to assets/images/icon.png, and configure the splash screen using the expo-splash-screen config plugin so it shows assets/images/splash-icon.png centered on a #25292e background on Android, iOS, and web.
```

</Collapsible>

**显示效果**：这些设置会写入应用的配置文件，因此需要重启开发服务器才能生效。在终端中按下 <kbd>Ctrl</kbd> + <kbd>C</kbd>，再次运行 `npx expo start`，然后从 Expo Go 重新打开应用。在项目加载期间，会短暂显示启动画面。

有一点需要注意。主屏幕上的应用图标不会改变。这是因为你当前运行的是 Expo Go 中的应用，使用的是 Expo Go 自身的图标。只有在创建应用的独立构建版本时，才会使用你自己的图标。准备好进入该阶段后，请参阅[开发构建](/develop/development-builds/introduction/)。

</Step>

> 如果结果与预期不符，请将你看到的情况原样告诉代理。[遇到问题时](/ja/tutorial/build-with-ai/create-your-first-app/#うまくいかないとき)提供了处理方法。

## 你已经完成了应用

现在请稍作停留，回顾一下到目前为止完成的工作。你从零开始搭建了开发环境，通过向 AI 代理发出指令，构建出了一个真正的应用，其中包含导航、照片选择、通过手势操作的贴纸，以及保存功能（可在 Android、iOS 和 web 上运行），而且一行代码都没有编写。

更重要的是，你已经学会了这个循环：发送提示词、构建、确认，然后再次发出指令。这个循环不会随着本教程结束。现在就用自己的想法试试看吧。
