## 关于本教程

本教程将帮助你掌握 [Expo Application Services（EAS）](https://expo.dev/eas) 的核心服务：[Build](/build/introduction/)、[Submit](/deploy/submit-to-app-stores/) 和 [Update](/eas-update/introduction/)。完成本教程后，无论是个人项目还是团队项目，你都将能够构建完整的移动端持续集成（CI）/持续交付（CD）流水线。

本教程将涵盖以下主题。

- 使用 EAS Build 创建并安装开发构建，并在实体设备、模拟器和仿真器上运行
- 体验使用开发构建代替 Expo Go 的优势
- 实践与团队成员或外部相关人员共享开发构建的工作流
- 自动逐个递增应用的构建版本
- 在一台设备上同时安装不同的应用变体，例如 development 和 preview
- 使用 EAS Update 在开发阶段快速创建和发布更新
- 连接 GitHub 仓库以自动化构建流程

这些主题将为有效使用 EAS 以及根据需要继续学习更高级的主题打下基础。

本教程采用实践形式，完成大约需要 2 小时。

## 工具

使用 [Expo Orbit](https://expo.dev/orbit)，可以在 macOS、Windows 和 Linux 上一键管理和启动构建。

如果你想在本地计算机上同时安装并运行构建，可以使用 Android Emulator 或 iOS Simulator。请参阅以下内容了解设置方法。

- [Android Emulator](/workflow/android-studio-emulator/)
- [iOS Simulator](/workflow/ios-simulator/)（仅可在 macOS 上使用）
