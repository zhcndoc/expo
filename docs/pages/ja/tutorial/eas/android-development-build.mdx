## 使用 Development 配置文件创建构建

在 Android 上，开发构建必须是 **.apk**。Android 的默认格式是 **.aab**，这对于在 Google Play 商店中分发非常理想，但无法安装到实体设备或模拟器上。

要创建 **.apk**，请执行以下操作。

- 确认 **eas.json** 的 `build.development` 配置文件中 `developmentClient` 已设置为 `true`。
- 接下来，指定平台为 `android`、构建配置文件为 `development`，运行 `eas build` 命令。

  <Terminal cmd={['$ eas build --platform android --profile development']} />

  > **info** **提示**：下次运行 `eas build` 命令时，也可以使用 `-p` 指定平台。这是 `--platform` 的缩写形式。

此命令会显示以下问题。

- **What would you like your Android application id to be?**（您希望 Android application ID 是什么？）按下 <kbd>Return</kbd>，选择显示的默认值。这样会将 [`android.package`](/versions/latest/config/app/#package) 添加到 **app.json** 中。
- **Generate a new Android Keystore**?（是否生成新的 Android Keystore？）按下 <kbd>Y</kbd>。

回答后，构建会进入队列，您可以通过 EAS CLI 显示的链接，在 EAS 控制面板中查看进度。

<Collapsible summary="构建详细信息页面包含哪些信息？">

构建详细信息页面会显示构建类型、配置文件、Expo SDK 版本、应用版本、版本代码、最后一次提交的哈希值，以及启动构建的开发者或账户所有者。

在上图中，**Build artifact** 的当前状态表示构建正在进行中。完成后，您可以从此部分下载构建结果。**Logs** 中会列出 Android 在 EAS Build 上的构建过程的各个步骤。为简洁起见，这里不介绍每个步骤的详细信息。详情请参阅 [Android 构建过程](/build-reference/android-builds/)。

</Collapsible>

<Collapsible summary="什么是 Android application ID？">

它也称为 Android 应用的包名，其值采用 DNS 逆序表示法（`com.owner.appname`）。此表示法中的每个元素都必须以小写字母开头。

例如，示例应用的值为 `com.owner.stickersmash`，其中 `com.owner` 是域名，`stickersmash` 是应用名称。

</Collapsible>

## Android 实体设备

<Step label="1">

### 安装开发构建

构建完成后，**Build artifact** 部分会更新，以表示构建已完成。

<ContentSpotlight
  alt="Build artifact 提供在 Android 设备和模拟器上下载开发构建的选项"
  src="/static/images/tutorial/eas/android-build-artifact.png"
/>

此部分提供 Expo Orbit 和 Install 按钮，作为在 Android 实体设备上运行开发构建的方式。

使用 [Expo Orbit](https://expo.dev/orbit)，可以顺利地将开发构建安装到 Android 实体设备上。使用此方法时，请执行以下操作。

- 通过 USB 将 Android 实体设备连接到本地计算机。
- 打开 Orbit 应用。
- 在 Orbit 应用中选择 **Device**。

<ContentSpotlight
  alt="连接 Android 设备时的 Expo Orbit 应用界面"
  src="/static/images/tutorial/eas/android-orbit.png"
  className="max-w-[300px]"
/>

- 在 EAS 控制面板的 **Build artifact** 中点击 **Open with Orbit**。

安装构建后，Orbit 应用会在实体设备上启动开发构建。

<Collapsible summary="其他方法：使用 Install 按钮和 QR 码">

**Build artifact** 中的 **Install** 按钮会生成用于安装的 QR 码。

- 点击 **Install**，会显示包含 QR 码的弹窗。

<ContentSpotlight
  alt="Install 按钮生成 QR 码，以便在 Android 设备和模拟器上轻松安装"
  src="/static/images/tutorial/eas/android-qr-code.png"
  className="max-w-[480px]"
/>

- 使用 Android 实体设备的相机扫描 QR 码，然后在默认 web 浏览器中打开构建链接。
- 点击页面中的 **Install** 按钮，下载 **.apk** 文件。
- 下载完成后，打开 **.apk** 开始安装。
- 如果显示 **Unsafe app blocked** 消息，请选择 **Install anyway**。由于 **.apk** 的来源（由您自行生成）是可信的，因此可以忽略此警告。

<ContentSpotlight
  alt="在 Android 设备上安装开发构建时显示的 Unsafe app 消息对话框"
  src="/static/images/tutorial/eas/android-unsafe-dialog.webp"
  className="max-w-[300px]"
/>

</Collapsible>

</Step>

<Step label="2">

### 运行开发构建

在项目目录中运行 `npx expo start`，启动开发服务器。服务器启动后，在终端窗口中按 <kbd>A</kbd> 打开项目。

<Terminal
  cmd={{
    npm: ['$ npx expo start'],
    yarn: ['$ yarn expo start'],
    pnpm: ['$ pnpm expo start'],
    bun: ['$ bun expo start'],
  }}
/>

</Step>

## Android Emulator

<Step label="1">

### 安装开发构建

构建完成后，EAS CLI 会在终端中询问是否在 Android Emulator 上运行构建。按下 <kbd>Y</kbd>。

<ContentSpotlight
  alt="EAS CLI 自动提供在 Android Emulator 上运行构建的选项"
  src="/static/images/tutorial/eas/android-emulator-cli.png"
  className="max-w-[600px]"
/>

<Collapsible summary="其他方法：使用 Expo Orbit">

也可以使用 [Expo Orbit](/build/orbit/) 进行安装。在 EAS 控制面板的 **Build artifact** 中点击 **Open with Expo Orbit**，开发构建就会安装到 Android Emulator 中。

</Collapsible>

</Step>

<Terminal
  cmd={{
    npm: ['$ npx expo start'],

    pnpm: ['$ pnpm expo start'],
    bun: ['$ bun expo start'],

</Step>
