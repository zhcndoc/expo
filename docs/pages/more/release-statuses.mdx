title: 发布状态
description: 了解 Expo SDK、Expo Router、EAS 和 Expo CLI 中使用的实验性、Alpha、预览、Beta、稳定版和已弃用发布状态
---

Expo 使用各种发布状态来表示其工具和服务的稳定性与准备程度。了解这些状态可以帮助你对项目中应使用哪些功能和版本做出明智的决定。

这些状态并不是每项功能都会经历的单一流程。每个产品领域都会使用适合其发布方式的状态：

| 产品领域                             | 主要会看到的状态                   |
| ------------------------------------ | ---------------------------------- |
| Expo SDK 库和 Expo Router            | [Alpha](#alpha)、[Beta](#beta)     |
| EAS 服务                             | [预览](#preview)、[Beta](#beta)    |
| Expo CLI 和其他开发工具              | [实验性功能](#experimental)        |

> **info** **注意：** 任何功能都可能在其生命周期结束时变为[已弃用](#deprecated)，而稳定库中的独立 API 也可能是[实验性的](#experimental)。

## 实验性功能

实验性功能是对新想法的早期探索。我们分享这些功能是为了验证发展方向，目前仍在决定该功能是否应该存在。

**预期情况：**

- 可能在任何版本中发生重大变化或被完全移除
- API 可能会在不另行通知或提供弃用警告的情况下发生变化
- 应将实验性功能的实现视为概念验证，而不是最终版本
- 可能存在已知错误、功能缺失或性能问题，并且不保证会修复
- 不建议用于生产应用

实验性功能是尝试新想法并影响其是否继续发展的最早机会。请在开发环境中进行测试，并[分享您的反馈](https://expo.dev/contact)，帮助我们决定下一步的发展方向。

> **info** **注意：** 此处的 Experimental 状态不同于[应用配置](/workflow/configuration/)中的 [`experiments`](/versions/latest/config/app/#experiments)字段。该字段用于启用选择加入的功能，这些功能在 Expo 项目的应用配置中不一定是实验性的。例如，`experiments.typedRoutes` 会启用[类型化路由](/router/reference/typed-routes/)，它是一项 Beta 功能。

## Alpha

Alpha 功能可供早期测试，但可能存在较大的限制。这些功能处于开发的最早阶段，会与社区分享以收集反馈并塑造其发展方向。

**可以预期：**

- API 可能会在不发布新版 SDK 的情况下发生破坏性变更
- 实现可能会根据反馈发生重大变化
- 不建议用于生产应用

Alpha 功能是影响 Expo 未来的机会。我们鼓励你在开发环境中测试这些功能，并[提供反馈](https://expo.dev/contact)，帮助我们在它们面向更广泛的受众之前进一步完善。

## 预览

预览功能让你可以提前了解新功能中某个专注的部分。它们以最小开销和有限范围为设计目标，但尚未实现完整功能。你主要会在新的 EAS 服务中看到此状态。

**可以预期：**

- 功能中的某个专注部分，而不是完整的功能集
- 随着功能的完善，API 可能会发生破坏性变更
- 经过全面测试后可以用于生产环境

预览的目的是尽早分享新功能，并在进一步完善之前收集关于特定部分的反馈。你的意见将直接帮助塑造该功能的方向。[分享你的反馈](https://expo.dev/contact)，帮助我们确定下一步优先构建什么。

## Beta

Beta 功能已完成功能开发，正在稳定版发布前进行最终验证。你主要会在 EAS 服务和接近稳定的 SDK 库中看到此状态。

**可以预期：**

- 核心功能已完成
- 除非发现严重问题，否则可能发生破坏性变更，但不太可能
- 经过全面测试后可以用于生产环境

Beta 功能已准备好用于真实世界测试。虽然我们不预期会有重大变更，但如果你计划在生产环境中使用，我们建议进行彻底测试。[你的反馈](https://expo.dev/contact)在这个阶段能帮助我们在稳定发布前发现任何遗留问题。

## 稳定版

没有状态徽章的功能都是稳定的，已完整发布，可用于生产环境。

**可以预期：**

- 已准备好用于生产环境，并提供完整支持
- 根据语义化版本控制，稳定功能的破坏性变更只会在新的主版本中发生

## 已弃用

已弃用的功能不再建议使用，并将在未来版本中移除。我们会提供弃用警告，为开发者留出时间来停止使用这些功能并完成迁移。

**可以预期：**

- 文档和代码会显示弃用警告
- Expo 可能不再接受有关已弃用 API 的反馈或问题
- 已弃用的功能和 API 会在新的 SDK 版本中移除
