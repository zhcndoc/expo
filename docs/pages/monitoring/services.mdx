一旦你的应用发布，你就可以跟踪匿名化的使用数据，从而了解用户如何使用你的应用。这些数据包括正在使用哪些更新、用户何时遇到错误、应用在生产环境中的表现等等。

## EAS 洞察

[EAS 洞察](/eas-insights/introduction/) 是一个仪表板，可展示你项目中的趋势，分为三个选项卡：

- **[App usage](/eas-insights/app-usage/)**：基于 [EAS Update](/deploy/send-over-the-air-updates/) 请求和 `expo-insights` 库汇总的应用在不同平台、应用商店版本以及时间维度上的使用情况。
- **[Workflows](/eas-insights/workflows/)**：你的 [EAS Workflows](/eas/workflows/introduction/) 的运行次数、成功率和趋势。
- **[Maestro](/eas-insights/maestro/)**：[Maestro](https://maestro.dev/) 端到端测试的通过、波动和失败趋势，这些测试运行于 EAS Workflows 中。

## EAS Observe

[EAS Observe](/eas/observe/introduction/) 是 Expo 提供的一项性能监控服务，用于跟踪你的应用在生产环境中的表现。它可以让你了解真实应用用户会话中的启动指标（例如冷启动时间、首次渲染时间和可交互时间）、渲染性能，以及应用在不同设备、网络和条件下的用户体验。它还会记录你从应用中记录的[用户自定义事件](/eas/observe/events/)，因此你可以将自定义信号与性能数据结合起来进行跟踪。

## LogRocket

你可以通过 [LogRocket](https://logrocket.com) 获得更多洞察。LogRocket 会记录用户会话，并在用户使用你的应用时识别错误。你可以按更新 ID 筛选会话，还可以在 EAS 仪表板中连接你的 LogRocket 账户，以便快速访问应用的会话数据。

## Sentry

[Sentry](https://getsentry.com/) 是一个崩溃报告平台，它通过提供可帮助重现和修复崩溃的信息，让你实时了解生产环境部署情况。

当你的用户在使用应用时遇到异常或错误，Sentry 会通知你，并在 Web 仪表板中为你整理这些问题。报告的异常会自动包含堆栈跟踪、设备信息、版本和其他相关上下文。你还可以提供与你的应用相关的其他上下文，例如当前路由和用户 ID。

## Vexo

[Vexo](https://www.vexo.co/) 帮助你了解用户如何与你的 Expo 应用交互、识别阻碍点并提升参与度。它通过简单的两行集成提供实时用户分析，并提供一个完整的仪表板，包含用户活动、应用性能和采用趋势的洞察，以及热力图、会话回放等功能。

## BugSnag

[BugSnag](https://www.bugsnag.com/) 是一个稳定性监控解决方案，可提供丰富的端到端错误报告和分析，帮助你快速而精准地复现和修复错误。BugSnag 支持完整技术栈，并为 50 多个平台提供开源库，包括 React Native。

## PostHog

[PostHog](https://posthog.com/) 是一个产品分析平台，提供会话回放、功能标志和错误跟踪。EAS CLI 集成会配置一个 PostHog 项目，连接 SDK，并允许你通过发布标记按 EAS Update 为事件添加标签，这样你就可以按发布筛选分析和错误。
