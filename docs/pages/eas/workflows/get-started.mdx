本页面将引导你创建第一个 EAS 工作流：为 Android 模拟器、iOS 模拟器、实体设备以及应用商店构建你应用的开发构建版本和生产构建版本。

## 开始使用

<Prerequisites>
  <Requirement title="注册 Expo 账号">
    你需要先[注册](https://expo.dev/signup)一个 Expo 账号。
  </Requirement>
  <Requirement title="创建项目">
    你需要使用以下命令创建一个项目：

    <Terminal
      cmd={{
        npm: ['$ npx create-expo-app@latest --template default@sdk-57'],
        yarn: ['$ yarn create expo-app --template default@sdk-57'],
        pnpm: ['$ pnpm create expo-app --template default@sdk-57'],
        bun: ['$ bun create expo --template default@sdk-57'],
      }}
    />

  </Requirement>
  <Requirement title="安装 EAS CLI">
    你需要安装 EAS CLI 来创建和运行工作流：

    <Terminal cmd={['$ npm install -g eas-cli']} />

  </Requirement>
</Prerequisites>

<Step label="1">

运行以下命令来创建一个工作流，用于为 Android 和 iOS 创建开发构建：

<Terminal cmd={['$ eas workflow:create --template build']} />

然后按提示操作，并在出现 `[Action requested]` 步骤时继续执行。该命令会在 **.eas/workflows/build.yml** 处生成一个工作流文件，并为你在 EAS 上构建项目进行设置。

</Step>

<Step label="2">

使用以下命令运行该工作流：

<Terminal cmd={['$ eas workflow:run .eas/workflows/build.yml']} />

完成后，你可以在项目的[工作流页面](https://expo.dev/accounts/[account]/projects/[projectName]/workflows)上查看工作流的运行情况。

</Step>

<Step label="3">

当构建完成后，你可以通过网站界面将它们安装到你的实体设备上。你也可以运行以下命令，将最新构建安装到你的 Android 模拟器和 iOS 模拟器上：

<Terminal cmd={['$ eas build:run -p android --latest']} />

<Terminal cmd={['$ eas build:run -p ios -e development-ios-simulator --latest']} />

然后，启动一个开发服务器，这样开发构建就可以加载你的应用：

<Terminal cmd={['$ npx expo start']} />

</Step>

## 创建生产构建

当你准备为应用商店构建时，使用 `deploy` 模板生成一个发布工作流：

<Terminal cmd={['$ eas workflow:create --template deploy']} />

这会为自动化部署配置你的项目：它会配置 EAS Build 和 EAS Update，并设置你的应用标识符，然后将一个完整的发布工作流写入 **.eas/workflows/deploy.yml**。

运行它时，工作流会为你的项目生成指纹，然后在存在原生更改时构建并提交一个新的生产构建，以便它们可供提交；或者在已存在匹配构建时发布一个空中更新，这将会立即发送给你的用户。

有关生成的工作流的演练，请参阅 [部署到生产示例](/eas/workflows/examples/deploy-to-production)。

如果你只需要创建生产构建，请为每个平台使用一个包含 `build` 作业的工作流：

```yaml .eas/workflows/create-production-builds.yml
name: 创建生产构建

jobs:
  build_android:
    type: build # 此作业类型会为 Android 创建一个生产构建
    params:
      platform: android
      profile: production
  build_ios:
    type: build # 此作业类型会为 iOS 创建一个生产构建
    params:
      platform: ios
      profile: production
```

此工作流使用你 **eas.json** 中的 `production` 配置。生产构建需要应用签名凭据。请使用以下命令为每个平台进行设置：

<Terminal cmd={['$ eas credentials:configure-build -p android -e production']} />

<Terminal cmd={['$ eas credentials:configure-build -p ios -e production']} />

然后，运行该工作流：

<Terminal cmd={['$ eas workflow:run .eas/workflows/create-production-builds.yml']} />

## 更多

### 使用 GitHub 事件自动化工作流

你可以通过向 GitHub 仓库推送提交来触发工作流。你可以按以下步骤将 GitHub 仓库连接到你的 EAS 项目：

- 进入项目的[GitHub 设置](https://expo.dev/accounts/%5Baccount%5D/projects/%5BprojectName%5D/github)。
- 按照界面提示安装 GitHub 应用。
- 选择与 Expo 项目匹配的 GitHub 仓库并将其连接。

然后，将[`on` 触发器](/eas/workflows/syntax/#on)添加到你的工作流文件中。例如，如果你想在提交推送到 `main` 分支时触发工作流，可以添加以下内容：

```yaml .eas/workflows/create-production-builds.yml
name: 创建生产构建

# @info #
on:
  push:
    branches: ['main']
  # @end #

jobs:
  build_android:
    type: build
    params:
      platform: android
      profile: production
  build_ios:
    type: build
    params:
      platform: ios
      profile: production
```

### 从 App Store Connect 事件触发工作流

你也可以使用[`on.app_store_connect`](/eas/workflows/syntax/#onapp_store_connect)从 App Store Connect 事件触发工作流。

在使用 App Store Connect 触发器之前，请先在 EAS 仪表板中配置你的 App Store Connect 连接：

- 打开 EAS 仪表板并选择你的项目。
- 进入**[项目设置 > 常规 > 连接](https://expo.dev/accounts/[account]/projects/[project]/settings)**。
- 连接你的 App Store Connect 应用。

示例工作流：

```yaml .eas/workflows/app-store-connect-events.yml
name: 响应 App Store Connect 事件

# @info #
on:
  app_store_connect:
    app_version:
      states:
        - ready_for_review
        - waiting_for_review
  # @end #

jobs:
  send_slack_notification:
    type: slack
    environment: production
    params:
      webhook_url: ${{ env.SLACK_WEBHOOK_URL }}
      message: '应用版本已准备好审核或正在等待审核。'
```

示例会从 `SLACK_WEBHOOK_URL` [环境变量](/eas/environment-variables/manage/#manage-environment-variables)中读取 webhook URL。运行工作流之前，请先在 `production` 环境中[创建它](https://expo.dev/accounts/[account]/settings/environment-variables)。
