**EAS Observe** 是 Expo 提供的一项性能监控服务，用于跟踪你的应用在生产环境中的表现。它能让你了解真实世界中的启动时间、渲染性能，以及不同设备、网络和条件下的用户体验。

React Native 中的性能调试传统上仅限于开发工具。EAS Observe 关注的是生产环境，因为那里的性能特征与你在开发过程中看到的情况有很大不同。

## 为什么选择 EAS Observe

传统的开发期分析工具展示的是应用在你自己机器上的表现。EAS Observe 展示的是它在真实用户环境中的表现：

- **生产环境性能数据**：从不同设备上的真实用户会话中跟踪启动时间、渲染性能和 bundle 加载时间
- **版本发布对比**：查看不同应用版本和 OTA 更新之间的指标变化，以便及早发现性能回归
- **会话调查**：深入了解单个用户会话，以弄清某些设备或条件导致性能变慢的原因
- **用户定义事件**：使用 `Observe.logEvent` 从应用中记录自定义信号，并将其与性能数据一起分析
- **CLI 和仪表板访问**：使用 `eas observe:` 命令从终端查询指标，或在 EAS 仪表板中查看指标

## 何时使用 EAS Observe

| 场景                                               | 建议             |
| --------------------------------------------------- | -------------- |
| 在生产环境中监控应用启动性能                         | <YesIcon />    |
| 比较不同版本发布和 OTA 更新之间的性能                 | <YesIcon />    |
| 调查特定设备上的慢速会话                             | <YesIcon />    |
| 从 CLI 查询性能指标                                  | <YesIcon />    |
| 跟踪应用中的用户定义事件                             | <YesIcon />    |
| 开发期分析与调试                                     | <NoIcon />     |
| 崩溃报告和错误跟踪                                   | <NoIcon />     |

**开发期分析与调试**：使用 [React Native DevTools](/debugging/tools/#debugging-with-react-native-devtools) 进行调试，并使用 [Expo Atlas](/guides/analyzing-bundles/) 检查 bundle。

**崩溃报告和错误跟踪**：这是 EAS Observe 未来计划添加的功能。目前我们建议使用 [Sentry](/guides/using-sentry/) 或 [BugSnag](/guides/using-bugsnag/) 等崩溃报告服务。

## 常见问题（FAQ）

<FAQ>

<Collapsible summary="EAS Observe 跟踪哪些指标？">

EAS Observe 主要关注启动指标：冷启动时间、热启动时间、首次渲染时间、可交互时间和 bundle 加载时间。有关每项指标的详细说明，请参见[指标参考](/eas/observe/reference/metrics/)。你还可以将自己的信号记录为[用户定义事件](/eas/observe/events/)。

</Collapsible>

<Collapsible summary="支持哪些平台？">

EAS Observe 支持 Android 和 iOS。指标会从生产构建中收集，并可在仪表板和 CLI 中按平台筛选。

</Collapsible>

<Collapsible summary="EAS Observe 是否可在 Expo Go 中使用？">

不可以。EAS Observe 依赖于 `expo-observe` 原生库，而该库不包含在 Expo Go 中。要使用它，请创建一个 [开发构建](/develop/development-builds/introduction/) 或生产构建。

</Collapsible>

<Collapsible summary="EAS Observe 会收集个人身份信息吗？">

不会。用户通过一个匿名 ID 进行标识，该 ID 在每次应用安装中都是唯一的。此 ID 不可识别个人身份，且当用户卸载并重新安装应用时会重置。更多详情请参见[指标参考：用户](/eas/observe/reference/metrics/#user)。

</Collapsible>

<Collapsible summary="设备离线时会发生什么？">

离线期间收集的指标会存储在设备本地。当应用切换到后台且网络连接可用时，它们会自动发送。你也可以使用 `dispatchEvents()` 手动刷新事件。

</Collapsible>

<Collapsible summary="我可以在开发期间测试指标吗？">

默认情况下，从调试构建中收集的指标不会发送。不过，你仍可以通过 [`configure()`](/eas/observe/configuration/#configure) 将 `dispatchInDebug` 设置为 `true` 来进行测试。详情请参见[配置](/eas/observe/configuration/#enable-metrics-in-development)。

</Collapsible>

<Collapsible summary="指标数据会保留多久？">

指标数据至少保留 60 天。

</Collapsible>

</FAQ>
