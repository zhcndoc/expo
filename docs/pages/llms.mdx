使用以下端点和工具，让 AI 代理和 LLM 以比获取完整网页更低的 token 成本访问 Expo 文档。

## 快速开始

选择与你的工具相匹配的方法：

| 方法                   | 最适合                                                     | 使用方式                                                                       |
| ---------------------- | ---------------------------------------------------------- | ------------------------------------------------------------------------------ |
| 单页 Markdown          | ChatGPT、Claude.ai 等聊天界面和编码代理                    | 在任意文档页面 URL 后附加 `/index.md` 或 `.md`。                               |
| 复制 Markdown 下拉菜单 | 使用单个页面的快速提示                                     | 点击任意文档页面顶部的 **Copy page** > **Copy Markdown**。                     |
| 文档索引               | 项目规则和编码代理                                         | 将通用索引（`/llms.txt`）添加到 AI 工具配置中。                                |

## 单页 Markdown

每个文档页面都有一个轻量级的 markdown 版本，只需在页面 URL 后附加 `/index.md` 或 `.md` 即可访问。这两个 URL 提供的是同一个文件。例如：

```text Introduction to development builds
https://docs.expo.dev/develop/development-builds/introduction/index.md
https://docs.expo.dev/develop/development-builds/introduction.md
```

当你希望向 AI 代理提供某个特定主题或页面的上下文，而又不想让它接收该页面完整 HTML 时，上述方法非常有用。

## 文档索引

Expo 支持 [llms.txt](https://llmstxt.org/) 倡议，为大型语言模型（LLM）及使用它们的应用提供文档。

[/llms.txt](/llms.txt) 文件（约 54 kB）列出了每个文档页面，并附有其 Markdown 版本的链接和简短描述。AI 代理可以使用它来发现与任务相关的页面，然后仅获取这些页面，而不是将完整文档加载到其上下文窗口中。
