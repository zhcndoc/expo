Expo 是一个 React Native 框架，它使开发 Android 和 iOS 应用变得更容易。我们的框架提供基于文件的路由、原生模块标准库等更多功能。Expo 是开源的，在 [GitHub](https://github.com/expo/expo) 和 [Discord](https://chat.expo.dev) 上拥有活跃的社区。

我们还提供 [Expo 应用服务（EAS）](https://expo.dev/eas)，这是一组在开发过程的每个步骤中补充 Expo 框架的服务。

> **info** **编程新手？** 你可以通过提示 AI 编程代理来构建你的第一个 Expo 应用，而不是自己编写代码。请参阅 [使用 AI 构建教程](/tutorial/build-with-ai/introduction/)。其中涵盖了从零开始的设置过程。

## 系统要求

- [Node.js (LTS)](https://nodejs.org/en/)。
- 支持 macOS、Windows（Powershell 和 [WSL 2](https://expo.fyi/wsl)）以及 Linux。

## 从默认项目开始

我们建议从 [`create-expo-app`](/more/create-expo/) 创建的默认项目开始。默认项目包含示例代码，可帮助你快速上手。

要创建新项目，请运行以下命令：

<Terminal
  cmd={{
    npm: ['$ npx create-expo-app@latest --template default@sdk-57'],
    yarn: ['$ yarn create expo-app --template default@sdk-57'],
    pnpm: ['$ pnpm create expo-app --template default@sdk-57'],
    bun: ['$ bun create expo --template default@sdk-57'],
  }}
/>

> **注意：** 在 SDK 57 过渡期间，不带 `--template` 标志的 `create-expo-app@latest` 会创建一个 SDK 54 项目。如果你计划在实体设备上使用 Expo Go，请使用 SDK 54 项目。否则，请使用 `--template default@sdk-57` 创建 SDK 57 项目。你也可以通过添加 [`--template` 选项](/more/create-expo/#--template) 来选择其他模板。

## 从示例开始

你可以不使用默认项目，而是从 [Expo 示例](https://github.com/expo/examples) 中选择一个开始。这些都是小型应用，每个都演示一个特定的功能或集成，例如 Expo Router、Expo Widgets 或相机页面。

要浏览完整列表并交互式地选择一个，请运行带有 [`--example`](/more/create-expo/#--example) 选项且不指定名称的 `create-expo-app`：

<Terminal
  cmd={{
    npm: ['$ npx create-expo-app@latest --example'],
    yarn: ['$ yarn create expo-app --example'],
    pnpm: ['$ pnpm create expo-app --example'],
    bun: ['$ bun create expo --example'],
  }}
/>

要直接创建一个已知示例，请传入其名称：

<Terminal
  cmd={{
    npm: ['$ npx create-expo-app@latest --example with-widgets'],
    yarn: ['$ yarn create expo-app --example with-widgets'],
    pnpm: ['$ pnpm create expo-app --example with-widgets'],
    bun: ['$ bun create expo --example with-widgets'],
  }}
/>

> **info** 本 **“入门”** 部分中的其余指南都基于默认项目。示例应用的组织方式可能不同，但概念是相同的。
