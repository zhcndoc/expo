当项目中的 Expo SDK 版本与已安装的 Expo Go 应用中包含的 SDK 版本不匹配时，Expo Go 会显示此错误：

```text
Project is incompatible with this version of Expo Go
```

你还可能会看到以下消息之一：

```text
The project you requested requires a newer version of Expo Go.
This project requires a newer version of Expo Go.
```

## 为什么会发生这种情况

每个 Expo Go 构建版本都包含一个 Expo SDK 版本。**package.json** 中的 `expo` 软件包版本决定了项目的 SDK 版本。项目和 Expo Go 的 SDK 版本必须匹配。

Apple App Store 中的 Expo Go 最高支持 SDK 54，SDK 55 及更高版本无法在其中使用。Google Play 版本也可能落后于新的 SDK 版本发布。如果你的项目使用的 SDK 比应用商店中的构建版本更新，请使用以下选项之一，而不是等待应用商店更新。

## 安装兼容的 Expo Go 版本

根据测试项目的设备，使用相应的说明。

### 实体 iPhone 或 iPad

对于使用 SDK 55 或更高版本的项目，打开 [sign.expo.dev](https://sign.expo.dev/)，选择项目使用的 SDK 版本，然后按照步骤在设备上安装该 Expo Go 构建版本。

此安装程序使用你的 Apple ID 提供的免费开发者配置，因此不需要付费的 Apple Developer Program 会员资格。证书有效期约为七天。证书过期后，返回 [sign.expo.dev](https://sign.expo.dev/) 重新签名并安装 Expo Go。

对于使用 SDK 54 的项目，请从 Apple App Store 安装 Expo Go。你还可以使用 [`eas go`](https://expo.fyi/deploy-expo-go-testflight) 构建 SDK 54 或更高版本的 Expo Go，并通过 TestFlight 内部团队分发，这需要 Apple Developer Program 会员资格。

对于使用 SDK 53 或更早版本的项目，无法在实体 iOS 设备上安装旧版本的 Expo Go。升级项目、使用 Android 设备或 iOS Simulator，或者创建 development build。

### Android 设备、Android Emulator 或 iOS Simulator

访问 [expo.dev/go](https://expo.dev/go)，选择项目使用的 SDK 版本和目标平台，然后安装兼容的 Expo Go 构建版本。

你还可以使用 [`expo-go` CLI](/develop/tools/#expo-go-cli) 下载特定版本。

安装兼容的构建版本后，使用 `npx expo start` 重启开发服务器，然后重新打开项目。

## 检查项目的 SDK 版本

如果安装正确的 Expo Go 构建版本后错误仍然存在：

1. 检查 **package.json** 中的 `expo` 依赖项，确认项目的 SDK 版本。
2. 如果你的 [app config](/workflow/configuration/) 包含 `sdkVersion` 字段，请将其删除，或确保其与 `expo` 依赖项匹配。
3. 运行 `npx expo-doctor@latest` 检查依赖项版本问题。
4. 运行 `npx expo install --fix`，使软件包版本与已安装的 Expo SDK 保持一致。

## 升级项目或使用 development build

你可以[将项目升级到更新的 Expo SDK](/workflow/upgrading-expo-sdk-walkthrough/)，而不是安装其他版本的 Expo Go。

Expo Go 是一个学习环境和沙盒。对于生产项目，请[创建 development build](/develop/development-builds/introduction/)，这样原生应用及其依赖项就由你的项目控制。
